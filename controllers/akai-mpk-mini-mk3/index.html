AKAI MPK mini mk3

AKAI MPK mini mk3 is a MIDI hardware controller by AKAI Professional: 8 pads, 25 keys, 8 knobs and 2 wheels.

It sends Pitch bend, CC and Note on channels 1, 10. The profile cites 6 sources. 25 of its controls are marked unverified: the number is our best reading, and Learn rebinds it in one move.

Notes on single controls

  • keys Lowest key at octave 0 is not printed in the docs; C3 = 48 is assumed. Keys follow any note on channel 1, so an octave shift just scrolls the on-screen keys.

Notes

Program 1 ("PGM:MPC", loaded at power-on), pads in Note mode, Bank A. Bank B (notes 44–51) and the CC (16–31) / Prog Change (0–15) pad modes re-use the same 8 pads — a layer the faceplate cannot show, so they are not modelled (學習 rebinds; they still arrive as midi/ch/10/…). The knobs are endless but send absolute 0–127 (the unit keeps the value). The joystick is drawn as two strips: X = pitch bend (springs to centre), Y = CC 1 rising from 0 whichever way you push it ("Dual CC", springs back to 0). Pad pressure arrives as channel aftertouch on channel 10. Arp, Tap Tempo, Octave, Full Level, Note Repeat, Bank, CC, Prog Change and Prog Select act inside the unit and send nothing of their own. The pads light themselves; no LED feedback is sent.

Port names it recognises

matches
/mpk\s*mini\s*(3|mk\s*3|mkiii)/i

Signals

Every control publishes midi/mpkmini3/<control> (0..1), plus /raw; pads add /hit, encoders /delta, keys /on /off and n<note>; the last control touched is midi/mpkmini3/last.

Use it

Use AKAI MPK mini mk3 in your own work

  1. Embed it with one line

    No import map, no build step. Change layout, add hardware="ask" for a Connect button.

    html
    <script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="akai-mpk-mini-mk3" readout></oav-controller>

  2. Or as an iframe

    For places that only take an iframe. Every event arrives as a postMessage.

    html
    <iframe src="https://openaudiovisual.com/embed/controller/?profile=akai-mpk-mini-mk3&readout"
        width="720" height="432" style="border:0;max-width:100%" allow="midi"
        title="AKAI MPK mini mk3"></iframe>
<script>
  // every control the visitor plays arrives here
  addEventListener('message', (e) => {
    if (e.data?.source !== 'openav' || e.data.type !== 'control') return;
    console.log(e.data.detail.signal, e.data.detail.value);
  });
</script>

  3. Send it to Ableton, TouchDesigner or Resolume

    What you play on screen leaves as real MIDI on the IAC bus (macOS) or a loopMIDI port (Windows). The steps are on the catalog page.

    html
    <!-- what you play on this controller → the IAC bus (macOS) → Ableton, TouchDesigner, Resolume -->
<script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="akai-mpk-mini-mk3" midi-out="IAC" readout></oav-controller>
<!-- Windows: midi-out="loopMIDI" · let the visitor pick a port: midi-out="ask" -->

    macOS: Audio MIDI Setup → MIDI Studio → IAC Driver → “Device is online”. Windows: install loopMIDI and add a port; use midi-out="loopMIDI".

document.head.prepend(Object.assign(document.createElement('script'), { src: 'https://openaudiovisual.com/p5/oav-p5.js?profile=akai-mpk-mini-mk3' }));

  circle(random(width), random(height), velocity * 100);

  circle(random(width), random(height), velocity * 100);
}
