Novation Launchkey 37 MK4

Novation Launchkey 37 MK4 is a MIDI hardware controller by Novation: 16 pads, 37 keys, 8 knobs, 1 button and 2 wheels.

It sends Pitch bend, CC and Note on channels 1, 10. The profile cites 6 sources. 8 of its controls are marked unverified: the number is our best reading, and Learn rebinds it in one move.

Notes

Standalone, MIDI port (the device powers up in Standalone mode; no DAW needed). Keys C2–C5 (notes 48–84), channel 1 (Keys Channel setting; octave and transpose buttons shift the range, the faceplate follows any note on the channel). Pads in the default Drum mode: notes 36–51 on channel 10 with poly aftertouch (factory Pad Aftertouch = Polyphonic), 2 × 8 as in the Programmer's Reference (bottom-left 36 … top-right 51). Pitch wheel = pitch bend, mod wheel = CC 1 and sustain pedal = CC 64 are Novation's defaults (Components Guide); the channel they use is not printed (Keys Channel 1 assumed). The 37 MK4 has no faders or fader buttons (49/61 only) and the wheels are real wheels (the Mini MK4 has touch strips; it is a different profile family and not matched). Encoders: power-on mode is Custom 1 but Novation prints no default numbers — CC 21–28 on channel 1 is a placeholder, marked unverified (學習 rebinds, or set them in Novation Components). DAW mode (Plugin / Mixer / Sends / Transport encoders, DAW pad layout, track and transport buttons, screen and LED control) needs a DAW and talks on the DAW port, channels 1, 7 and 16 — not modelled. In Standalone the DAW-control buttons send CC on channel 16 (Programmer's Reference, Figure 1) but the printed figures do not show a Launchkey 37 map: Shift, Octave, Transpose, Settings, Scale, Chord Map, Arp, Fixed Chord, Track, workflow and transport buttons are drawn, not mapped; chord, scale and arp output follows the Chords Channel (default 3) and is not modelled. Port names: macOS "Launchkey MK4 37 MIDI" / "… DAW" (per the Novation Ableton article's "Launchkey MK4 61 MIDI/DAW" pattern and the Linux names above — not seen on a Mac for this model); Windows names the first interface "Launchkey 37 MIDI" and the DAW one "MIDIIN2 (LKMK4 MIDI)". The profile matches "Launchkey 37" with or without "MK4" in either order, and neither the Launchkey Mini 25/37 (MK3 or MK4), the other MK4 sizes, nor MK3 ports. No LED feedback. Faceplate proportions come from the published size (the printed 557 mm width is narrower than 22 white keys at the 25's key pitch would need, so the drawing follows the key count); unconfirmed on hardware.

Use it

Use Novation Launchkey 37 MK4 in your own work

  1. Embed it with one line

    No import map, no build step. Change layout, add hardware="ask" for a Connect button.

    html
    <script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="novation-launchkey-37-mk4" readout></oav-controller>

  2. Or as an iframe

    For places that only take an iframe. Every event arrives as a postMessage.

    html
    <iframe src="https://openaudiovisual.com/embed/controller/?profile=novation-launchkey-37-mk4&readout"
        width="720" height="311" style="border:0;max-width:100%" allow="midi"
        title="Novation Launchkey 37 MK4"></iframe>
<script>
  // every control the visitor plays arrives here
  addEventListener('message', (e) => {
    if (e.data?.source !== 'openav' || e.data.type !== 'control') return;
    console.log(e.data.detail.signal, e.data.detail.value);
  });
</script>

  3. Send it to Ableton, TouchDesigner or Resolume

    What you play on screen leaves as real MIDI on the IAC bus (macOS) or a loopMIDI port (Windows). The steps are on the catalog page.

    html
    <!-- what you play on this controller → the IAC bus (macOS) → Ableton, TouchDesigner, Resolume -->
<script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="novation-launchkey-37-mk4" midi-out="IAC" readout></oav-controller>
<!-- Windows: midi-out="loopMIDI" · let the visitor pick a port: midi-out="ask" -->

    macOS: Audio MIDI Setup → MIDI Studio → IAC Driver → “Device is online”. Windows: install loopMIDI and add a port; use midi-out="loopMIDI".

  circle(random(width), random(height), velocity * 100);
}
