Sources

  • manufacturer MIDImix User Guide v1.0 (AKAI)layout: 24 knobs (3 per channel), 8 mute buttons (amber-backlit; hold Solo to make them solo buttons), 8 record-arm buttons (red-backlit), 8 + 1 master faders, Bank Left / Right, Solo, Send All; Ableton Live control surface and port name "MIDI Mix"; 23.9 × 20.1 cm. It prints no MIDI numbers (the MIDImix Editor holds them).
  • community Ableton Live 12 MIDI Remote Script MIDI_Mix (decompiled; non-official)all on channel 1: knob rows CC 16 20 24 28 46 50 54 58 / +1 / +2 (the bottom row is pan), faders CC 19 23 27 31 49 53 57 61, master CC 62; mute notes 1 4 … 22, solo (Solo held) 2 5 … 23, rec arm 3 6 … 24; bank left 25, bank right 26, solo 27; LEDs note-on 127 / 0
  • community Ardour AKAI_MIDIMix_Normal_Mode.map and AKAI_MIDIMix_EQ_Mode.map (non-official)agree with the Ableton script: faders 19 … 61, master 62, mute / solo / rec notes 1–24, bank 25 / 26, solo 27, knobs 16–18 … 58–60 (EQ map), channel 1

Notes

The factory mapping (what the MIDImix Editor calls the default), channel 1. AKAI's own documents print no numbers, so every number here comes from Ableton's shipped MIDI_Mix script and Ardour's maps, which agree. Holding Solo turns the Mute row into solo buttons sending notes 2, 5 … 23 — a layer the faceplate cannot show, so those notes are not modelled (they still arrive as midi/ch/1/note/<n>). Send All re-sends every knob and fader position and has no message of its own. LED feedback: mute (amber) and rec-arm (red) buttons, note-on 127 / 0, lit while held.

Port names it recognises

matches
/midi\s*mix/i

Signals

Every control publishes midi/midimix/<control> (0..1), plus /raw; pads add /hit, encoders /delta, keys /on /off and n<note>; the last control touched is midi/midimix/last.

Use it

Use AKAI MIDImix in your own work

  1. Embed it with one line

    No import map, no build step. Change layout, add hardware="ask" for a Connect button.

    html
    <script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="akai-midimix" readout></oav-controller>

  2. Or as an iframe

    For places that only take an iframe. Every event arrives as a postMessage.

    html
    <iframe src="https://openaudiovisual.com/embed/controller/?profile=akai-midimix&readout"
        width="720" height="627" style="border:0;max-width:100%" allow="midi"
        title="AKAI MIDImix"></iframe>
<script>
  // every control the visitor plays arrives here
  addEventListener('message', (e) => {
    if (e.data?.source !== 'openav' || e.data.type !== 'control') return;
    console.log(e.data.detail.signal, e.data.detail.value);
  });
</script>

  3. Send it to Ableton, TouchDesigner or Resolume

    What you play on screen leaves as real MIDI on the IAC bus (macOS) or a loopMIDI port (Windows). The steps are on the catalog page.

    html
    <!-- what you play on this controller → the IAC bus (macOS) → Ableton, TouchDesigner, Resolume -->
<script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="akai-midimix" midi-out="IAC" readout></oav-controller>
<!-- Windows: midi-out="loopMIDI" · let the visitor pick a port: midi-out="ask" -->

    macOS: Audio MIDI Setup → MIDI Studio → IAC Driver → “Device is online”. Windows 11: the built-in Windows MIDI Services have a loopback (not tested by us); older Windows: install loopMIDI, add a port and use midi-out="loopMIDI".

In p5.js, with one line

The one-line injection names knobs, faders and pads by their order in this profile, the order of the table above. Add ?profile=akai-midimix to make the on-screen controller this one; a real AKAI MIDImix is recognised by its port name.

javascript
document.head.prepend(Object.assign(document.createElement('script'), { src: 'https://openaudiovisual.com/p5/oav-p5.js?profile=akai-midimix' }));
