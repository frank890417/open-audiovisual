Generic 49-key keyboard

Generic 49-key keyboard is a generic layout, not a product: 49 keys, 1 button and 2 wheels. Its messages are conventions rather than one maker's chart. Pick it for a controller that is not in the library, press Learn and move your controls in order.

Sources

  • convention open-audiovisual generic layoutKeys 36–84 on channel 1 (C2–C6, scientific pitch: 60 = C4), pitch bend, mod wheel CC 1, sustain CC 64 — the General MIDI conventions every keyboard follows. Keys catch any note on their channel, so octave shifts on the hardware just scroll the on-screen keys.

Port names it recognises

Generic layouts never match a port by themselves: assign one by hand, then learn.

Signals

Every control publishes midi/keys49/<control> (0..1), plus /raw; pads add /hit, encoders /delta, keys /on /off and n<note>; the last control touched is midi/keys49/last.

Use it

Use Generic 49-key keyboard in your own work

  1. Embed it with one line

    No import map, no build step. Change layout, add hardware="ask" for a Connect button.

    html
    <script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="generic-keys49" readout></oav-controller>

  2. Or as an iframe

    For places that only take an iframe. Every event arrives as a postMessage.

    html
    <iframe src="https://openaudiovisual.com/embed/controller/?profile=generic-keys49&readout"
        width="720" height="188" style="border:0;max-width:100%" allow="midi"
        title="Generic 49-key keyboard"></iframe>
<script>
  // every control the visitor plays arrives here
  addEventListener('message', (e) => {
    if (e.data?.source !== 'openav' || e.data.type !== 'control') return;
    console.log(e.data.detail.signal, e.data.detail.value);
  });
</script>

  3. Send it to Ableton, TouchDesigner or Resolume

    What you play on screen leaves as real MIDI on the IAC bus (macOS) or a loopMIDI port (Windows). The steps are on the catalog page.

    html
    <!-- what you play on this controller → the IAC bus (macOS) → Ableton, TouchDesigner, Resolume -->
<script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="generic-keys49" midi-out="IAC" readout></oav-controller>
<!-- Windows: midi-out="loopMIDI" · let the visitor pick a port: midi-out="ask" -->

    macOS: Audio MIDI Setup → MIDI Studio → IAC Driver → “Device is online”. Windows: install loopMIDI and add a port; use midi-out="loopMIDI".

In p5.js, with one line

The one-line injection names knobs, faders and pads by their order in this layout, the order of the table above. Add ?profile=generic-keys49 to make the on-screen controller this one.

javascript
document.head.prepend(Object.assign(document.createElement('script'), { src: 'https://openaudiovisual.com/p5/oav-p5.js?profile=generic-keys49' }));
In your sketchControlMessage
notePressed(note, velocity)36–84 (C2–C6)a key goes down
p5.js sketch
function draw() {
  background(20);
}

function notePressed(note, velocity) {   // a key goes down
  circle(random(width), random(height), velocity * 100);
}

Encoders, buttons, wheels and strips are not numbered: read them as midi.cc[number] in the table above, or react in controlChange(cc, value, ch).

This is a generic layout. Its numbering applies when you choose it as the on-screen controller; an unknown real controller numbers its knobs in the order you turn them.
