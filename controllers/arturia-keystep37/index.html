Arturia KeyStep 37

Arturia KeyStep 37 is a MIDI hardware controller by Arturia: 37 keys, 4 knobs, 1 button and 2 touch strips.

It sends Pitch bend, CC and Note on channel 1. The profile cites 2 sources. 41 of its controls are marked unverified: the number is our best reading, and Learn rebinds it in one move.

Notes

Channel 1 and lowest key C3 (48) are assumptions (the manual leaves the defaults to MIDI Control Center); the keys follow any note on the channel, so an octave shift on the unit just scrolls the on-screen keys. Knob banks 2–4 are not mapped. The original 32-key KeyStep has the same strips and pedal: use this profile or generic-keys25/49.

Signals

Every control publishes midi/keystep37/<control> (0..1), plus /raw; pads add /hit, encoders /delta, keys /on /off and n<note>; the last control touched is midi/keystep37/last.

Use it

Use Arturia KeyStep 37 in your own work

  1. Embed it with one line

    No import map, no build step. Change layout, add hardware="ask" for a Connect button.

    html
    <script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="arturia-keystep37" readout></oav-controller>

  2. Or as an iframe

    For places that only take an iframe. Every event arrives as a postMessage.

    html
    <iframe src="https://openaudiovisual.com/embed/controller/?profile=arturia-keystep37&readout"
        width="720" height="267" style="border:0;max-width:100%" allow="midi"
        title="Arturia KeyStep 37"></iframe>
<script>
  // every control the visitor plays arrives here
  addEventListener('message', (e) => {
    if (e.data?.source !== 'openav' || e.data.type !== 'control') return;
    console.log(e.data.detail.signal, e.data.detail.value);
  });
</script>

  3. Send it to Ableton, TouchDesigner or Resolume

    What you play on screen leaves as real MIDI on the IAC bus (macOS) or a loopMIDI port (Windows). The steps are on the catalog page.

    html
    <!-- what you play on this controller → the IAC bus (macOS) → Ableton, TouchDesigner, Resolume -->
<script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="arturia-keystep37" midi-out="IAC" readout></oav-controller>
<!-- Windows: midi-out="loopMIDI" · let the visitor pick a port: midi-out="ask" -->

    macOS: Audio MIDI Setup → MIDI Studio → IAC Driver → “Device is online”. Windows 11: the built-in Windows MIDI Services have a loopback (not tested by us); older Windows: install loopMIDI, add a port and use midi-out="loopMIDI".

In p5.js, with one line

The one-line injection names knobs, faders and pads by their order in this profile, the order of the table above. Add ?profile=arturia-keystep37 to make the on-screen controller this one; a real Arturia KeyStep 37 is recognised by its port name.

javascript
document.head.prepend(Object.assign(document.createElement('script'), { src: 'https://openaudiovisual.com/p5/oav-p5.js?profile=arturia-keystep37' }));

p5.js sketch
function draw() {
  background(knob1 * 255);   // 1 · CC 74
  circle(width / 2, height / 2, 50 + knob2 * 300);   // 2 · CC 71
}

function notePressed(note, velocity) {   // a key goes down
  circle(random(width), random(height), velocity * 100);
}

Encoders, buttons, wheels and strips are not numbered: read them as midi.cc[number] in the table above, or react in controlChange(cc, value, ch).
