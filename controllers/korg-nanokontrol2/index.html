LED feedback is modeled for 35 of its controls: the LED column says which message lights each one.

Sources

  • manufacturer nanoKONTROL2 Parameter Guide (KORG)button behaviour momentary/toggle; LED mode internal/external — external: an incoming CC assigned to a button lights its LED with the On value, the Off value turns it off
  • manufacturer nanoKONTROL2 MIDI Implementation (KORG)transport / marker numbers 41–46, 58–62
  • manufacturer nanoKONTROL2 Owner's Manual (KORG)CC mode: hold SET MARKER + CYCLE while connecting; ports 'nanoKONTROL2 SLIDER/KNOB' (in) and 'nanoKONTROL2 CTRL' (out)
  • community Ardour Korg_nanoKONTROL2.map (non-official)factory scene: faders CC 0–7, knobs 16–23, S 32–39, M 48–55, R 64–71, global channel 1

Notes

Factory scene, CC mode, global channel 1. LED feedback reaches the buttons only when LED mode is set to External in the KORG KONTROL Editor (default Internal: the unit lights its own buttons).

Port names it recognises

matches

prefers
/slider/i /knob/i /ctrl/i

Signals

Every control publishes midi/nano2/<control> (0..1), plus /raw; pads add /hit, encoders /delta, keys /on /off and n<note>; the last control touched is midi/nano2/last.

Use it

Use Korg nanoKONTROL2 in your own work

  1. Embed it with one line

    No import map, no build step. Change layout, add hardware="ask" for a Connect button.

    html
    <script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="korg-nanokontrol2" readout></oav-controller>

  2. Or as an iframe

    For places that only take an iframe. Every event arrives as a postMessage.

    html
    <iframe src="https://openaudiovisual.com/embed/controller/?profile=korg-nanokontrol2&readout"
        width="720" height="216" style="border:0;max-width:100%" allow="midi"
        title="Korg nanoKONTROL2"></iframe>
<script>
  // every control the visitor plays arrives here
  addEventListener('message', (e) => {
    if (e.data?.source !== 'openav' || e.data.type !== 'control') return;
    console.log(e.data.detail.signal, e.data.detail.value);
  });
</script>

  3. Send it to Ableton, TouchDesigner or Resolume

    What you play on screen leaves as real MIDI on the IAC bus (macOS) or a loopMIDI port (Windows). The steps are on the catalog page.

    html
    <!-- what you play on this controller → the IAC bus (macOS) → Ableton, TouchDesigner, Resolume -->
<script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="korg-nanokontrol2" midi-out="IAC" readout></oav-controller>
<!-- Windows: midi-out="loopMIDI" · let the visitor pick a port: midi-out="ask" -->

    macOS: Audio MIDI Setup → MIDI Studio → IAC Driver → “Device is online”. Windows 11: the built-in Windows MIDI Services have a loopback (not tested by us); older Windows: install loopMIDI, add a port and use midi-out="loopMIDI".

In p5.js, with one line

The one-line injection names knobs, faders and pads by their order in this profile, the order of the table above. Add ?profile=korg-nanokontrol2 to make the on-screen controller this one; a real Korg nanoKONTROL2 is recognised by its port name.

javascript
document.head.prepend(Object.assign(document.createElement('script'), { src: 'https://openaudiovisual.com/p5/oav-p5.js?profile=korg-nanokontrol2' }));
