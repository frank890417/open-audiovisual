DJ TechTools Midi Fighter Twister

DJ TechTools Midi Fighter Twister is a MIDI hardware controller by DJ TechTools: 16 encoders and 22 buttons.

It sends CC on channels 1, 2, 4. The profile cites 2 sources. 6 of its controls are marked unverified: the number is our best reading, and Learn rebinds it in one move.

LED feedback is modeled for 16 of its controls: the LED column says which message lights each one.

Notes on single controls

  • sidel1 Left side button 1 (top). Bank 1: CC 8 / note G#-1 on the system channel (4). The manual lists this number for a side button set to a MIDI function; which function the factory configuration gives it is not printed, so the number is the manual's, the default behaviour unconfirmed.
  • sidel2 Left side button 2 (middle). By default it decrements the bank (an internal action, no MIDI): the manual's Bank 1 table lists CC 9 / note A-1 for it only when the Utility makes it a MIDI button.
  • sidel3 Left side button 3 (bottom). Bank 1: CC 10 / note A#-1 on the system channel (4); factory function not printed.
  • sider1 Right side button 1 (top). Bank 1: CC 11 / note B-1 on the system channel (4); factory function not printed.
  • sider2 Right side button 2 (middle). By default it increments the bank (an internal action, no MIDI): the manual's Bank 1 table lists CC 12 / note C0 for it only when the Utility makes it a MIDI button.
  • sider3 Right side button 3 (bottom). Bank 1: CC 13 / note C#0 on the system channel (4); factory function not printed.

Notes

Models the factory configuration of the Midi Fighter Utility, Bank 1 of 4 (the unit starts on Bank 1; the middle side buttons change bank by default, an action that sends no CC). Each of the 16 encoders is two controls: the encoder (CC 0–15, channel 1, absolute 0–127) and its push switch (CC 0–15, channel 2, 127 while held, 0 on release). The encoder is endless in your hand but sends an absolute value by default. Switch an encoder to 'Enc 3FH/41H' in the Utility and it becomes relative: 65 for each clockwise step, 63 for each anti-clockwise one, which is relative "offset64" in this format (set it on the control or with learn). Banks 2–4 send encoders and switches on the same channels with CC 16–31, 32–47 and 48–63 (the v1.01 guide's bank 3 switch column skips CC 37; the encoder column does not), and the side buttons move up with the bank: none of that is modelled, and any encoder or switch you remap in the Utility leaves this table. LED feedback: send the push switch's own CC on channel 2 (value 0 = its inactive colour, 127 = its active colour, 1–126 a colour on the guide's scale) and the 11-LED ring follows a CC of the same number on channel 1: that is how a DAW or this page shows a parameter's value on the unit. Animations (strobe 1–8, pulse 9–16, rainbow 127) go to channel 3. The six side buttons send on channel 4; their numbers are the manual's but its factory function for them is not printed, so they are flagged. On the unit they sit on the left and right edges; here they are drawn beside the grid. Ring colours follow DJ TechTools' product image (a yellow-to-red gradient, row by row).

Signals

Every control publishes midi/twister/<control> (0..1), plus /raw; pads add /hit, encoders /delta, keys /on /off and n<note>; the last control touched is midi/twister/last.

Use it

Use DJ TechTools Midi Fighter Twister in your own work

  1. Embed it with one line

    No import map, no build step. Change layout, add hardware="ask" for a Connect button.

    html
    <script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="djtechtools-midi-fighter-twister" readout></oav-controller>

  2. Or as an iframe

    For places that only take an iframe. Every event arrives as a postMessage.

    html
    <iframe src="https://openaudiovisual.com/embed/controller/?profile=djtechtools-midi-fighter-twister&readout"
        width="720" height="656" style="border:0;max-width:100%" allow="midi"
        title="DJ TechTools Midi Fighter Twister"></iframe>
<script>
  // every control the visitor plays arrives here
  addEventListener('message', (e) => {
    if (e.data?.source !== 'openav' || e.data.type !== 'control') return;
    console.log(e.data.detail.signal, e.data.detail.value);
  });
</script>

  3. Send it to Ableton, TouchDesigner or Resolume

    What you play on screen leaves as real MIDI on the IAC bus (macOS) or a loopMIDI port (Windows). The steps are on the catalog page.

    html
    <!-- what you play on this controller → the IAC bus (macOS) → Ableton, TouchDesigner, Resolume -->
<script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="djtechtools-midi-fighter-twister" midi-out="IAC" readout></oav-controller>
<!-- Windows: midi-out="loopMIDI" · let the visitor pick a port: midi-out="ask" -->

    macOS: Audio MIDI Setup → MIDI Studio → IAC Driver → “Device is online”. Windows 11: the built-in Windows MIDI Services have a loopback (not tested by us); older Windows: install loopMIDI, add a port and use midi-out="loopMIDI".

In p5.js, with one line

The one-line injection names knobs, faders and pads by their order in this profile, the order of the table above. Add ?profile=djtechtools-midi-fighter-twister to make the on-screen controller this one; a real DJ TechTools Midi Fighter Twister is recognised by its port name.

javascript
document.head.prepend(Object.assign(document.createElement('script'), { src: 'https://openaudiovisual.com/p5/oav-p5.js?profile=djtechtools-midi-fighter-twister' }));
p5.js sketch
function draw() {
  background(20);
}

Encoders, buttons, wheels and strips are not numbered: read them as midi.cc[number] in the table above, or react in controlChange(cc, value, ch).
