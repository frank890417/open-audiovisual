Novation Launchpad Mini MK3

Novation Launchpad Mini MK3 is a MIDI hardware controller by Novation: 64 pads and 16 buttons.

It sends Note and CC on channel 1. The profile cites 3 sources. 8 of its controls are marked unverified: the number is our best reading, and Learn rebinds it in one move.

Where this profile comes from

Che-Yu Wu's TouchDesigner tool: MIDI In ch1 notes 36–99 in four groups of 16 (select1–4) = the four 4×4 drum racks; positions xy −4..−1 / 1..4 (skipping 0) or balanced −3.5..3.5; a stepped colour ramp gives each rack one colour (yellow, salmon red, lavender, green); idle pads drawn at ~16 % alpha, hit pads full colour with bloom; 'last event' (index + active) as the action output. TouchDesigner's MIDI In CHOP names channels 1-based (ch1ctrl75 = CC 74, ch10n37 = note 36); the numbers here are real MIDI numbers. LaunchPadMini_251209.tox

Notes

Use the device in Custom mode 1 (Drums). Entering Programmer mode needs SysEx (F0 00 20 29 02 0D 0E 01 F7), which stays off by default — Programmer-mode notes 11–88 are a different layout. What the right-column buttons send in Custom mode is undocumented (marked unverified; 學習 rebinds). LED colours are palette indices: the rack colours mirror the TD tool's ramp.

Signals

Every control publishes midi/lpmini/<control> (0..1), plus /raw; pads add /hit, encoders /delta, keys /on /off and n<note>; the last control touched is midi/lpmini/last.

Use it

Use Novation Launchpad Mini MK3 in your own work

  1. Embed it with one line

    No import map, no build step. Change layout, add hardware="ask" for a Connect button.

    html
    <script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="novation-launchpad-mini-mk3" readout></oav-controller>

  2. Or as an iframe

    For places that only take an iframe. Every event arrives as a postMessage.

    html
    <iframe src="https://openaudiovisual.com/embed/controller/?profile=novation-launchpad-mini-mk3&readout"
        width="720" height="742" style="border:0;max-width:100%" allow="midi"
        title="Novation Launchpad Mini MK3"></iframe>
<script>
  // every control the visitor plays arrives here
  addEventListener('message', (e) => {
    if (e.data?.source !== 'openav' || e.data.type !== 'control') return;
    console.log(e.data.detail.signal, e.data.detail.value);
  });
</script>

  3. Send it to Ableton, TouchDesigner or Resolume

    What you play on screen leaves as real MIDI on the IAC bus (macOS) or a loopMIDI port (Windows). The steps are on the catalog page.

    html
    <!-- what you play on this controller → the IAC bus (macOS) → Ableton, TouchDesigner, Resolume -->
<script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="novation-launchpad-mini-mk3" midi-out="IAC" readout></oav-controller>
<!-- Windows: midi-out="loopMIDI" · let the visitor pick a port: midi-out="ask" -->

    macOS: Audio MIDI Setup → MIDI Studio → IAC Driver → “Device is online”. Windows 11: the built-in Windows MIDI Services have a loopback (not tested by us); older Windows: install loopMIDI, add a port and use midi-out="loopMIDI".
