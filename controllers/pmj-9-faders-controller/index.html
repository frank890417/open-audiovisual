PMJ 9 Faders Controller

PMJ 9 Faders Controller is a MIDI hardware controller by PMJ: 9 faders.

It sends CC on channel 1. The profile cites 1 source. 9 of its controls are marked unverified: the number is our best reading, and Learn rebinds it in one move.

Notes

Imported from QLC+. The messages are what its community profile lists; nobody has checked them on a unit for this project, so every control is unverified. QLC+ has no faceplate data, so the layout was generated from the list of controls and does not look like the device. There is no port name to go by, so it is never picked automatically: assign it by hand. QLC+ numbers these controls without a MIDI channel, so channel 1 here is a placeholder: the unit may send on another.

Port names it recognises

Signals

Every control publishes midi/9faderscontroller/<control> (0..1), plus /raw; pads add /hit, encoders /delta, keys /on /off and n<note>; the last control touched is midi/9faderscontroller/last.

Use it

Use PMJ 9 Faders Controller in your own work

  1. Embed it with one line

    No import map, no build step. Change layout, add hardware="ask" for a Connect button.

    html
    <script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="pmj-9-faders-controller" readout></oav-controller>

  2. Or as an iframe

    For places that only take an iframe. Every event arrives as a postMessage.

    html
    <iframe src="https://openaudiovisual.com/embed/controller/?profile=pmj-9-faders-controller&readout"
        width="720" height="296" style="border:0;max-width:100%" allow="midi"
        title="PMJ 9 Faders Controller"></iframe>
<script>
  // every control the visitor plays arrives here
  addEventListener('message', (e) => {
    if (e.data?.source !== 'openav' || e.data.type !== 'control') return;
    console.log(e.data.detail.signal, e.data.detail.value);
  });
</script>

  3. Send it to Ableton, TouchDesigner or Resolume

    What you play on screen leaves as real MIDI on the IAC bus (macOS) or a loopMIDI port (Windows). The steps are on the catalog page.

    html
    <!-- what you play on this controller → the IAC bus (macOS) → Ableton, TouchDesigner, Resolume -->
<script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="pmj-9-faders-controller" midi-out="IAC" readout></oav-controller>
<!-- Windows: midi-out="loopMIDI" · let the visitor pick a port: midi-out="ask" -->

    macOS: Audio MIDI Setup → MIDI Studio → IAC Driver → “Device is online”. Windows 11: the built-in Windows MIDI Services have a loopback (not tested by us); older Windows: install loopMIDI, add a port and use midi-out="loopMIDI".

In p5.js, with one line

The one-line injection names knobs, faders and pads by their order in this profile, the order of the table above. Add ?profile=pmj-9-faders-controller to make the on-screen controller this one; a real PMJ 9 Faders Controller is recognised by its port name.

javascript
document.head.prepend(Object.assign(document.createElement('script'), { src: 'https://openaudiovisual.com/p5/oav-p5.js?profile=pmj-9-faders-controller' }));

Other software

Use this controller outside this project

The same data, as files other programs read. Nobody has tested these on this exact unit unless the table above says so.

QLC+

An input profile: every control and LED value, for lighting. Copy it to your user folder (macOS ~/Library/Application Support/QLC+/InputProfiles, Linux ~/.qlcplus/inputprofiles, Windows %USERPROFILE%\QLC+\InputProfiles) and restart QLC+.

pmj-9-faders-controller.qxi

Mixxx

A starting point, not a finished mapping: decks, EQ and hot cues go to the controls in order. Put both files in the folder that Preferences → Controllers → Open User Mapping Folder opens, then remap what you like with the Learning Wizard.
