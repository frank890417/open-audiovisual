AKAI LPD8 (mk2)

AKAI LPD8 (mk2) is a MIDI hardware controller by AKAI Professional: 8 pads and 8 knobs.

It sends Note and CC on channels 1, 10. The profile cites 4 sources. 8 of its controls are marked unverified: the number is our best reading, and Learn rebinds it in one move.

Where this profile comes from

Che-Yu Wu's TouchDesigner tool: MIDI In (Device ID + Active toggle) → select ch10n* → Pad1–8, select ch1ctrl* → K1–K8, math 0..127 → 0..1, bound both ways to custom parameters (Pads page: 8 momentary pulses, Knobs page: 8 floats) and to an 800×200 panel (pads left, knobs right). TouchDesigner's MIDI In CHOP names channels 1-based (ch1ctrl75 = CC 74, ch10n37 = note 36); the numbers here are real MIDI numbers. AKAI_LPD8.tox

Notes

Pad note numbers are the common program-1 layout (36–43) but not printed in the manual — pads are marked unverified; 學習 rebinds them in one tap each. The pads light themselves; no LED feedback is sent.

Port names it recognises

matches
/lpd\s*8/i

Signals

Every control publishes midi/lpd8/<control> (0..1), plus /raw; pads add /hit, encoders /delta, keys /on /off and n<note>; the last control touched is midi/lpd8/last.

Use it

Use AKAI LPD8 (mk2) in your own work

  1. Embed it with one line

    No import map, no build step. Change layout, add hardware="ask" for a Connect button.

    html
    <script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="akai-lpd8" readout></oav-controller>

  2. Or as an iframe

    For places that only take an iframe. Every event arrives as a postMessage.

    html
    <iframe src="https://openaudiovisual.com/embed/controller/?profile=akai-lpd8&readout"
        width="720" height="216" style="border:0;max-width:100%" allow="midi"
        title="AKAI LPD8 (mk2)"></iframe>
<script>
  // every control the visitor plays arrives here
  addEventListener('message', (e) => {
    if (e.data?.source !== 'openav' || e.data.type !== 'control') return;
    console.log(e.data.detail.signal, e.data.detail.value);
  });
</script>

  3. Send it to Ableton, TouchDesigner or Resolume

    What you play on screen leaves as real MIDI on the IAC bus (macOS) or a loopMIDI port (Windows). The steps are on the catalog page.

    html
    <!-- what you play on this controller → the IAC bus (macOS) → Ableton, TouchDesigner, Resolume -->
<script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="akai-lpd8" midi-out="IAC" readout></oav-controller>
<!-- Windows: midi-out="loopMIDI" · let the visitor pick a port: midi-out="ask" -->

    macOS: Audio MIDI Setup → MIDI Studio → IAC Driver → “Device is online”. Windows 11: the built-in Windows MIDI Services have a loopback (not tested by us); older Windows: install loopMIDI, add a port and use midi-out="loopMIDI".

In p5.js, with one line

The one-line injection names knobs, faders and pads by their order in this profile, the order of the table above. Add ?profile=akai-lpd8 to make the on-screen controller this one; a real AKAI LPD8 (mk2) is recognised by its port name.

javascript
document.head.prepend(Object.assign(document.createElement('script'), { src: 'https://openaudiovisual.com/p5/oav-p5.js?profile=akai-lpd8' }));
