Knobs send an absolute position; encoders turn without end and send steps. A dash means none. Unverified counts the controls whose number is our best reading.

“Good for” is assigned by a rule from the counts: keys → melody; 8 or more pads → triggers; 8 or more knobs or encoders → many parameters; 4 or more faders → mixing. It is a rule of thumb, not a review.

LED feedback

LED feedback is a controller lighting its own pads and buttons. A profile that models it says which note or CC lights each control and which values mean on and off. 8 of the 27 profiles have it:

  • AKAI APC mini mk2
  • AKAI MIDImix
  • AKAI APC40 mkII
  • DJ TechTools Midi Fighter Twister
  • Korg nanoKONTROL2
  • Novation Launchpad Mini MK3
  • Novation Launch Control XL (MK2)
  • Novation Launchpad Pro MK3

When one of them is plugged in, OAV sends those messages to its output port as a control changes, and once when the device connects, so the lights can follow what happens on screen.

The other 19 have no LED messages in their profile yet: OAV does not light them, but every control still plays and sends its message. A profile takes an led entry on each control.

The last event, as your code receives it

Play the preview: its control event appears here.

  1. One line, any page

    No import map, no build step. Shadow DOM keeps your page's CSS out and the controller's CSS in.

    html
    <script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="akai-lpd8" readout></oav-controller>

  2. An iframe

    For places that only take an iframe. Every event arrives as a postMessage; you can send set and ingest back.

    html
    <iframe src="https://openaudiovisual.com/embed/controller/?profile=akai-lpd8&readout"
        width="720" height="216" style="border:0;max-width:100%" allow="midi"
        title="AKAI LPD8 (mk2)"></iframe>
<script>
  // every control the visitor plays arrives here
  addEventListener('message', (e) => {
    if (e.data?.source !== 'openav' || e.data.type !== 'control') return;
    console.log(e.data.detail.signal, e.data.detail.value);
  });
</script>

  3. JavaScript, any framework

    createController() is the element without the element: React, Vue, Svelte or plain. It works headless, with no faceplate at all.

    javascript
    import { createController } from 'https://openaudiovisual.com/packages/midi/index.js';

const ctl = createController('akai-lpd8');
ctl.mount(document.querySelector('#controller'));   // optional: headless works too
ctl.on('control', (e) => console.log(e.signal, e.value));
ctl.connectHardware();   // optional: follow the real one (asks for Web MIDI)

  4. Listen to it

    Events bubble and cross the shadow root. Each payload is plain JSON: the control, its value, its signal name, the MIDI message and the bytes.

    javascript
    const el = document.querySelector('oav-controller');
el.addEventListener('control', (e) => {
  const { id, value, signal, message, source } = e.detail;
  // 'k1'  0..1  'midi/lpd8/k1'  { type: 'cc', ch: 1, cc: 70, value: 64 }  'ui' | 'hardware'
});
el.addEventListener('noteon', (e) => console.log(e.detail.note, e.detail.velocity));

await el.ready;
el.set('k1', 0.5);              // move a control: fires 'control', reaches MIDI out
el.set('pad1', 1); el.set('pad1', 0);   // strike and release
el.ingest([0xb0, 70, 64]);   // MIDI from anywhere (a WebSocket, another tab)

  5. Play your DAW with it

    What you play on screen leaves as real MIDI, into Ableton Live, TouchDesigner, Resolume or any software that takes a MIDI input.

    html
    <!-- what you play on this controller → the IAC bus (macOS) → Ableton, TouchDesigner, Resolume -->
<script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="akai-lpd8" midi-out="IAC" readout></oav-controller>
<!-- Windows: midi-out="loopMIDI" · let the visitor pick a port: midi-out="ask" -->

MIDI out to Ableton, TouchDesigner, Resolume

  1. macOS: open Audio MIDI Setup → Window → Show MIDI Studio, double-click IAC Driver, tick “Device is online”.
  2. Windows: install loopMIDI and add a port.
  3. Ableton Live: Settings → Link, Tempo & MIDI → turn on Track and Remote for the IAC or loopMIDI input. TouchDesigner: a MIDI In CHOP on that device. Resolume: Preferences → MIDI.

Web MIDI works in Chrome and Edge, and in Firefox after it asks you to allow the site. Safari and iPad have none: the controller still plays and fires every event, and MIDI out reports that it is unavailable.

No feedback loops: the engine never listens to IAC inputs, the element mutes any input with the same name as its output (the loopMIDI echo), and moves from your real hardware are not forwarded, because your software already hears the device.

Usage stats: each embed sends one anonymous hit per page load (which kind, which controller, the page’s origin; no cookies, nothing you play). telemetry="off" turns it off. What exactly is sent.

iframe messages

The iframe posts every event to its parent and accepts a few commands back. Add &frame=name to tell several iframes apart, and &origin=https://your.site to talk to your page only.

postMessage
// iframe → your page, for every event
{ source: 'openav', v: 1, type: 'control', frame: 'pads',
  detail: { id, type, value, raw, signal, message, bytes, source } }
// type: ready · control · noteon · noteoff · connect · disconnect · status · profilechange · error

// your page → iframe
const win = document.querySelector('iframe').contentWindow;
win.postMessage({ target: 'openav', type: 'set', id: 'k1', value: 0.5 }, '*');
win.postMessage({ target: 'openav', type: 'ingest', bytes: [0xb0, 70, 64] }, '*');
win.postMessage({ target: 'openav', type: 'get' }, '*');   // answers with type 'values'
// also: press · release · reset · profile · layout

06 · Model yours

Add your controller

A profile is one JSON file. If the manual has a MIDI implementation chart, the profile can be exact; if it does not, say so in the file.

  1. Start from the closest file Copy a device that looks like yours, or a generic layout. The faceplate is sections on a grid in face units, so the screen version looks like the desk.
  2. Write down what each control sends Type, message (cc, note, pitchbend), channel, number. Encoders name their relative mode; buttons say momentary or toggle; LEDs say what lights them.
  3. Cite every number Each source has a title, a link and what it confirmed. A number nobody has checked gets "verified": false and a note.
  4. Validate validateProfile() returns every problem in words, or an empty list. The test suite runs it on every shipped profile.
  5. Try it before you send it <oav-controller profile="./my-pads.json"> loads a profile from a URL, so you can play your file on your own page first.
  6. Open a pull request Put the file in packages/midi/profiles/ and add it to profiles/index.js. Tell us which unit and firmware you checked it on.

A profile, in short

packages/midi/profiles/my-pads.json
{
  "id": "my-pads", "short": "mypads", "name": "My Pads", "maker": "…", "kind": "device",
  "match": { "ports": ["my\\s*pads"] },
  "sources": [{ "title": "My Pads manual, MIDI implementation chart", "url": "https://…",
                "note": "pads: notes 36–43 on channel 10" }],
  "face": { "w": 100, "h": 30, "label": "MY PADS" },
  "sections": [{ "id": "pads", "x": 2, "y": 4, "w": 60, "h": 24, "cols": 4, "rows": 2,
                 "controls": ["pad1", "pad2", "…"] }],
  "controls": [
    { "id": "pad1", "type": "pad", "msg": "note", "ch": 10, "note": 36, "label": "1" },
    { "id": "k1", "type": "knob", "msg": "cc", "cc": 70, "label": "K1",
      "verified": false, "note": "default not printed in the manual" }
  ]
}

Check it

check.mjs
// check.mjs — run: node check.mjs
import { validateProfile } from './packages/midi/profiles.js';
import p from './packages/midi/profiles/my-pads.json' with { type: 'json' };

console.log(validateProfile(p));   // [] = valid; otherwise every problem, in words

TypeSendsSignal value
knob · faderCC, absolute 0–1270..1
encoderCC, relative (offset64, offset16, twos, signbit)position 0..1, plus /delta steps

No manual? Learn it

Choose a generic layout, press Learn, and move your controls in order: the layout fills itself with your device's messages. exportMapping() gives you the result as JSON, the start of a real profile.
