Use it

American DJ XS 400 in your code

Paste it into a <script type="module"> on any page: it loads @openav/devices and @openav/dmx from this site, patches the light at address 1 in mode 18ch and prints the bytes it would send. Send them with dmxTransport() (Art-Net or sACN through the out-bridge, or an Enttec DMX USB Pro by Web Serial).

javascript
import { device } from 'https://openaudiovisual.com/packages/devices/index.js';
import { Patch, DmxEngine } from 'https://openaudiovisual.com/packages/dmx/index.js';

const light = await device('american-dj-xs-400');   // American DJ XS 400
const patch = new Patch();
light.patch(patch, { id: 'light1', address: 1, mode: '18ch' });   // 18 channels from address 1
const engine = new DmxEngine(patch);
engine.set('light1', { dimmer: 1, color: [1, 0.5, 0], pan: 0.5, tilt: 0.25 });
console.log(engine.render(0).bytes(1).slice(0, 18).join(' '));
// → 128 0 64 0 0 0 255 128 0 0 0 0 255 0 0 0 0 255

It prints the channels of mode 18ch, in order:

  1. pan 128
  2. panFine 0
  3. tilt 64
  4. tiltFine 0

  6. tiltContinuousRotationSpeed 0
  7. red 255
