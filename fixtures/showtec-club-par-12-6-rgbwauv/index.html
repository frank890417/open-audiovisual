Use it

Showtec Club Par 12/6 RGBWAUV in your code

Paste it into a <script type="module"> on any page: it loads @openav/devices and @openav/dmx from this site, patches the light at address 1 in mode 11ch and prints the bytes it would send. Send them with dmxTransport() (Art-Net or sACN through the out-bridge, or an Enttec DMX USB Pro by Web Serial).

javascript
import { device } from 'https://openaudiovisual.com/packages/devices/index.js';
import { Patch, DmxEngine } from 'https://openaudiovisual.com/packages/dmx/index.js';

const light = await device('showtec-club-par-12-6-rgbwauv');   // Showtec Club Par 12/6 RGBWAUV
const patch = new Patch();
light.patch(patch, { id: 'light1', address: 1, mode: '11ch' });   // 11 channels from address 1
const engine = new DmxEngine(patch);
engine.set('light1', { dimmer: 1, color: [1, 0.5, 0] });
console.log(engine.render(0).bytes(1).slice(0, 11).join(' '));
// → 255 0 0 0 255 0 0 0 0 0 0

It prints the channels of mode 11ch, in order:

  1. dimmer 255
  2. red 0
  3. green 0
  4. blue 0
  5. amber 255
  6. white 0
  7. uV 0
  8. strobe 0
  9. program 0
  10. programSpeed 0
  11. programDuration 0
