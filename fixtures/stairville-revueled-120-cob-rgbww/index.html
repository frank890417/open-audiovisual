Use it

Stairville RevueLED 120 COB RGBWW in your code

Paste it into a <script type="module"> on any page: it loads @openav/devices and @openav/dmx from this site, patches the light at address 1 in mode 7ch and prints the bytes it would send. Send them with dmxTransport() (Art-Net or sACN through the out-bridge, or an Enttec DMX USB Pro by Web Serial).

javascript
import { device } from 'https://openaudiovisual.com/packages/devices/index.js';
import { Patch, DmxEngine } from 'https://openaudiovisual.com/packages/dmx/index.js';

const light = await device('stairville-revueled-120-cob-rgbww');   // Stairville RevueLED 120 COB RGBWW
const patch = new Patch();
light.patch(patch, { id: 'light1', address: 1, mode: '7ch' });   // 7 channels from address 1
const engine = new DmxEngine(patch);
engine.set('light1', { dimmer: 1, color: [1, 0.5, 0] });
console.log(engine.render(0).bytes(1).slice(0, 7).join(' '));
// → 255 128 0 0 255 0 0

It prints the channels of mode 7ch, in order:

  1. red 255
  2. green 128
  3. blue 0
  4. warmWhite 0
  5. dimmer 255
  6. strobe 0
  7. autoPrograms 0
