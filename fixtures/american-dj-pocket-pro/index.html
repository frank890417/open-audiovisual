Use it

American DJ Pocket Pro in your code

Paste it into a <script type="module"> on any page: it loads @openav/devices and @openav/dmx from this site, patches the light at address 1 in mode 13ch and prints the bytes it would send. Send them with dmxTransport() (Art-Net or sACN through the out-bridge, or an Enttec DMX USB Pro by Web Serial).

javascript
import { device } from 'https://openaudiovisual.com/packages/devices/index.js';
import { Patch, DmxEngine } from 'https://openaudiovisual.com/packages/dmx/index.js';

const light = await device('american-dj-pocket-pro');   // American DJ Pocket Pro
const patch = new Patch();
light.patch(patch, { id: 'light1', address: 1, mode: '13ch' });   // 13 channels from address 1
const engine = new DmxEngine(patch);
engine.set('light1', { dimmer: 1, pan: 0.5, tilt: 0.25 });
console.log(engine.render(0).bytes(1).slice(0, 13).join(' '));
// → 128 0 64 0 0 0 8 255 0 0 0 0 0

It prints the channels of mode 13ch, in order:

  1. pan 128
  2. panFine 0
  3. tilt 64
  4. tiltFine 0
  5. colorWheel 0
  6. goboWheel 0
  7. shutter 8
  8. dimmer 255
  9. panTiltMacros 0
  10. panTiltMacroSpeed 0
  11. dimmerCurves 0
  12. panTiltSpeed 0
  13. specialFunctions 0
