Use it

Eurolite LED 7C-7 Silent Slim in your code

Paste it into a <script type="module"> on any page: it loads @openav/devices and @openav/dmx from this site, patches the light at address 1 in mode 12ch and prints the bytes it would send. Send them with dmxTransport() (Art-Net or sACN through the out-bridge, or an Enttec DMX USB Pro by Web Serial).

javascript
import { device } from 'https://openaudiovisual.com/packages/devices/index.js';
import { Patch, DmxEngine } from 'https://openaudiovisual.com/packages/dmx/index.js';

const light = await device('eurolite-led-7c-7-silent-slim');   // Eurolite LED 7C-7 Silent Slim
const patch = new Patch();
light.patch(patch, { id: 'light1', address: 1, mode: '12ch' });   // 12 channels from address 1
const engine = new DmxEngine(patch);
engine.set('light1', { dimmer: 1, color: [1, 0.5, 0] });
console.log(engine.render(0).bytes(1).slice(0, 12).join(' '));
// → 255 0 0 0 0 0 0 255 0 0 0 0

It prints the channels of mode 12ch, in order:

  1. masterDimmer 255
  2. strobeEffect 0
  3. red 0
  4. green 0
  5. blue 0
  6. coldWhite 0
  7. warmWhite 0
  8. amber 255
  9. uV 0
  10. presetColors 0
  11. internalPrograms 0
  12. colorTemperature 0
