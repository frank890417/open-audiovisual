Use it

Generic Dimmer in your code

Paste it into a <script type="module"> on any page: it loads @openav/devices and @openav/dmx from this site, patches the light at address 1 in mode 1ch and prints the bytes it would send. Send them with dmxTransport() (Art-Net or sACN through the out-bridge, or an Enttec DMX USB Pro by Web Serial).

javascript
import { device } from 'https://openaudiovisual.com/packages/devices/index.js';
import { Patch, DmxEngine } from 'https://openaudiovisual.com/packages/dmx/index.js';

const light = await device('generic-dimmer');   // Generic Dimmer
const patch = new Patch();
light.patch(patch, { id: 'light1', address: 1, mode: '1ch' });   // 1 channel from address 1
const engine = new DmxEngine(patch);
engine.set('light1', { dimmer: 1 });
console.log(engine.render(0).bytes(1).slice(0, 1).join(' '));
// → 255

It prints the channels of mode 1ch, in order:

  1. dimmer 255
