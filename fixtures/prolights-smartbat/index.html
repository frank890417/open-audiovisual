Use it

Prolights SMARTBAT in your code

Paste it into a <script type="module"> on any page: it loads @openav/devices and @openav/dmx from this site, patches the light at address 1 in mode 10ch and prints the bytes it would send. Send them with dmxTransport() (Art-Net or sACN through the out-bridge, or an Enttec DMX USB Pro by Web Serial).

javascript
import { device } from 'https://openaudiovisual.com/packages/devices/index.js';
import { Patch, DmxEngine } from 'https://openaudiovisual.com/packages/dmx/index.js';

const light = await device('prolights-smartbat');   // Prolights SMARTBAT
const patch = new Patch();
light.patch(patch, { id: 'light1', address: 1, mode: '10ch' });   // 10 channels from address 1
const engine = new DmxEngine(patch);
engine.set('light1', { dimmer: 1, color: [1, 0.5, 0] });
console.log(engine.render(0).bytes(1).slice(0, 10).join(' '));
// → 255 255 128 0 0 0 0 0 0 0

It prints the channels of mode 10ch, in order:

  1. dimmer 255
  2. red 255
  3. green 128
  4. blue 0
  5. white 0
  6. colorPresetsTemperature 0
  7. strobe 0
  8. autoSoundPrograms 0
  9. autoSpeed 0
  10. dimmerSpeed 0
