Setup

Set it up

  1. For DDP, give the out-bridge a ddp route to the WLED's address: { "match": "light/*", "sink": "ddp", "host": "192.168.1.50", "port": 4048, "pixels": 60 }; light/<i>/r|g|b, 0..1, is pixel i from 0. open-audiovisual: packages/out README (the ddp sink, its config, WLED's fallback)
  2. For Art-Net or E1.31 instead, switch WLED to that mode in its Sync settings and reboot it once, then send through the out-bridge's artnet or sacn sink. WLED Knowledge Base: E1.31 (DMX) / Art-Net

Known problems

  • WLED goes back to its own effect about 2.5 s after the last DDP packet, on top of the bridge's watchdog: a page that stops sending loses the strip. open-audiovisual: packages/out README (the ddp sink, its config, WLED's fallback)
  • Two senders at the same E1.31 priority are not merged: one page and a lighting desk on one strip fight. WLED Knowledge Base: E1.31 (DMX) / Art-Net

Use it

WLED in your code

Paste it into a <script type="module"> on any page: it loads the packages from this site. It asks for nothing until you press the button it adds.

javascript
import { device } from 'https://openaudiovisual.com/packages/devices/index.js';
import { OutClient } from 'https://openaudiovisual.com/packages/out/client.js';

const strip = await device('wled');   // WLED
console.log(strip.record.use.map((u) => `${u.package} ${u.sink}`).join(', '));
// → @openav/out ddp, @openav/dmx artnet
const button = document.body.appendChild(Object.assign(document.createElement('button'), { textContent: "Pixel 0 red" }));
button.onclick = () => new OutClient({ url: 'ws://127.0.0.1:6450/out' }).connect().set('light/0/r', 1);   // through the out-bridge, out.json below

What reaches it

  • @openav/out · OutClient · sink ddp

    new OutClient({ url: 'ws://127.0.0.1:6450/out' }).connect().set('light/0/r', 1)

    Page values go to the out-bridge, whose ddp sink packs light/<i>/r|g|b into DDP for the strip, at most 60 times a second, with a watchdog.

  • @openav/dmx · dmxTransport · sink artnet

    dmxTransport('bridge', { patch, client })

    Patched as RGB fixtures, the strip takes the DMX engine's looks through the out-bridge's artnet (or sacn) sink, with the flash cap.
