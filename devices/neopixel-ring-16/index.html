Notes

The library writes its notes in Chinese; they are shown as written.

  • 產品頁寫「5VDC（4–7V works）」，但燈珠規格書上限 5.3 V，這裡照規格書。外徑 44.5 mm、內徑 31.7 mm。
  • 資料線靠近第一顆燈那端串一顆 300–500 Ω 電阻，電源正負之間並一顆 500–1000 µF（6.3 V 以上）電容（Adafruit NeoPixel Überguide）。
  • 用 LiPo 直接以 3.7 V 供電時，3.3 V 的資料訊號可以用；用 5 V 供電、3.3 V 板子推時，要加電平轉換（74AHCT125 或 74HCT245）（Adafruit NeoPixel Überguide）。

Use it

Adafruit NeoPixel Ring 16 (1463) in your code

Paste it into a <script type="module"> on any page: it loads @openav/devices from this site and prints the library entry Hw.check() reads.

javascript
import { device } from 'https://openaudiovisual.com/packages/devices/index.js';

const part = await device('neopixel-ring-16');   // Adafruit NeoPixel Ring 16 (1463)
console.log(JSON.stringify(part.part.supply), Object.keys(part.part.pins).join(' '));
// → {"min":3.7,"max":5.3,"nominal":5} VDD GND DIN DOUT

What reaches it

  • @openav/hw · Hw

    Hw.check({ board, parts: { x: { part: 'neopixel-ring-16' } }, wires })

    Listed in a spec's parts, it is checked with the rest of the wiring: voltages, pins, current.
