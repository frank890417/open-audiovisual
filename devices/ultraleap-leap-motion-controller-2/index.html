Setup

Set it up

  1. Install Ultraleap Hand Tracking (Gemini 5.x) and plug the sensor in; "/Applications/Ultraleap Hand Tracking.app/Contents/bin/leapctl" devices should list it with Tracking: true. open-audiovisual: packages/leap README (setup on macOS, the bridge)
  2. Install the Xcode command line tools (clang): the bridge compiles its small C reader on first start. open-audiovisual: packages/leap README (setup on macOS, the bridge)
  3. Run the bridge, node packages/leap/bridge/leap-bridge.mjs, and check http://127.0.0.1:6437/health; install.sh keeps it running at login. open-audiovisual: packages/leap README (setup on macOS, the bridge)

Known problems

  • A page on a public https site that reaches the bridge on this machine meets Chrome's local network prompt; blocked, it fails with net::ERR_BLOCKED_BY_LOCAL_NETWORK_ACCESS_CHECKS. Allow it, or open the page from localhost. open-audiovisual handbook: Troubleshooting, Chrome asks about the local network, or about apps on this device

Use it

Ultraleap Leap Motion Controller 2 in your code

Paste it into a <script type="module"> on any page: it loads the packages from this site. It asks for nothing until you press the button it adds.

javascript
import { device } from 'https://openaudiovisual.com/packages/devices/index.js';
import { Signals } from 'https://openaudiovisual.com/packages/core/index.js';
import { LeapInput } from 'https://openaudiovisual.com/packages/leap/index.js';

const leap = await device('ultraleap-leap-motion-controller-2');   // Ultraleap Leap Motion Controller 2
console.log(leap.record.use.map((u) => u.package).join(' '));
// → @openav/leap
const signals = new Signals();
const button = document.body.appendChild(Object.assign(document.createElement('button'), { textContent: "Connect the Leap bridge" }));
button.onclick = () => new LeapInput({ signals }).connect();   // the bridge on this computer: see Setup

What reaches it

  • @openav/leap · LeapInput

    new LeapInput({ signals }).connect()

    Through the local bridge, both hands become leap/hand/<side>/… signals (palm position, pinch, grab, angles, fingertips), and leap.hands has the joints for drawing.
