Notes

The library writes its notes in Chinese; they are shown as written.

  • GPIO 全部 3.3 V，不耐 5 V（Espressif FAQ：「ESP8266 is not 5 V tolerant」，GPIO 上限 3.6 V）。
  • gpio0 開機時被拉低就會進燒錄模式；板上紅色 LED 接在這支腳（低電位亮）。
  • gpio2 開機時必須是高電位（板上 10K 上拉）。進燒錄模式時 ROM 會把 GPIO2 設成輸出並送出 UART 訊號（esptool 文件），燒錄或重開機那一下接在這裡的東西會收到雜訊；ESP 模組上的藍色 LED 也在這支腳。
  • gpio15 開機時必須是低電位（板上 4.7K 下拉）；接的東西不能在開機時把它拉高，否則不會執行程式。
  • tx TX 是 USB 序列埠的線，開機時 ROM 會從這裡印出開機訊息（74880 baud）；開機時不能被拉低。
  • rx RX 是 USB 序列埠的線，接了別的東西可能燒錄失敗。

Use it

Adafruit Feather HUZZAH with ESP8266 (2821) in your code

Paste it into a <script type="module"> on any page: it loads @openav/devices from this site and prints the library entry Hw.check() reads.

javascript
import { device } from 'https://openaudiovisual.com/packages/devices/index.js';

const part = await device('feather-huzzah-esp8266');   // Adafruit Feather HUZZAH with ESP8266 (2821)
console.log(JSON.stringify(part.part.supply), Object.keys(part.part.pins).join(' '));
// → null 0 2 4 5 12 13 14 15 16 3V USB BAT EN RST GND A0 TX RX

What reaches it

  • @openav/hw · Hw

    Hw.check({ board, parts: { x: { part: 'feather-huzzah-esp8266' } }, wires })

    Listed in a spec's parts, it is checked with the rest of the wiring: voltages, pins, current.

Status

How sure this page is

Not checked on a unit yet: every value is as its source says. Only a person with the unit can change that.

To be confirmed

  • Adafruit 說 RX 有電平轉換、可接 5 V，但三版線路圖都只看到 1K 串聯電阻：當成只能 3.3 V。
  • 充電電流：Adafruit 寫 100 mA；rev G 線路圖的設定電阻推算約 213 mA。
  • GPIO2 藍色 LED 的極性。
  • 整塊板子深度睡眠時的電流（晶片本身 20 µA，穩壓器、CP2104、充電 IC 另計）。
  • 尖峰電流：規格書只給 Wi-Fi 傳送時的典型值 170 mA（這裡拿它當最大值）；Espressif FAQ 建議電源能給 500 mA 以上。
