Setup

Set it up

  1. Plug it into a USB-C port that supports USB 3.0. It works as a basic UVC webcam; Logitech's software (Logi Options+, G HUB) adds its settings. Logitech Support: Specification, MX BRIO
  2. The page must be on https or localhost and start the camera from a click; on macOS the browser needs camera access in System Settings → Privacy & Security. open-audiovisual handbook: Troubleshooting, the camera or microphone does not start

Known problems

  • Browsers hide camera labels until the page has had camera permission once, so before that the MX Brio cannot be told apart from another camera by name; open() asks first, then looks again. open-audiovisual: @openav/record, camera.js (ideal, never exact, sizes; labels hidden until permission)

Use it

Logitech MX Brio in your code

Paste it into a <script type="module"> on any page: it loads the packages from this site. It asks for nothing until you press the button it adds.

javascript
import { device } from 'https://openaudiovisual.com/packages/devices/index.js';

const cam = await device('logitech-mx-brio');   // Logitech MX Brio
console.log(JSON.stringify(cam.constraints()));
// → {"video":{"width":{"ideal":1920},"height":{"ideal":1080},"frameRate":{"ideal":60}},"audio":false}
const video = document.body.appendChild(Object.assign(document.createElement('video'), { autoplay: true, muted: true, playsInline: true }));
const button = document.body.appendChild(Object.assign(document.createElement('button'), { textContent: "Logitech MX Brio" }));
button.onclick = async () => {
  video.srcObject = await cam.open();   // asks once, finds it by its name, opens it
};

What reaches it

  • @openav/devices · device

    const stream = await (await device('logitech-mx-brio')).open()

    Finds the MX Brio among the cameras by its label and opens it at 1920×1080, 60 fps as ideal values, only when called.
