驗證控制器

用你的機器核對資料

這個資料庫大多來自說明書。數字對不對，要有人在實機上動過那個控制才算數。只要一個人、一台機器，幾分鐘就夠。

  1. 選型號，接上機器。
  2. 頁面一格一格亮起，亮到哪裡就動哪裡。
  3. 對上的打勾，對不上的會列出兩邊的值和修正方式。
  4. 下載更新過的 JSON，或開 issue、pull request 送回來。

要開 pull request：複製 JSON，到 GitHub 開啟檔案，貼上蓋掉舊內容，按 Propose changes，GitHub 會幫你 fork。要開 issue：連結會填好報告，再把 JSON 附上或貼上。

標記是什麼意思

實機驗過
有人在實機上動過這個控制項，訊息也對得上。檔案會寫明誰、哪一天、什麼韌體、作業系統和瀏覽器。
來自出處
數字來自註明的說明書或工具，還沒有人在實機上確認。
未確認
這是我們最好的判讀，備註會寫原因。

用虛擬埠或模擬驗證，只能說明這一頁會動，不能說明機器是這樣，所以永遠不會把控制項標成已驗證。格式寫在套件 README ↗。
