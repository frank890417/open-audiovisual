Korg nanoKONTROL2

Korg nanoKONTROL2 是 KORG 的 MIDI 硬體控制器：8 顆旋鈕、8 支推桿、35 顆按鈕。

它在 頻道 1 送出 CC，設定檔引用了 4 份出處。 沒有任何控制項被標為未確認。

這一台有 35 個控制項寫了 LED 回饋，上面表格的 LED 欄就是讓它亮的訊息。

出處

  • 原廠 nanoKONTROL2 Parameter Guide (KORG)button behaviour momentary/toggle; LED mode internal/external — external: an incoming CC assigned to a button lights its LED with the On value, the Off value turns it off
  • 原廠 nanoKONTROL2 MIDI Implementation (KORG)transport / marker numbers 41–46, 58–62
  • 原廠 nanoKONTROL2 Owner's Manual (KORG)CC mode: hold SET MARKER + CYCLE while connecting; ports 'nanoKONTROL2 SLIDER/KNOB' (in) and 'nanoKONTROL2 CTRL' (out)
  • 社群 Ardour Korg_nanoKONTROL2.map (non-official)factory scene: faders CC 0–7, knobs 16–23, S 32–39, M 48–55, R 64–71, global channel 1

說明

Factory scene, CC mode, global channel 1. LED feedback reaches the buttons only when LED mode is set to External in the KORG KONTROL Editor (default Internal: the unit lights its own buttons).

認得的埠名稱

比對
/nanokontrol\s*2/i
優先
/slider/i /knob/i /ctrl/i

訊號

每個控制項都會發出 midi/nano2/<控制項>（0..1）和 /raw。打擊墊多一個 /hit，無段旋鈕多 /delta，琴鍵有 /on、/off 和 n<音高>。最後動到的那個控制項是 midi/nano2/last。

用起來

把 Korg nanoKONTROL2 用在你的作品裡

  1. 一行嵌入

    不用 import map，也不用建置。可以改 layout，加上 hardware="ask" 就有「接上」按鈕。

    html
    <script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="korg-nanokontrol2" readout></oav-controller>

  2. 或用 iframe

    給只能貼 iframe 的地方。每個事件都以 postMessage 傳回來。

    html
    <iframe src="https://openaudiovisual.com/embed/controller/?profile=korg-nanokontrol2&readout"
        width="720" height="216" style="border:0;max-width:100%" allow="midi"
        title="Korg nanoKONTROL2"></iframe>
<script>
  // every control the visitor plays arrives here
  addEventListener('message', (e) => {
    if (e.data?.source !== 'openav' || e.data.type !== 'control') return;
    console.log(e.data.detail.signal, e.data.detail.value);
  });
</script>

  3. 送進 Ableton、TouchDesigner、Resolume

    你在畫面上彈的，會變成真正的 MIDI，從 macOS 的 IAC 匯流排或 Windows 的 loopMIDI 埠送出。步驟在圖鑑頁。

    html
    <!-- what you play on this controller → the IAC bus (macOS) → Ableton, TouchDesigner, Resolume -->
<script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="korg-nanokontrol2" midi-out="IAC" readout></oav-controller>
<!-- Windows: midi-out="loopMIDI" · let the visitor pick a port: midi-out="ask" -->

    macOS：音訊 MIDI 設定 → MIDI 工作室 → IAC 驅動程式 → 勾「裝置在線上」。Windows 11：內建的 Windows MIDI Services 有 loopback（我們沒有實測）；舊版 Windows：安裝 loopMIDI、新增一個埠，用 midi-out="loopMIDI"。

在 p5.js 裡，只要一行

一行注入會依這份設定檔裡的順序（也就是上面表格的順序）替旋鈕、推桿和打擊墊編號。網址加上 ?profile=korg-nanokontrol2，畫面上的控制器就是這一台；真的 Korg nanoKONTROL2 接上時，會依埠名稱自動認出來。

javascript
document.head.prepend(Object.assign(document.createElement('script'), { src: 'https://openaudiovisual.com/p5/oav-p5.js?profile=korg-nanokontrol2' }));
