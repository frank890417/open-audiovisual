Novation Launch Control XL 3

Novation Launch Control XL 3 是 Novation 的 MIDI 硬體控制器：24 顆無段旋鈕、8 支推桿、16 顆按鈕。

它在 頻道 16 送出 CC，設定檔引用了 7 份出處。 沒有任何控制項被標為未確認。

說明

Mode 16, the fixed default mode, on MIDI channel 16 — the one mode every unit has the same. Select it: press Mode, then button 16 (bottom-right), press Mode again. Custom modes 1–15 hold whatever was sent from Components and are not modelled. The encoders are endless but send absolute 0–127 by default (the unit keeps the value). Novation does not print the button press / release values for Mode 16; they are treated as momentary CC buttons. Page, Track, Record, Play, Solo/Arm and Mute/Select send nothing in standalone mode; Shift and Mode open menus. No LED feedback: in standalone the colours come from the mode itself (the colour messages in the reference are DAW-mode only). Distinct from the MK2 (port "Launch Control XL", factory template channels 9–16).

訊號

每個控制項都會發出 midi/lcxl3/<控制項>（0..1）和 /raw。打擊墊多一個 /hit，無段旋鈕多 /delta，琴鍵有 /on、/off 和 n<音高>。最後動到的那個控制項是 midi/lcxl3/last。

用起來

把 Novation Launch Control XL 3 用在你的作品裡

  1. 一行嵌入

    不用 import map，也不用建置。可以改 layout，加上 hardware="ask" 就有「接上」按鈕。

    html
    <script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="novation-launch-control-xl-3" readout></oav-controller>

  2. 或用 iframe

    給只能貼 iframe 的地方。每個事件都以 postMessage 傳回來。

    html
    <iframe src="https://openaudiovisual.com/embed/controller/?profile=novation-launch-control-xl-3&readout"
        width="720" height="710" style="border:0;max-width:100%" allow="midi"
        title="Novation Launch Control XL 3"></iframe>
<script>
  // every control the visitor plays arrives here
  addEventListener('message', (e) => {
    if (e.data?.source !== 'openav' || e.data.type !== 'control') return;
    console.log(e.data.detail.signal, e.data.detail.value);
  });
</script>

  3. 送進 Ableton、TouchDesigner、Resolume

    你在畫面上彈的，會變成真正的 MIDI，從 macOS 的 IAC 匯流排或 Windows 的 loopMIDI 埠送出。步驟在圖鑑頁。

    html
    <!-- what you play on this controller → the IAC bus (macOS) → Ableton, TouchDesigner, Resolume -->
<script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="novation-launch-control-xl-3" midi-out="IAC" readout></oav-controller>
<!-- Windows: midi-out="loopMIDI" · let the visitor pick a port: midi-out="ask" -->

    macOS：音訊 MIDI 設定 → MIDI 工作室 → IAC 驅動程式 → 勾「裝置在線上」。Windows 11：內建的 Windows MIDI Services 有 loopback（我們沒有實測）；舊版 Windows：安裝 loopMIDI、新增一個埠，用 midi-out="loopMIDI"。

在 p5.js 裡，只要一行

一行注入會依這份設定檔裡的順序（也就是上面表格的順序）替旋鈕、推桿和打擊墊編號。網址加上 ?profile=novation-launch-control-xl-3，畫面上的控制器就是這一台；真的 Novation Launch Control XL 3 接上時，會依埠名稱自動認出來。

javascript
document.head.prepend(Object.assign(document.createElement('script'), { src: 'https://openaudiovisual.com/p5/oav-p5.js?profile=novation-launch-control-xl-3' }));
