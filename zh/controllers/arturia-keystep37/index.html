Arturia KeyStep 37

Arturia KeyStep 37 是 Arturia 的 MIDI 硬體控制器：37 個琴鍵、4 顆旋鈕、1 顆按鈕、2 條觸控條。

它在 頻道 1 送出 彎音、CC、音符，設定檔引用了 2 份出處。 其中 41 個控制項標了未確認：數字是照目前出處的最佳判讀，按「學習」一次就能重新對應。

這一台還沒有寫 LED 回饋，OAV 不會讓它的燈亮，但每個控制項照樣可以彈、照樣送出各自的訊息。

出處

  • 原廠 KeyStep Manual v1.1.2 (Arturia)mod strip CC 1, pitch strip = pitch bend snapping to centre, sustain CC 64; user channel set with Shift + key
  • 社群 Spectrasonics — Setting up the KeyStep 37 (non-official)knob bank 1: CC 74, 71, 76, 77

說明

Channel 1 and lowest key C3 (48) are assumptions (the manual leaves the defaults to MIDI Control Center); the keys follow any note on the channel, so an octave shift on the unit just scrolls the on-screen keys. Knob banks 2–4 are not mapped. The original 32-key KeyStep has the same strips and pedal: use this profile or generic-keys25/49.

訊號

每個控制項都會發出 midi/keystep37/<控制項>（0..1）和 /raw。打擊墊多一個 /hit，無段旋鈕多 /delta，琴鍵有 /on、/off 和 n<音高>。最後動到的那個控制項是 midi/keystep37/last。

用起來

把 Arturia KeyStep 37 用在你的作品裡

  1. 一行嵌入

    不用 import map，也不用建置。可以改 layout，加上 hardware="ask" 就有「接上」按鈕。

    html
    <script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="arturia-keystep37" readout></oav-controller>

  2. 或用 iframe

    給只能貼 iframe 的地方。每個事件都以 postMessage 傳回來。

    html
    <iframe src="https://openaudiovisual.com/embed/controller/?profile=arturia-keystep37&readout"
        width="720" height="267" style="border:0;max-width:100%" allow="midi"
        title="Arturia KeyStep 37"></iframe>
<script>
  // every control the visitor plays arrives here
  addEventListener('message', (e) => {
    if (e.data?.source !== 'openav' || e.data.type !== 'control') return;
    console.log(e.data.detail.signal, e.data.detail.value);
  });
</script>

  3. 送進 Ableton、TouchDesigner、Resolume

    你在畫面上彈的，會變成真正的 MIDI，從 macOS 的 IAC 匯流排或 Windows 的 loopMIDI 埠送出。步驟在圖鑑頁。

    html
    <!-- what you play on this controller → the IAC bus (macOS) → Ableton, TouchDesigner, Resolume -->
<script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="arturia-keystep37" midi-out="IAC" readout></oav-controller>
<!-- Windows: midi-out="loopMIDI" · let the visitor pick a port: midi-out="ask" -->

    macOS：音訊 MIDI 設定 → MIDI 工作室 → IAC 驅動程式 → 勾「裝置在線上」。Windows 11：內建的 Windows MIDI Services 有 loopback（我們沒有實測）；舊版 Windows：安裝 loopMIDI、新增一個埠，用 midi-out="loopMIDI"。

在 p5.js 裡，只要一行

一行注入會依這份設定檔裡的順序（也就是上面表格的順序）替旋鈕、推桿和打擊墊編號。網址加上 ?profile=arturia-keystep37，畫面上的控制器就是這一台；真的 Arturia KeyStep 37 接上時，會依埠名稱自動認出來。

javascript
document.head.prepend(Object.assign(document.createElement('script'), { src: 'https://openaudiovisual.com/p5/oav-p5.js?profile=arturia-keystep37' }));

p5.js 草稿
function draw() {
  background(knob1 * 255);   // 1 · CC 74
  circle(width / 2, height / 2, 50 + knob2 * 300);   // 2 · CC 71
}

function notePressed(note, velocity) {   // a key goes down
  circle(random(width), random(height), velocity * 100);
}

無段旋鈕、按鈕、滾輪和觸控條沒有編號：用 midi.cc[編號] 讀（編號見上面的表），或寫 controlChange(cc, value, ch) 接。
