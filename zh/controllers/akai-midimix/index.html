AKAI MIDImix

AKAI MIDImix 是 AKAI Professional 的 MIDI 硬體控制器：24 顆旋鈕、9 支推桿、19 顆按鈕。

它在 頻道 1 送出 CC、音符，設定檔引用了 3 份出處。 沒有任何控制項被標為未確認。

出處

  • 原廠 MIDImix User Guide v1.0 (AKAI)layout: 24 knobs (3 per channel), 8 mute buttons (amber-backlit; hold Solo to make them solo buttons), 8 record-arm buttons (red-backlit), 8 + 1 master faders, Bank Left / Right, Solo, Send All; Ableton Live control surface and port name "MIDI Mix"; 23.9 × 20.1 cm. It prints no MIDI numbers (the MIDImix Editor holds them).
  • 社群 Ableton Live 12 MIDI Remote Script MIDI_Mix (decompiled; non-official)all on channel 1: knob rows CC 16 20 24 28 46 50 54 58 / +1 / +2 (the bottom row is pan), faders CC 19 23 27 31 49 53 57 61, master CC 62; mute notes 1 4 … 22, solo (Solo held) 2 5 … 23, rec arm 3 6 … 24; bank left 25, bank right 26, solo 27; LEDs note-on 127 / 0
  • 社群 Ardour AKAI_MIDIMix_Normal_Mode.map and AKAI_MIDIMix_EQ_Mode.map (non-official)agree with the Ableton script: faders 19 … 61, master 62, mute / solo / rec notes 1–24, bank 25 / 26, solo 27, knobs 16–18 … 58–60 (EQ map), channel 1

說明

The factory mapping (what the MIDImix Editor calls the default), channel 1. AKAI's own documents print no numbers, so every number here comes from Ableton's shipped MIDI_Mix script and Ardour's maps, which agree. Holding Solo turns the Mute row into solo buttons sending notes 2, 5 … 23 — a layer the faceplate cannot show, so those notes are not modelled (they still arrive as midi/ch/1/note/<n>). Send All re-sends every knob and fader position and has no message of its own. LED feedback: mute (amber) and rec-arm (red) buttons, note-on 127 / 0, lit while held.

訊號

每個控制項都會發出 midi/midimix/<控制項>（0..1）和 /raw。打擊墊多一個 /hit，無段旋鈕多 /delta，琴鍵有 /on、/off 和 n<音高>。最後動到的那個控制項是 midi/midimix/last。

用起來

把 AKAI MIDImix 用在你的作品裡

  1. 一行嵌入

    不用 import map，也不用建置。可以改 layout，加上 hardware="ask" 就有「接上」按鈕。

    html
    <script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="akai-midimix" readout></oav-controller>

  2. 或用 iframe

    給只能貼 iframe 的地方。每個事件都以 postMessage 傳回來。

    html
    <iframe src="https://openaudiovisual.com/embed/controller/?profile=akai-midimix&readout"
        width="720" height="627" style="border:0;max-width:100%" allow="midi"
        title="AKAI MIDImix"></iframe>
<script>
  // every control the visitor plays arrives here
  addEventListener('message', (e) => {
    if (e.data?.source !== 'openav' || e.data.type !== 'control') return;
    console.log(e.data.detail.signal, e.data.detail.value);
  });
</script>

  3. 送進 Ableton、TouchDesigner、Resolume

    你在畫面上彈的，會變成真正的 MIDI，從 macOS 的 IAC 匯流排或 Windows 的 loopMIDI 埠送出。步驟在圖鑑頁。

    html
    <!-- what you play on this controller → the IAC bus (macOS) → Ableton, TouchDesigner, Resolume -->
<script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="akai-midimix" midi-out="IAC" readout></oav-controller>
<!-- Windows: midi-out="loopMIDI" · let the visitor pick a port: midi-out="ask" -->

    macOS：音訊 MIDI 設定 → MIDI 工作室 → IAC 驅動程式 → 勾「裝置在線上」。Windows：安裝 loopMIDI 並新增一個埠，用 midi-out="loopMIDI"。

在 p5.js 裡，只要一行

一行注入會依這份設定檔裡的順序（也就是上面表格的順序）替旋鈕、推桿和打擊墊編號。網址加上 ?profile=akai-midimix，畫面上的控制器就是這一台；真的 AKAI MIDImix 接上時，會依埠名稱自動認出來。

javascript
document.head.prepend(Object.assign(document.createElement('script'), { src: 'https://openaudiovisual.com/p5/oav-p5.js?profile=akai-midimix' }));
