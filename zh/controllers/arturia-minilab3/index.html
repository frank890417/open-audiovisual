Arturia MiniLab 3

Arturia MiniLab 3 是 Arturia 的 MIDI 硬體控制器：8 個打擊墊、25 個琴鍵、8 顆旋鈕、1 顆無段旋鈕、4 支推桿、2 條觸控條。

它在 頻道 1、10 送出 彎音、CC、音符，設定檔引用了 3 份出處。 其中 1 個控制項標了未確認：數字是照目前出處的最佳判讀，按「學習」一次就能重新對應。

個別控制項的說明

  • enc Main encoder message is not documented in the manual; CC 28 relative is a placeholder — use 學習 (learn) to bind it on your unit.

出處

  • 原廠 Arturia MiniLab 3 User Manual v1.0.5pads bank A notes 36–43 on channel 10 (bank B 44–51), mod strip CC 1, pitch strip = pitch bend (springs to centre), USB ports MIDI / DIN Thru / MCU / ALV
  • 作者的工具 260830 minilab3 midi.toe (the artist's TouchDesigner tool)knob, fader, pad, key and wheel numbers as recorded from the hardware
  • 社群 Spectrasonics — Setting up the MiniLab mk3 (non-official)knob and fader CC defaults; agree with the TD recording

這個設定檔從哪裡來

Che-Yu Wu's TouchDesigner tool, recorded from his own MiniLab 3: base_minilab3 → out_knob (knob1–8 ← CC 74 71 76 77 93 18 19 16), out_slider (s1–s4 ← CC 82 83 85 17), out_pad (pad1–8 ← ch10 notes 36–43), out_note (25 keys, notes 48–72), out_pitch (mod CC 1 + pitch bend). Device table: in-device "Minilab3MIDI", channel 1. TouchDesigner's MIDI In CHOP names channels 1-based (ch1ctrl75 = CC 74, ch10n37 = note 36); the numbers here are real MIDI numbers. 260830 minilab3 midi.toe

說明

Pad pressure type is not documented: poly aftertouch is followed automatically if the unit sends it. Pad RGB LEDs are SysEx-only (not sent; sysex stays off).

訊號

每個控制項都會發出 midi/minilab3/<控制項>（0..1）和 /raw。打擊墊多一個 /hit，無段旋鈕多 /delta，琴鍵有 /on、/off 和 n<音高>。最後動到的那個控制項是 midi/minilab3/last。

用起來

把 Arturia MiniLab 3 用在你的作品裡

  1. 一行嵌入

    不用 import map，也不用建置。可以改 layout，加上 hardware="ask" 就有「接上」按鈕。

    html
    <script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="arturia-minilab3" readout></oav-controller>

  2. 或用 iframe

    給只能貼 iframe 的地方。每個事件都以 postMessage 傳回來。

    html
    <iframe src="https://openaudiovisual.com/embed/controller/?profile=arturia-minilab3&readout"
        width="720" height="468" style="border:0;max-width:100%" allow="midi"
        title="Arturia MiniLab 3"></iframe>
<script>
  // every control the visitor plays arrives here
  addEventListener('message', (e) => {
    if (e.data?.source !== 'openav' || e.data.type !== 'control') return;
    console.log(e.data.detail.signal, e.data.detail.value);
  });
</script>

  3. 送進 Ableton、TouchDesigner、Resolume

    你在畫面上彈的，會變成真正的 MIDI，從 macOS 的 IAC 匯流排或 Windows 的 loopMIDI 埠送出。步驟在圖鑑頁。

    html
    <!-- what you play on this controller → the IAC bus (macOS) → Ableton, TouchDesigner, Resolume -->
<script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="arturia-minilab3" midi-out="IAC" readout></oav-controller>
<!-- Windows: midi-out="loopMIDI" · let the visitor pick a port: midi-out="ask" -->

    macOS：音訊 MIDI 設定 → MIDI 工作室 → IAC 驅動程式 → 勾「裝置在線上」。Windows：安裝 loopMIDI 並新增一個埠，用 midi-out="loopMIDI"。

在 p5.js 裡，只要一行

一行注入會依這份設定檔裡的順序（也就是上面表格的順序）替旋鈕、推桿和打擊墊編號。網址加上 ?profile=arturia-minilab3，畫面上的控制器就是這一台；真的 Arturia MiniLab 3 接上時，會依埠名稱自動認出來。

javascript
document.head.prepend(Object.assign(document.createElement('script'), { src: 'https://openaudiovisual.com/p5/oav-p5.js?profile=arturia-minilab3' }));

p5.js 草稿
function draw() {
  background(knob1 * 255);   // 1 · CC 74
  circle(width / 2, height / 2, 50 + knob2 * 300);   // 2 · CC 71
}

function padPressed(n, velocity) {      // n = 1…8, as in the table
  circle(random(width), random(height), velocity * 100);
}

function notePressed(note, velocity) {   // a key goes down
  circle(random(width), random(height), velocity * 100);
}
