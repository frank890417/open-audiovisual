通用 16 打擊墊

通用 16 打擊墊是通用版面，不對應任何一款產品：16 個打擊墊。它的訊息是慣例，不是哪個廠牌的對照表。找不到你那一台的話，先挑它，按「學習」，再照順序動每個控制項。

出處

  • 慣例 open-audiovisual generic layoutNo device behind it: default messages are a convention (knobs CC 70–77 like many 8-knob pads, faders CC 20–27 in the undefined range, pads GM drum notes from 36 on channel 10). Plug an unknown controller in, pick this layout, and auto-learn binds its messages in the order you move the controls.

認得的埠名稱

通用版面不會自己比對埠：手動指定一個埠，再用學習模式。

訊號

每個控制項都會發出 midi/g16p/<控制項>（0..1）和 /raw。打擊墊多一個 /hit，無段旋鈕多 /delta，琴鍵有 /on、/off 和 n<音高>。最後動到的那個控制項是 midi/g16p/last。

用起來

把 通用 16 打擊墊 用在你的作品裡

  1. 一行嵌入

    不用 import map，也不用建置。可以改 layout，加上 hardware="ask" 就有「接上」按鈕。

    html
    <script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="generic-16p" readout></oav-controller>

  2. 或用 iframe

    給只能貼 iframe 的地方。每個事件都以 postMessage 傳回來。

    html
    <iframe src="https://openaudiovisual.com/embed/controller/?profile=generic-16p&readout"
        width="720" height="742" style="border:0;max-width:100%" allow="midi"
        title="Generic 16 pads"></iframe>
<script>
  // every control the visitor plays arrives here
  addEventListener('message', (e) => {
    if (e.data?.source !== 'openav' || e.data.type !== 'control') return;
    console.log(e.data.detail.signal, e.data.detail.value);
  });
</script>

  3. 送進 Ableton、TouchDesigner、Resolume

    你在畫面上彈的，會變成真正的 MIDI，從 macOS 的 IAC 匯流排或 Windows 的 loopMIDI 埠送出。步驟在圖鑑頁。

    html
    <!-- what you play on this controller → the IAC bus (macOS) → Ableton, TouchDesigner, Resolume -->
<script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="generic-16p" midi-out="IAC" readout></oav-controller>
<!-- Windows: midi-out="loopMIDI" · let the visitor pick a port: midi-out="ask" -->

    macOS：音訊 MIDI 設定 → MIDI 工作室 → IAC 驅動程式 → 勾「裝置在線上」。Windows：安裝 loopMIDI 並新增一個埠，用 midi-out="loopMIDI"。

在 p5.js 裡，只要一行

一行注入會依這個版面裡的順序（也就是上面表格的順序）替旋鈕、推桿和打擊墊編號。網址加上 ?profile=generic-16p，畫面上的控制器就是這個版面。

javascript
document.head.prepend(Object.assign(document.createElement('script'), { src: 'https://openaudiovisual.com/p5/oav-p5.js?profile=generic-16p' }));
