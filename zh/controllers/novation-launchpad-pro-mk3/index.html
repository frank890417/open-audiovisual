Novation Launchpad Pro MK3

Novation Launchpad Pro MK3 是 Novation 的 MIDI 硬體控制器：64 個打擊墊、41 顆按鈕。

它在 頻道 1 送出 音符、CC，設定檔引用了 2 份出處。 沒有任何控制項被標為未確認。

  • 原廠 Launchpad Pro [MK3] Programmer's reference manual (Novation)official. 'Programmer mode layout' diagram (p.19): 8×8 pads = notes 11–88, 11 bottom-left, +1 to the right, +10 per row up; top row CC 91–98 (CC 90 top-left, CC 99 the logo); left column CC 80, 70 … 10 (top to bottom); right column CC 89, 79 … 19; the row under the grid CC 101–108, the row under that CC 1–8; 'all buttons and pads accept either Note or Control Change messages. The indicated type is which is sent by the device'. LEDs: note-on or CC on ch 1 = static, ch 2 = flashing, ch 3 = pulsing, velocity / value = palette index (0 off, 3 white, 5 red, 13 yellow, 21 green, 37 turquoise, 45 blue); Live/Programmer toggle F0 00 20 29 02 0E 0E <0|1> F7; three ports LPProMK3 MIDI / DIN / DAW
  • 原廠 Launchpad Pro [MK3] User Guide v1 (Novation)official. §3 Hardware Overview (what is printed on each button: the top row ◀ ▶ Session Note Chord Custom Sequencer Projects, the left column ▲ ▼ Clear Duplicate Quantise Fixed Length Play Record, the right column Patterns … Print to Clip, the Ableton track controls Record Arm … Stop Clip); §10.4 pressure mode off / polyphonic / channel; §10.7 Programmer mode: hold Setup, press the orange Scene Launch button, release Setup; the unit always powers on into Live mode

說明

Models Programmer mode, the one layout in which every pad and button has a documented message. Live mode (what the unit boots into) is different: Note, Chord, Custom and Session modes each send their own notes. Enter Programmer mode from the unit (hold Setup, press the orange Scene Launch button, release Setup) or with the SysEx F0 00 20 29 02 0E 0E 01 F7 (stays off by default: the element sends no SysEx). Use the first port, "LPProMK3 MIDI" (macOS), not DIN or DAW. The manual gives a channel only for lighting (ch 1 static, 2 flashing, 3 pulsing); channel 1 for what the pads and buttons send is an assumption (the worked examples are all channel 1), not a line of the manual: unconfirmed. Pads send velocity; their pressure (off, polyphonic or channel aftertouch) is a unit setting and is not modelled. The labels on the buttons are what the Live-mode faceplate prints; in Programmer mode they are only positions. CC 99 lights the logo and the Setup button sends nothing: both are drawn only. LED feedback: pads light turquoise (palette 37) while played, buttons white (palette 3).

訊號

每個控制項都會發出 midi/lppro3/<控制項>（0..1）和 /raw。打擊墊多一個 /hit，無段旋鈕多 /delta，琴鍵有 /on、/off 和 n<音高>。最後動到的那個控制項是 midi/lppro3/last。

用起來

把 Novation Launchpad Pro MK3 用在你的作品裡

  1. 一行嵌入

    不用 import map，也不用建置。可以改 layout，加上 hardware="ask" 就有「接上」按鈕。

    html
    <script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="novation-launchpad-pro-mk3" readout></oav-controller>

  2. 或用 iframe

    給只能貼 iframe 的地方。每個事件都以 postMessage 傳回來。

    html
    <iframe src="https://openaudiovisual.com/embed/controller/?profile=novation-launchpad-pro-mk3&readout"
        width="720" height="728" style="border:0;max-width:100%" allow="midi"
        title="Novation Launchpad Pro MK3"></iframe>
<script>
  // every control the visitor plays arrives here
  addEventListener('message', (e) => {
    if (e.data?.source !== 'openav' || e.data.type !== 'control') return;
    console.log(e.data.detail.signal, e.data.detail.value);
  });
</script>

  3. 送進 Ableton、TouchDesigner、Resolume

    你在畫面上彈的，會變成真正的 MIDI，從 macOS 的 IAC 匯流排或 Windows 的 loopMIDI 埠送出。步驟在圖鑑頁。

    html
    <!-- what you play on this controller → the IAC bus (macOS) → Ableton, TouchDesigner, Resolume -->
<script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="novation-launchpad-pro-mk3" midi-out="IAC" readout></oav-controller>
<!-- Windows: midi-out="loopMIDI" · let the visitor pick a port: midi-out="ask" -->

    macOS：音訊 MIDI 設定 → MIDI 工作室 → IAC 驅動程式 → 勾「裝置在線上」。Windows 11：內建的 Windows MIDI Services 有 loopback（我們沒有實測）；舊版 Windows：安裝 loopMIDI、新增一個埠，用 midi-out="loopMIDI"。

在 p5.js 裡，只要一行

一行注入會依這份設定檔裡的順序（也就是上面表格的順序）替旋鈕、推桿和打擊墊編號。網址加上 ?profile=novation-launchpad-pro-mk3，畫面上的控制器就是這一台；真的 Novation Launchpad Pro MK3 接上時，會依埠名稱自動認出來。

javascript
document.head.prepend(Object.assign(document.createElement('script'), { src: 'https://openaudiovisual.com/p5/oav-p5.js?profile=novation-launchpad-pro-mk3' }));
