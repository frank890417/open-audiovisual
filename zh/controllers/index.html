01 · 彈奏

MIDI 控制器圖鑑

每一顆旋鈕、打擊墊、琴鍵按下去送出什麼 MIDI 訊息，這個數字出自哪一份手冊，這裡都查好寫清楚了。用滑鼠或手指直接彈，接上你手邊的控制器，畫面會跟著你的手動，也可以用一行程式碼放進自己的網頁。

以前每換一套軟體，就要把手上的控制器重新對一次，CC 幾號、哪個頻道，每個人都在翻同一本手冊。這裡把每一台查一次、建好模型、附上出處，之後大家直接拿去用。

這個設定檔從哪裡來

Che-Yu Wu's TouchDesigner tool: MIDI In (Device ID + Active toggle) → select ch10n* → Pad1–8, select ch1ctrl* → K1–K8, math 0..127 → 0..1, bound both ways to custom parameters (Pads page: 8 momentary pulses, Knobs page: 8 floats) and to an 800×200 panel (pads left, knobs right). TouchDesigner's MIDI In CHOP names channels 1-based (ch1ctrl75 = CC 74, ch10n37 = note 36); the numbers here are real MIDI numbers. AKAI_LPD8.tox

說明

Pad note numbers are the common program-1 layout (36–43) but not printed in the manual — pads are marked unverified; 學習 rebinds them in one tap each. The pads light themselves; no LED feedback is sent.

認得的埠名稱

比對
/lpd\s*8/i

訊號

每個控制項都會發出 midi/lpd8/<控制項>（0..1）和 /raw。打擊墊多一個 /hit，無段旋鈕多 /delta，琴鍵有 /on、/off 和 n<音高>。最後動到的那個控制項是 midi/lpd8/last。

放進你的網頁

一行 HTML、一個 iframe，或一段 JavaScript 都可以。先選機型和選項，預覽和下面每一段程式碼會跟著換。

即時預覽

最後一個事件，你的程式收到的樣子

彈一下預覽，它的 control 事件會出現在這裡。

  1. 一行，任何網頁

    不用 import map，不用建置。Shadow DOM 讓你網頁的 CSS 進不來，控制器的 CSS 也出不去。

    html
    <script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="akai-lpd8" readout></oav-controller>

  2. iframe

    給只能放 iframe 的地方。每個事件都會用 postMessage 傳出來，你也可以把 set、ingest 傳回去。

    html
    <iframe src="https://openaudiovisual.com/embed/controller/?profile=akai-lpd8&readout"
        width="720" height="216" style="border:0;max-width:100%" allow="midi"
        title="AKAI LPD8 (mk2)"></iframe>
<script>
  // every control the visitor plays arrives here
  addEventListener('message', (e) => {
    if (e.data?.source !== 'openav' || e.data.type !== 'control') return;
    console.log(e.data.detail.signal, e.data.detail.value);
  });
</script>

  3. JavaScript，任何框架

    createController() 就是不帶元素的元素：React、Vue、Svelte 或純 JS 都能用。不畫面板也能跑。

    javascript
    import { createController } from 'https://openaudiovisual.com/packages/midi/index.js';

const ctl = createController('akai-lpd8');
ctl.mount(document.querySelector('#controller'));   // optional: headless works too
ctl.on('control', (e) => console.log(e.signal, e.value));
ctl.connectHardware();   // optional: follow the real one (asks for Web MIDI)

  4. 聽它

    事件會冒泡，也會穿過 shadow root。每個事件內容都是單純的 JSON：控制項、數值、訊號名稱、MIDI 訊息和位元組。

    javascript
    const el = document.querySelector('oav-controller');
el.addEventListener('control', (e) => {
  const { id, value, signal, message, source } = e.detail;
  // 'k1'  0..1  'midi/lpd8/k1'  { type: 'cc', ch: 1, cc: 70, value: 64 }  'ui' | 'hardware'
});
el.addEventListener('noteon', (e) => console.log(e.detail.note, e.detail.velocity));

await el.ready;
el.set('k1', 0.5);              // move a control: fires 'control', reaches MIDI out
el.set('pad1', 1); el.set('pad1', 0);   // strike and release
el.ingest([0xb0, 70, 64]);   // MIDI from anywhere (a WebSocket, another tab)

  5. 拿它彈你的 DAW

    在螢幕上彈的，會變成真的 MIDI 送出去，進到 Ableton Live、TouchDesigner、Resolume，或任何收 MIDI 輸入的軟體。

    html
    <!-- what you play on this controller → the IAC bus (macOS) → Ableton, TouchDesigner, Resolume -->
<script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="akai-lpd8" midi-out="IAC" readout></oav-controller>
<!-- Windows: midi-out="loopMIDI" · let the visitor pick a port: midi-out="ask" -->

MIDI 輸出到 Ableton、TouchDesigner、Resolume

  1. macOS：打開音訊 MIDI 設定 → 視窗 → 顯示 MIDI 工作室，雙擊 IAC 驅動程式，勾選「裝置已上線」。
  2. Windows：安裝 loopMIDI，新增一個埠。
  3. Ableton Live：設定 → Link, Tempo & MIDI → 把 IAC 或 loopMIDI 輸入的 Track 和 Remote 打開。TouchDesigner：在那個裝置上放一個 MIDI In CHOP。Resolume：Preferences → MIDI。

Chrome 和 Edge 有 Web MIDI，Firefox 會先問你是否允許這個網站。Safari 和 iPad 沒有：控制器照樣能彈、每個事件照樣送出，MIDI 輸出會顯示無法使用。

不會繞成迴圈。引擎本來就不聽 IAC 輸入，跟輸出同名的輸入（loopMIDI 自己的回音）也會靜音。實體控制器的動作不會再轉送一次，因為你的軟體本來就收得到那台。

iframe 訊息

iframe 會把每個事件傳給上層網頁，也接受幾個指令。加上 &frame=名稱 可以分辨多個 iframe，加上 &origin=https://你的網站 就只和你的網頁溝通。

postMessage
// iframe → your page, for every event
{ source: 'openav', v: 1, type: 'control', frame: 'pads',
  detail: { id, type, value, raw, signal, message, bytes, source } }
// type: ready · control · noteon · noteoff · connect · disconnect · status · profilechange · error

// your page → iframe
const win = document.querySelector('iframe').contentWindow;
win.postMessage({ target: 'openav', type: 'set', id: 'k1', value: 0.5 }, '*');
win.postMessage({ target: 'openav', type: 'ingest', bytes: [0xb0, 70, 64] }, '*');
win.postMessage({ target: 'openav', type: 'get' }, '*');   // answers with type 'values'
// also: press · release · reset · profile · layout

05 · 自己建一台

加入你的控制器

一台控制器就是一個 JSON 檔。手冊裡有 MIDI 實作表，就照著抄，數字會完全準確。手冊沒寫的，就在檔案裡註明是怎麼查到的。

  1. 從最接近的檔案開始 複製一台長得像你那台的裝置，或一個通用版面。面板是用面板單位排在格線上的區塊，所以螢幕上的版本看起來就像桌上那台。
  2. 寫下每個控制項送什麼 類型、訊息（cc、note、pitchbend）、頻道、編號。無段旋鈕寫明相對值怎麼編碼，按鈕寫是按住還是切換，有 LED 就寫哪個訊息會點亮它。
  3. 每個數字都要有出處 每份出處都有標題、連結，以及它證實了什麼。沒人確認過的數字，標上 "verified": false 並寫一句說明。
  4. 驗證 validateProfile() 會用文字列出每一個問題，沒有問題就回傳空陣列。測試會對每個內建設定檔跑一次。
  5. 送出前先試 <oav-controller profile="./my-pads.json"> 可以從網址載入設定檔，先在你自己的網頁上彈彈看。
  6. 開一個 pull request 把檔案放進 packages/midi/profiles/，在 profiles/index.js 加上它。告訴我們你在哪台機器、哪個韌體上確認過。

控制項類型

類型送出訊號數值
knob · faderCC，絕對值 0–1270..1
encoderCC，相對值（offset64、offset16、twos、signbit）位置 0..1，另有 /delta 步數
pad帶力度的音符（或 CC），可能有觸後按住時是力度，放開是 0，另有 /hit
button音符或 CC，按住或切換0 或 1
keys一段音域/on、/off 脈衝，按住時 n<音高>
wheel · stripCC 或彎音，可能會回彈0..1，雙極時 −1..1
