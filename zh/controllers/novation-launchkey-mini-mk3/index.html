Novation Launchkey Mini MK3

Novation Launchkey Mini MK3 是 Novation 的 MIDI 硬體控制器：16 個打擊墊、25 個琴鍵、8 顆旋鈕、2 條觸控條。

它在 頻道 1、10 送出 彎音、CC、音符，設定檔引用了 6 份出處。 其中 34 個控制項標了未確認：數字是照目前出處的最佳判讀，按「學習」一次就能重新對應。

個別控制項的說明

  • mod Novation only calls it the Modulation strip; CC 1 is the MIDI modulation controller but no Novation document prints the number. 學習 rebinds it.
  • k1 Factory Custom pot mode sends CC 21–28 (Spectrasonics); its MIDI channel is not documented — channel 1 assumed. Select Custom: hold Shift, press the top-right pad.

出處

  • 原廠 Launchkey Mini [MK3] User Guide 1.1 (Novation)pitch and modulation touch strips; 8 knobs; 16 pads with Session / Drum / Custom pad modes (hold Shift, press a top-row pad: Session, Drum, Custom left; Device, Volume, Pan, Sends, Custom pot modes right); custom modes send notes (pads) and CCs (knobs), edited in Novation Components; Shift + Transpose picks the keyboard MIDI channel; ports "Launchkey Mini MK3 (DAW Port)" on Mac, "MIDI IN2" on Windows for the DAW. No note or CC numbers are printed.
  • 原廠 Launchkey [MK3] Programmer's Reference Guide v1 (Novation; the full-size MK3 family)the family powers into Standalone mode; keys, pitch/mod wheels, sustain and the Drum layout of the pads stay on the MIDI port, the rest of the surface talks only to a DAW on the DAW port; note-off = note-on velocity 0; mentions script compatibility with the Launchkey Mini [MK3]
  • 社群 Ableton Live 12 MIDI Remote Script novation/launchkey_elements.py (used by Launchkey_Mini_MK3; decompiled, non-official)drum pads notes 36–51 on channel 10 (DRUM_CHANNEL = 9); in DAW mode the pots are CC 21–28 on channel 16
  • 社群 DrivenByMoss LaunchkeyPadGrid.java, Launchkey Mini MK3 (Bitwig; non-official)Drum layout on the 2 × 8 pads, channel 10: bottom row 36 37 38 39 44 45 46 47, top row 40 41 42 43 48 49 50 51; Windows ports "Launchkey Mini MK3" and "MIDIIN2 (Launchkey Mini MK3)"
  • 社群 giezu/LaunchkeyMiniMK3 — reverse-engineered MIDI implementation (non-official)Drum-mode pads send notes on channel 10; keys, custom-mode knobs and pads, pitch bend and modulation arrive on "Launchkey Mini MK3 MIDI 1", DAW traffic on "MIDI 2" (Linux names)
  • 社群 Spectrasonics — Setting up the Launchkey Mini mk3 (non-official)relies on the factory Custom pot mode: knobs 1–8 = CC 21–28 (hold Shift, press the Custom pad on the top row)

說明

Standalone, MIDI port: pads in Drum mode (hold Shift, press the 2nd top-row pad), knobs in Custom pot mode (hold Shift, press the top-right pad). Novation publishes no programmer's reference for the Mini, so: the pad notes and channel 10 are confirmed by Ableton's and DrivenByMoss's scripts (the 2 × 8 arrangement by DrivenByMoss); the knob CCs 21–28 come from Spectrasonics only and their channel is assumed — knobs, the Mod strip and the key range are marked unverified (學習 rebinds them). Session mode and the Device/Volume/Pan/Sends pot modes need a DAW and talk on the DAW port, not modelled. Shift, Transpose, Octave, >, Stop·Solo·Mute, Arp, Fixed Chord, Play and Record send nothing on the MIDI port in standalone use. No LED feedback.

訊號

每個控制項都會發出 midi/lkmini3/<控制項>（0..1）和 /raw。打擊墊多一個 /hit，無段旋鈕多 /delta，琴鍵有 /on、/off 和 n<音高>。最後動到的那個控制項是 midi/lkmini3/last。

用起來

把 Novation Launchkey Mini MK3 用在你的作品裡

  1. 一行嵌入

    不用 import map，也不用建置。可以改 layout，加上 hardware="ask" 就有「接上」按鈕。

    html
    <script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="novation-launchkey-mini-mk3" readout></oav-controller>

  2. 或用 iframe

    給只能貼 iframe 的地方。每個事件都以 postMessage 傳回來。

    html
    <iframe src="https://openaudiovisual.com/embed/controller/?profile=novation-launchkey-mini-mk3&readout"
        width="720" height="418" style="border:0;max-width:100%" allow="midi"
        title="Novation Launchkey Mini MK3"></iframe>
<script>
  // every control the visitor plays arrives here
  addEventListener('message', (e) => {
    if (e.data?.source !== 'openav' || e.data.type !== 'control') return;
    console.log(e.data.detail.signal, e.data.detail.value);
  });
</script>

  3. 送進 Ableton、TouchDesigner、Resolume

    你在畫面上彈的，會變成真正的 MIDI，從 macOS 的 IAC 匯流排或 Windows 的 loopMIDI 埠送出。步驟在圖鑑頁。

    html
    <!-- what you play on this controller → the IAC bus (macOS) → Ableton, TouchDesigner, Resolume -->
<script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="novation-launchkey-mini-mk3" midi-out="IAC" readout></oav-controller>
<!-- Windows: midi-out="loopMIDI" · let the visitor pick a port: midi-out="ask" -->

    macOS：音訊 MIDI 設定 → MIDI 工作室 → IAC 驅動程式 → 勾「裝置在線上」。Windows 11：內建的 Windows MIDI Services 有 loopback（我們沒有實測）；舊版 Windows：安裝 loopMIDI、新增一個埠，用 midi-out="loopMIDI"。

在 p5.js 裡，只要一行

一行注入會依這份設定檔裡的順序（也就是上面表格的順序）替旋鈕、推桿和打擊墊編號。網址加上 ?profile=novation-launchkey-mini-mk3，畫面上的控制器就是這一台；真的 Novation Launchkey Mini MK3 接上時，會依埠名稱自動認出來。

javascript
document.head.prepend(Object.assign(document.createElement('script'), { src: 'https://openaudiovisual.com/p5/oav-p5.js?profile=novation-launchkey-mini-mk3' }));

p5.js 草稿
function draw() {
  background(knob1 * 255);   // 1 · CC 21
  circle(width / 2, height / 2, 50 + knob2 * 300);   // 2 · CC 22
}

function padPressed(n, velocity) {      // n = 1…16, as in the table
  circle(random(width), random(height), velocity * 100);
}

function notePressed(note, velocity) {   // a key goes down
  circle(random(width), random(height), velocity * 100);
}
