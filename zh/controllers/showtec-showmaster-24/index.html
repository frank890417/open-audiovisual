ShowTec ShowMaster 24

ShowTec ShowMaster 24 是 ShowTec 的 MIDI 硬體控制器：45 顆按鈕。

它在 頻道 1 送出 CC，設定檔引用了 1 份出處。 其中 45 個控制項標了未確認：數字是照目前出處的最佳判讀，按「學習」一次就能重新對應。

這個設定檔從哪裡來

Imported from QLC+ on 2026-11-04. resources/inputprofiles/ShowTec-ShowMaster24.qxi

說明

Imported from QLC+. The messages are what its community profile lists; nobody has checked them on a unit for this project, so every control is unverified. QLC+ has no faceplate data, so the layout was generated from the list of controls and does not look like the device. There is no port name to go by, so it is never picked automatically: assign it by hand. QLC+ numbers these controls without a MIDI channel, so channel 1 here is a placeholder: the unit may send on another.

認得的埠名稱

訊號

每個控制項都會發出 midi/showmaster24/<控制項>（0..1）和 /raw。打擊墊多一個 /hit，無段旋鈕多 /delta，琴鍵有 /on、/off 和 n<音高>。最後動到的那個控制項是 midi/showmaster24/last。

用起來

把 ShowTec ShowMaster 24 用在你的作品裡

  1. 一行嵌入

    不用 import map，也不用建置。可以改 layout，加上 hardware="ask" 就有「接上」按鈕。

    html
    <script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="showtec-showmaster-24" readout></oav-controller>

  2. 或用 iframe

    給只能貼 iframe 的地方。每個事件都以 postMessage 傳回來。

    html
    <iframe src="https://openaudiovisual.com/embed/controller/?profile=showtec-showmaster-24&readout"
        width="720" height="303" style="border:0;max-width:100%" allow="midi"
        title="ShowTec ShowMaster 24"></iframe>
<script>
  // every control the visitor plays arrives here
  addEventListener('message', (e) => {
    if (e.data?.source !== 'openav' || e.data.type !== 'control') return;
    console.log(e.data.detail.signal, e.data.detail.value);
  });
</script>

  3. 送進 Ableton、TouchDesigner、Resolume

    你在畫面上彈的，會變成真正的 MIDI，從 macOS 的 IAC 匯流排或 Windows 的 loopMIDI 埠送出。步驟在圖鑑頁。

    html
    <!-- what you play on this controller → the IAC bus (macOS) → Ableton, TouchDesigner, Resolume -->
<script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="showtec-showmaster-24" midi-out="IAC" readout></oav-controller>
<!-- Windows: midi-out="loopMIDI" · let the visitor pick a port: midi-out="ask" -->

    macOS：音訊 MIDI 設定 → MIDI 工作室 → IAC 驅動程式 → 勾「裝置在線上」。Windows 11：內建的 Windows MIDI Services 有 loopback（我們沒有實測）；舊版 Windows：安裝 loopMIDI、新增一個埠，用 midi-out="loopMIDI"。

在 p5.js 裡，只要一行

一行注入會依這份設定檔裡的順序（也就是上面表格的順序）替旋鈕、推桿和打擊墊編號。網址加上 ?profile=showtec-showmaster-24，畫面上的控制器就是這一台；真的 ShowTec ShowMaster 24 接上時，會依埠名稱自動認出來。

javascript
document.head.prepend(Object.assign(document.createElement('script'), { src: 'https://openaudiovisual.com/p5/oav-p5.js?profile=showtec-showmaster-24' }));
p5.js 草稿
function draw() {
  background(20);
}

無段旋鈕、按鈕、滾輪和觸控條沒有編號：用 midi.cc[編號] 讀（編號見上面的表），或寫 controlChange(cc, value, ch) 接。

在這個專案以外使用這台控制器

同一份資料，換成別的程式讀得懂的檔案。除非上面的表格有寫，這些檔案都還沒在這台機器上實測過。

QLC+

輸入設定檔：每個控制項和 LED 值，給燈光控制用。複製到使用者資料夾（macOS ~/Library/Application Support/QLC+/InputProfiles，Linux ~/.qlcplus/inputprofiles，Windows %USERPROFILE%\QLC+\InputProfiles），重新開啟 QLC+。

showtec-showmaster-24.qxi

Mixxx

這是起點，不是完成的 mapping：唱盤、EQ、hot cue 依序分給各個控制項。把兩個檔案放進 Preferences → Controllers → Open User Mapping Folder 開啟的資料夾，再用 Learning Wizard 改成你要的。

showtec-showmaster-24.midi.xmlshowtec-showmaster-24.scripts.js
