Novation

Novation Launchpad

Novation Launchpad 是 Novation 的 MIDI 硬體控制器：80 顆按鈕。

它在 頻道 1 送出 CC、音符，設定檔引用了 1 份出處。 其中 80 個控制項標了未確認：數字是照目前出處的最佳判讀，按「學習」一次就能重新對應。

說明

Imported from QLC+. The messages are what its community profile lists; nobody has checked them on a unit for this project, so every control is unverified. QLC+ has no faceplate data, so the layout was generated from the list of controls and does not look like the device. QLC+ numbers these controls without a MIDI channel, so channel 1 here is a placeholder: the unit may send on another.

訊號

每個控制項都會發出 midi/launchpad/<控制項>（0..1）和 /raw。打擊墊多一個 /hit，無段旋鈕多 /delta，琴鍵有 /on、/off 和 n<音高>。最後動到的那個控制項是 midi/launchpad/last。

用起來

把 Novation Launchpad 用在你的作品裡

  1. 一行嵌入

    不用 import map，也不用建置。可以改 layout，加上 hardware="ask" 就有「接上」按鈕。

    html
    <script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="novation-launchpad" readout></oav-controller>

  2. 或用 iframe

    給只能貼 iframe 的地方。每個事件都以 postMessage 傳回來。

    html
    <iframe src="https://openaudiovisual.com/embed/controller/?profile=novation-launchpad&readout"
        width="720" height="263" style="border:0;max-width:100%" allow="midi"
        title="Novation Launchpad"></iframe>
<script>
  // every control the visitor plays arrives here
  addEventListener('message', (e) => {
    if (e.data?.source !== 'openav' || e.data.type !== 'control') return;
    console.log(e.data.detail.signal, e.data.detail.value);
  });
</script>

  3. 送進 Ableton、TouchDesigner、Resolume

    你在畫面上彈的，會變成真正的 MIDI，從 macOS 的 IAC 匯流排或 Windows 的 loopMIDI 埠送出。步驟在圖鑑頁。

    html
    <!-- what you play on this controller → the IAC bus (macOS) → Ableton, TouchDesigner, Resolume -->
<script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="novation-launchpad" midi-out="IAC" readout></oav-controller>
<!-- Windows: midi-out="loopMIDI" · let the visitor pick a port: midi-out="ask" -->

    macOS：音訊 MIDI 設定 → MIDI 工作室 → IAC 驅動程式 → 勾「裝置在線上」。Windows 11：內建的 Windows MIDI Services 有 loopback（我們沒有實測）；舊版 Windows：安裝 loopMIDI、新增一個埠，用 midi-out="loopMIDI"。

其他軟體

在這個專案以外使用這台控制器

同一份資料，換成別的程式讀得懂的檔案。除非上面的表格有寫，這些檔案都還沒在這台機器上實測過。

QLC+

輸入設定檔：每個控制項和 LED 值，給燈光控制用。複製到使用者資料夾（macOS ~/Library/Application Support/QLC+/InputProfiles，Linux ~/.qlcplus/inputprofiles，Windows %USERPROFILE%\QLC+\InputProfiles），重新開啟 QLC+。

novation-launchpad.qxi

Mixxx

這是起點，不是完成的 mapping：唱盤、EQ、hot cue 依序分給各個控制項。把兩個檔案放進 Preferences → Controllers → Open User Mapping Folder 開啟的資料夾，再用 Learning Wizard 改成你要的。
