Behringer X-TOUCH MINI

Behringer X-TOUCH MINI 是 Behringer 的 MIDI 硬體控制器：8 顆無段旋鈕、1 支推桿、24 顆按鈕。

它在 頻道 11 送出 CC、音符，設定檔引用了 3 份出處。 沒有任何控制項被標為未確認。

出處

  • 原廠 X-TOUCH MINI Quick Start Guide (Behringer / MUSIC Group, P0B3M; mirror)MIDI map: Preset A on MIDI channel 11 — encoders turn CC 1–8, push notes C-2…G-2 (0–7), upper buttons G#-2…D#-1 (8–15), lower buttons E-1…B-1 (16–23), fader CC 9; Preset B (channel 11) — CC 11–18, notes 24–47, fader CC 10. RX table (global channel): LED-ring style CC 1–8, ring value CC 9–16 (0 off, 1–13 one LED, 14–26 blink, 27 all, 28 all blink), button LEDs notes 0–15 velocity 0 off / 1 on / 2 blink, Program Change 0/1 = layer A/B, CC 127 = standard/MC mode. 8 endless encoders with 13-LED rings, 16 backlit buttons, 60 mm fader; MC mode = hold MC while plugging in; 325 × 102 mm
  • 社群 X-Touch-Mini-FS2020 docs (non-official)encoders must be switched to Relative2 in the X-TOUCH Editor for that app — i.e. the factory encoders are not relative; editor shows encoder push as Momentary notes on channel 11
  • 社群 Q Light Controller+ forum — Behringer X Touch Mini (non-official)input on channel 11; the fader is CC 9 on layer A and CC 10 on layer B; buttons pressed on the unit only light while held (momentary)

說明

Standard mode (not MC), Layer A, as shipped: everything on channel 11. Layer B sends CC 11–18 / notes 24–47 / fader CC 10 on the same channel — a layer the faceplate cannot show, so it is not modelled (學習 rebinds). The encoders are endless but send absolute 0–127 by default (the unit keeps the value and draws it on the LED ring); switch them to a relative mode in the X-TOUCH Editor and set "relative" here to match. Layer A / B select presets inside the unit. LED feedback is not wired: button LEDs and LED-ring values are addressed on the unit's global channel (notes 0–15, CC 9–16), whose factory value is not documented (owners report 1 or 12). MC mode (Mackie Control) is a different protocol and is not covered.

認得的埠名稱

比對
/x-?\s*touch\s*mini/i

訊號

每個控制項都會發出 midi/xtouchmini/<控制項>（0..1）和 /raw。打擊墊多一個 /hit，無段旋鈕多 /delta，琴鍵有 /on、/off 和 n<音高>。最後動到的那個控制項是 midi/xtouchmini/last。

用起來

把 Behringer X-TOUCH MINI 用在你的作品裡

  1. 一行嵌入

    不用 import map，也不用建置。可以改 layout，加上 hardware="ask" 就有「接上」按鈕。

    html
    <script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="behringer-x-touch-mini" readout></oav-controller>

  2. 或用 iframe

    給只能貼 iframe 的地方。每個事件都以 postMessage 傳回來。

    html
    <iframe src="https://openaudiovisual.com/embed/controller/?profile=behringer-x-touch-mini&readout"
        width="720" height="249" style="border:0;max-width:100%" allow="midi"
        title="Behringer X-TOUCH MINI"></iframe>
<script>
  // every control the visitor plays arrives here
  addEventListener('message', (e) => {
    if (e.data?.source !== 'openav' || e.data.type !== 'control') return;
    console.log(e.data.detail.signal, e.data.detail.value);
  });
</script>

  3. 送進 Ableton、TouchDesigner、Resolume

    你在畫面上彈的，會變成真正的 MIDI，從 macOS 的 IAC 匯流排或 Windows 的 loopMIDI 埠送出。步驟在圖鑑頁。

    html
    <!-- what you play on this controller → the IAC bus (macOS) → Ableton, TouchDesigner, Resolume -->
<script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="behringer-x-touch-mini" midi-out="IAC" readout></oav-controller>
<!-- Windows: midi-out="loopMIDI" · let the visitor pick a port: midi-out="ask" -->

    macOS：音訊 MIDI 設定 → MIDI 工作室 → IAC 驅動程式 → 勾「裝置在線上」。Windows：安裝 loopMIDI 並新增一個埠，用 midi-out="loopMIDI"。

在 p5.js 裡，只要一行

一行注入會依這份設定檔裡的順序（也就是上面表格的順序）替旋鈕、推桿和打擊墊編號。網址加上 ?profile=behringer-x-touch-mini，畫面上的控制器就是這一台；真的 Behringer X-TOUCH MINI 接上時，會依埠名稱自動認出來。

javascript
document.head.prepend(Object.assign(document.createElement('script'), { src: 'https://openaudiovisual.com/p5/oav-p5.js?profile=behringer-x-touch-mini' }));
在草稿裡控制項訊息
fader1Fader faderCC 9 · 頻道 11
p5.js 草稿
function draw() {
  background(fader1 * 255);   // Fader · CC 9
}
