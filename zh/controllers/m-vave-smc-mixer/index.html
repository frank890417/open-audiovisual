M-VAVE

M-VAVE SMC-Mixer

M-VAVE SMC-Mixer 是 M-VAVE 的 MIDI 硬體控制器：8 顆無段旋鈕、8 支推桿、43 顆按鈕。

它在 頻道 1、2、3、4、5、6、7、8 送出 CC、音符、彎音，設定檔引用了 2 份出處。 其中 7 個控制項標了未確認：數字是照目前出處的最佳判讀，按「學習」一次就能重新對應。

這個設定檔從哪裡來

Imported from QLC+ on 2026-11-04. resources/inputprofiles/M-VAVE-SMC-Mixer.qxi

說明

In DAW (Mackie) mode, which SHIFT + ◁ selects (SHIFT + ▷ goes back to user mode). Converted from the QLC+ community profile (Apache-2.0, see NOTICE); the faceplate, the labels from the manual (□ is Select, II is Stop, « and » are Bank − and +), the LEDs and most of these notes come from jcguevarap and his unit (firmware V012), PR #9. He checked that unit twice (issue #7), and both sittings are in verifications: on 2026-11-23 with a MIDI monitor, every control and its light; on 2026-11-24 with the verification page, every control but encoders 2–8, which it skipped because the file had them as buttons. The 52 controls the page confirmed are marked checked on hardware. Encoders 2–8 send CC 17–23 on the monitor reading and stay unconfirmed until a run on the page turns them. Every message number is the one QLC+ lists; the correction is the encoders: all eight are relative with a sign bit (1 = clockwise, 65 = counter-clockwise), where QLC+ has encoder 1 as absolute and 2–8 as buttons. The lights, as the owner reports them (this project has not checked them): the 32 strip buttons and Play, Stop, Record, Rewind and Forward light up with a Note On on the same note sent back to the unit (velocity > 0 on, 0 off; there is no blink). Bank −/+ and the arrows have no controllable light. The light bar under each encoder is not a ring: it does not answer the Mackie ring CCs 48–55; it is the unit's own soft-takeover indicator and blinks while a fixed Pitch Bend value sent to a fader differs from where the fader is. Faders have no motor and send Pitch Bend from −8192 to +8064 in steps of 128; the unit does not report their position until they move. The unit opens two input ports that repeat the same messages ("SMC-Mixer" and "MIDIIN2 (SMC-Mixer)"); the pattern picks the first. In user mode (as shipped) the messages are different: faders CC 0–7 on channel 1, encoders CC 0–7 on channel 3 (absolute), and the buttons switch their own lights.

認得的埠名稱

比對
/^smc[\s-]*mixer(\s+(midi|port))*(\s+\d+)?$/i

訊號

每個控制項都會發出 midi/smcmixer/<控制項>（0..1）和 /raw。打擊墊多一個 /hit，無段旋鈕多 /delta，琴鍵有 /on、/off 和 n<音高>。最後動到的那個控制項是 midi/smcmixer/last。

用起來

把 M-VAVE SMC-Mixer 用在你的作品裡

  1. 一行嵌入

    不用 import map，也不用建置。可以改 layout，加上 hardware="ask" 就有「接上」按鈕。

    html
    <script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="m-vave-smc-mixer" readout></oav-controller>

  2. 或用 iframe

    給只能貼 iframe 的地方。每個事件都以 postMessage 傳回來。

    html
    <iframe src="https://openaudiovisual.com/embed/controller/?profile=m-vave-smc-mixer&readout"
        width="720" height="432" style="border:0;max-width:100%" allow="midi"
        title="M-VAVE SMC-Mixer"></iframe>
<script>
  // every control the visitor plays arrives here
  addEventListener('message', (e) => {
    if (e.data?.source !== 'openav' || e.data.type !== 'control') return;
    console.log(e.data.detail.signal, e.data.detail.value);
  });
</script>

  3. 送進 Ableton、TouchDesigner、Resolume

    你在畫面上彈的，會變成真正的 MIDI，從 macOS 的 IAC 匯流排或 Windows 的 loopMIDI 埠送出。步驟在圖鑑頁。

    html
    <!-- what you play on this controller → the IAC bus (macOS) → Ableton, TouchDesigner, Resolume -->
<script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="m-vave-smc-mixer" midi-out="IAC" readout></oav-controller>
<!-- Windows: midi-out="loopMIDI" · let the visitor pick a port: midi-out="ask" -->

    macOS：音訊 MIDI 設定 → MIDI 工作室 → IAC 驅動程式 → 勾「裝置在線上」。Windows 11：內建的 Windows MIDI Services 有 loopback（我們沒有實測）；舊版 Windows：安裝 loopMIDI、新增一個埠，用 midi-out="loopMIDI"。

在 p5.js 裡，只要一行

一行注入會依這份設定檔裡的順序（也就是上面表格的順序）替旋鈕、推桿和打擊墊編號。網址加上 ?profile=m-vave-smc-mixer，畫面上的控制器就是這一台；真的 M-VAVE SMC-Mixer 接上時，會依埠名稱自動認出來。

javascript
document.head.prepend(Object.assign(document.createElement('script'), { src: 'https://openaudiovisual.com/p5/oav-p5.js?profile=m-vave-smc-mixer' }));

其他軟體

在這個專案以外使用這台控制器

同一份資料，換成別的程式讀得懂的檔案。除非上面的表格有寫，這些檔案都還沒在這台機器上實測過。

QLC+

輸入設定檔：每個控制項和 LED 值，給燈光控制用。複製到使用者資料夾（macOS ~/Library/Application Support/QLC+/InputProfiles，Linux ~/.qlcplus/inputprofiles，Windows %USERPROFILE%\QLC+\InputProfiles），重新開啟 QLC+。 接著把這個輸入的 MIDI 頻道設成 Omni。

m-vave-smc-mixer.qxi

Mixxx

這是起點，不是完成的 mapping：唱盤、EQ、hot cue 依序分給各個控制項。把兩個檔案放進 Preferences → Controllers → Open User Mapping Folder 開啟的資料夾，再用 Learning Wizard 改成你要的。

m-vave-smc-mixer.midi.xmlm-vave-smc-mixer.scripts.js
