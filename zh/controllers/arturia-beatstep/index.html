Arturia BeatStep

Arturia BeatStep 是 Arturia 的 MIDI 硬體控制器：16 個打擊墊、16 顆無段旋鈕。

它在 頻道 1 送出 CC、音符，設定檔引用了 3 份出處。 沒有任何控制項被標為未確認。

出處

  • 原廠 BeatStep User's Manual v1.0.1 (Arturia)ch. 8 default settings (CNTRL presets): encoders 1–16 CC 7 74 71 76 77 93 73 75 114 18 19 16 17 91 79 72, Absolute, Global channel; pads 1–8 notes 44–51, pads 9–16 notes 36–43, Gate; STOP / PLAY send MMC Stop (01) / Play (02) to device 127. §3.1: Global MIDI channel defaults to 1. §2.2: 16 endless encoders + the Level/Rate encoder (master level in CNTRL mode), 16 velocity- and pressure-sensitive pads; pads numbered 1–8 on the top row, 9–16 below (front-panel diagram)
  • 社群 Ableton Live 12 MIDI Remote Script BeatStep (decompiled; non-official)same encoder CCs except encoder 1 (it re-programs the unit by SysEx and puts encoder 1 on CC 10); pad rows 44–51 (top) and 36–43 (bottom)
  • 社群 DrivenByMoss BeatstepControllerDefinition.java (Bitwig; non-official)port name "Arturia BeatStep"

說明

CNTRL mode (red pads) with the factory preset, Global channel 1. The big Level/Rate encoder is not modelled: the manual's default table does not list it (it "controls the master level by default"); if it also sends CC 7 it will move encoder 1 on screen. STOP / PLAY send MMC SysEx and are not modelled (SysEx stays off). SEQ mode plays the step sequencer on the sequencer channel instead — not modelled. The encoders are endless but send absolute values in the default preset. Pad pressure: poly aftertouch is followed automatically if the unit sends it. The original BeatStep only — the BeatStep Pro is a different device and is not matched.

訊號

每個控制項都會發出 midi/beatstep/<控制項>（0..1）和 /raw。打擊墊多一個 /hit，無段旋鈕多 /delta，琴鍵有 /on、/off 和 n<音高>。最後動到的那個控制項是 midi/beatstep/last。

用起來

把 Arturia BeatStep 用在你的作品裡

  1. 一行嵌入

    不用 import map，也不用建置。可以改 layout，加上 hardware="ask" 就有「接上」按鈕。

    html
    <script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="arturia-beatstep" readout></oav-controller>

  2. 或用 iframe

    給只能貼 iframe 的地方。每個事件都以 postMessage 傳回來。

    html
    <iframe src="https://openaudiovisual.com/embed/controller/?profile=arturia-beatstep&readout"
        width="720" height="306" style="border:0;max-width:100%" allow="midi"
        title="Arturia BeatStep"></iframe>
<script>
  // every control the visitor plays arrives here
  addEventListener('message', (e) => {
    if (e.data?.source !== 'openav' || e.data.type !== 'control') return;
    console.log(e.data.detail.signal, e.data.detail.value);
  });
</script>

  3. 送進 Ableton、TouchDesigner、Resolume

    你在畫面上彈的，會變成真正的 MIDI，從 macOS 的 IAC 匯流排或 Windows 的 loopMIDI 埠送出。步驟在圖鑑頁。

    html
    <!-- what you play on this controller → the IAC bus (macOS) → Ableton, TouchDesigner, Resolume -->
<script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="arturia-beatstep" midi-out="IAC" readout></oav-controller>
<!-- Windows: midi-out="loopMIDI" · let the visitor pick a port: midi-out="ask" -->

    macOS：音訊 MIDI 設定 → MIDI 工作室 → IAC 驅動程式 → 勾「裝置在線上」。Windows 11：內建的 Windows MIDI Services 有 loopback（我們沒有實測）；舊版 Windows：安裝 loopMIDI、新增一個埠，用 midi-out="loopMIDI"。

在 p5.js 裡，只要一行

一行注入會依這份設定檔裡的順序（也就是上面表格的順序）替旋鈕、推桿和打擊墊編號。網址加上 ?profile=arturia-beatstep，畫面上的控制器就是這一台；真的 Arturia BeatStep 接上時，會依埠名稱自動認出來。

javascript
document.head.prepend(Object.assign(document.createElement('script'), { src: 'https://openaudiovisual.com/p5/oav-p5.js?profile=arturia-beatstep' }));
