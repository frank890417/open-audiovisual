Novation Launch Control XL (MK2)

Novation Launch Control XL (MK2) 是 Novation 的 MIDI 硬體控制器：24 顆旋鈕、8 支推桿、24 顆按鈕。

它在 頻道 9 送出 CC、音符，設定檔引用了 5 份出處。 沒有任何控制項被標為未確認。

出處

  • 原廠 Launch Control XL Programmer's Reference Guide v2 (Novation)8 user templates (slots 0–7) + 8 fixed factory templates (8–15); the MIDI channel of a message = its template, so factory template 1 is channel 9; one port named 'Launch Control XL n' (n = device ID, omitted for ID 1); buttons send 127 on press, 0 on release; LED = note-on (or CC for CC buttons) on the template's channel, velocity = 16 × green + red + 12 flags (12 off, 13/15 red low/full, 28/60 green low/full, 29/63 amber low/full, 62 yellow); knob LEDs addressed by notes 13–15, 29–31 … 125–127 (diagram p. 8)
  • 原廠 Launch Control XL Getting Started Guide v2 (Novation)hold User or Factory and press one of the bottom pads 1–8 to select a template; factory templates output a fixed set of CCs and notes; 24 pots, 8 faders, 16 buttons + 4 mode + 4 arrow buttons; same footprint as Launchpad S
  • 社群 Ableton Live 12 MIDI Remote Script Launch_Control_XL (decompiled; non-official)selects factory template 1 (LIVE_CHANNEL = 8, i.e. MIDI channel 9) by SysEx; send A knobs CC 13–20, send B 29–36, pan/device 49–56, faders 77–84; track focus notes 41–44, 57–60; track control notes 73–76, 89–92; device/mute/solo/arm notes 105–108; up/down/left/right CC 104–107; knob LED notes 13, 29, 45 … 125 (row 1), 14 … 126, 15 … 127
  • 社群 DrivenByMoss LaunchControlXLControlSurface.java (Bitwig; non-official)same numbers; every factory template uses them, on its own channel 9–16; single-LED buttons 127 = on
  • 社群 Ardour Novation_LaunchControl_XL.map (non-official)channel 9: knobs CC 13–20 / 29–36 / 49–56, faders 77–84, focus notes 41–44 57–60, control notes 73–76 89–92, left/right CC 106/107

說明

Factory template 1 (MIDI channel 9) — the template Ableton Live selects; select it by holding Factory and pressing bottom-row button 1. The other factory templates send the same numbers on channels 10–16 (copy the profile and change "channel"). User templates are editable in Novation Components and are not modelled. The User / Factory buttons switch templates inside the unit (SysEx F0 00 20 29 02 11 77 <template> F7) and send no control message. LED feedback: track focus amber-low idle / yellow when held, track control green-low / green, mode and arrow buttons 127 = on — the unit acts on it only while factory template 1 is selected. The LEDs under the knobs (notes 13–15, 29–31 … 125–127 on channel 9) are not driven. MK1 and MK2 share this protocol (Novation publishes one reference for both).

訊號

每個控制項都會發出 midi/lcxl/<控制項>（0..1）和 /raw。打擊墊多一個 /hit，無段旋鈕多 /delta，琴鍵有 /on、/off 和 n<音高>。最後動到的那個控制項是 midi/lcxl/last。

用起來

把 Novation Launch Control XL (MK2) 用在你的作品裡

  1. 一行嵌入

    不用 import map，也不用建置。可以改 layout，加上 hardware="ask" 就有「接上」按鈕。

    html
    <script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="novation-launch-control-xl-mk2" readout></oav-controller>

  2. 或用 iframe

    給只能貼 iframe 的地方。每個事件都以 postMessage 傳回來。

    html
    <iframe src="https://openaudiovisual.com/embed/controller/?profile=novation-launch-control-xl-mk2&readout"
        width="720" height="742" style="border:0;max-width:100%" allow="midi"
        title="Novation Launch Control XL (MK2)"></iframe>
<script>
  // every control the visitor plays arrives here
  addEventListener('message', (e) => {
    if (e.data?.source !== 'openav' || e.data.type !== 'control') return;
    console.log(e.data.detail.signal, e.data.detail.value);
  });
</script>

  3. 送進 Ableton、TouchDesigner、Resolume

    你在畫面上彈的，會變成真正的 MIDI，從 macOS 的 IAC 匯流排或 Windows 的 loopMIDI 埠送出。步驟在圖鑑頁。

    html
    <!-- what you play on this controller → the IAC bus (macOS) → Ableton, TouchDesigner, Resolume -->
<script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="novation-launch-control-xl-mk2" midi-out="IAC" readout></oav-controller>
<!-- Windows: midi-out="loopMIDI" · let the visitor pick a port: midi-out="ask" -->

    macOS：音訊 MIDI 設定 → MIDI 工作室 → IAC 驅動程式 → 勾「裝置在線上」。Windows 11：內建的 Windows MIDI Services 有 loopback（我們沒有實測）；舊版 Windows：安裝 loopMIDI、新增一個埠，用 midi-out="loopMIDI"。

在 p5.js 裡，只要一行

一行注入會依這份設定檔裡的順序（也就是上面表格的順序）替旋鈕、推桿和打擊墊編號。網址加上 ?profile=novation-launch-control-xl-mk2，畫面上的控制器就是這一台；真的 Novation Launch Control XL (MK2) 接上時，會依埠名稱自動認出來。

javascript
document.head.prepend(Object.assign(document.createElement('script'), { src: 'https://openaudiovisual.com/p5/oav-p5.js?profile=novation-launch-control-xl-mk2' }));
