AKAI APC mini mk2

AKAI APC mini mk2 是 AKAI Professional 的 MIDI 硬體控制器：64 個打擊墊、9 支推桿、17 顆按鈕。

它在 頻道 1 送出 音符、CC，設定檔引用了 5 份出處。 沒有任何控制項被標為未確認。

說明

Session (clip-launch) layout, the one the unit boots into: the 8×8 grid sends notes 0–63 on channel 1, bottom-left = 0. Drum mode (Shift + scene 6: notes 64–127 on channel 10) and Note mode (Shift + scene 7: notes on the second USB port) are not modelled — 學習 can rebind. Shift (note 122) is a plain button the host reads; the printed Shift legends are host functions. The unit has two USB ports: the first (…Control on Linux, plain "APC mini mk2" on Windows) carries everything here; the second carries Note mode only. LED feedback: grid pads lit at 100 % brightness (channel 7) with palette 37 (#00A9FF) while held; track buttons (red) and scene buttons (green) are single-colour, velocity 1 = on.

訊號

每個控制項都會發出 midi/apcmini2/<控制項>（0..1）和 /raw。打擊墊多一個 /hit，無段旋鈕多 /delta，琴鍵有 /on、/off 和 n<音高>。最後動到的那個控制項是 midi/apcmini2/last。

用起來

把 AKAI APC mini mk2 用在你的作品裡

  1. 一行嵌入

    不用 import map，也不用建置。可以改 layout，加上 hardware="ask" 就有「接上」按鈕。

    html
    <script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="akai-apc-mini-mk2" readout></oav-controller>

  2. 或用 iframe

    給只能貼 iframe 的地方。每個事件都以 postMessage 傳回來。

    html
    <iframe src="https://openaudiovisual.com/embed/controller/?profile=akai-apc-mini-mk2&readout"
        width="720" height="652" style="border:0;max-width:100%" allow="midi"
        title="AKAI APC mini mk2"></iframe>
<script>
  // every control the visitor plays arrives here
  addEventListener('message', (e) => {
    if (e.data?.source !== 'openav' || e.data.type !== 'control') return;
    console.log(e.data.detail.signal, e.data.detail.value);
  });
</script>

  3. 送進 Ableton、TouchDesigner、Resolume

    你在畫面上彈的，會變成真正的 MIDI，從 macOS 的 IAC 匯流排或 Windows 的 loopMIDI 埠送出。步驟在圖鑑頁。

    html
    <!-- what you play on this controller → the IAC bus (macOS) → Ableton, TouchDesigner, Resolume -->
<script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="akai-apc-mini-mk2" midi-out="IAC" readout></oav-controller>
<!-- Windows: midi-out="loopMIDI" · let the visitor pick a port: midi-out="ask" -->

    macOS：音訊 MIDI 設定 → MIDI 工作室 → IAC 驅動程式 → 勾「裝置在線上」。Windows：安裝 loopMIDI 並新增一個埠，用 midi-out="loopMIDI"。

在 p5.js 裡，只要一行

一行注入會依這份設定檔裡的順序（也就是上面表格的順序）替旋鈕、推桿和打擊墊編號。網址加上 ?profile=akai-apc-mini-mk2，畫面上的控制器就是這一台；真的 AKAI APC mini mk2 接上時，會依埠名稱自動認出來。

javascript
document.head.prepend(Object.assign(document.createElement('script'), { src: 'https://openaudiovisual.com/p5/oav-p5.js?profile=akai-apc-mini-mk2' }));

  circle(random(width), random(height), velocity * 100);
}
