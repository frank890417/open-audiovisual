Korg nanoKEY2

Korg nanoKEY2 是 KORG 的 MIDI 硬體控制器：25 個琴鍵、2 顆按鈕、1 條觸控條。

它在 頻道 1 送出 彎音、CC、音符，設定檔引用了 3 份出處。 其中 25 個控制項標了未確認：數字是照目前出處的最佳判讀，按「學習」一次就能重新對應。

這一台還沒有寫 LED 回饋，OAV 不會讓它的燈亮，但每個控制項照樣可以彈、照樣送出各自的訊息。

個別控制項的說明

  • keys Lowest key at octave 0 is not printed in the docs; 48 is assumed. Keys follow any note on the channel, so OCT−/OCT+ just scroll the on-screen keys.

出處

  • 原廠 nanoKEY2 Parameter Guide (KORG)factory settings: SUSTAIN button = CC 64, MOD button = CC 1 (momentary or toggle, on/off values editable); PITCH−/PITCH+ send pitch bend that returns to centre on release; keyboard, pitch, mod and sustain all transmit on the Global MIDI channel
  • 原廠 nanoKEY2 MIDI Implementation v1.00 (KORG)transmits note on/off (keyboard; note-off velocity 64), control change (MOD, SUSTAIN), pitch bend (PITCH buttons)
  • 原廠 nanoKEY2 Owner's Manual (KORG)ports: Mac "nanoKEY2 KEYBOARD" (in) / "nanoKEY2 CTRL" (out), Windows "nanoKEY2", with the KORG driver "nanoKEY2 1 KEYBOARD" / "nanoKEY2 1 CTRL"; OCT−/OCT+ shift ±4 octaves; 325 × 83 × 13 mm

說明

Factory settings. KORG does not print the factory Global MIDI channel; channel 1 is assumed (set it in KORG KONTROL Editor if yours differs, or use the element's channel attribute). PITCH− and PITCH+ are two buttons that send one pitch-bend message, so they are drawn as one bipolar strip. OCT−/OCT+ shift the keyboard inside the unit and send nothing of their own. No LED feedback.

訊號

每個控制項都會發出 midi/nanokey2/<控制項>（0..1）和 /raw。打擊墊多一個 /hit，無段旋鈕多 /delta，琴鍵有 /on、/off 和 n<音高>。最後動到的那個控制項是 midi/nanokey2/last。

用起來

把 Korg nanoKEY2 用在你的作品裡

  1. 一行嵌入

    不用 import map，也不用建置。可以改 layout，加上 hardware="ask" 就有「接上」按鈕。

    html
    <script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="korg-nanokey2" readout></oav-controller>

  2. 或用 iframe

    給只能貼 iframe 的地方。每個事件都以 postMessage 傳回來。

    html
    <iframe src="https://openaudiovisual.com/embed/controller/?profile=korg-nanokey2&readout"
        width="720" height="206" style="border:0;max-width:100%" allow="midi"
        title="Korg nanoKEY2"></iframe>
<script>
  // every control the visitor plays arrives here
  addEventListener('message', (e) => {
    if (e.data?.source !== 'openav' || e.data.type !== 'control') return;
    console.log(e.data.detail.signal, e.data.detail.value);
  });
</script>

  3. 送進 Ableton、TouchDesigner、Resolume

    你在畫面上彈的，會變成真正的 MIDI，從 macOS 的 IAC 匯流排或 Windows 的 loopMIDI 埠送出。步驟在圖鑑頁。

    html
    <!-- what you play on this controller → the IAC bus (macOS) → Ableton, TouchDesigner, Resolume -->
<script type="module" src="https://openaudiovisual.com/packages/midi/element.js"></script>
<oav-controller profile="korg-nanokey2" midi-out="IAC" readout></oav-controller>
<!-- Windows: midi-out="loopMIDI" · let the visitor pick a port: midi-out="ask" -->

    macOS：音訊 MIDI 設定 → MIDI 工作室 → IAC 驅動程式 → 勾「裝置在線上」。Windows 11：內建的 Windows MIDI Services 有 loopback（我們沒有實測）；舊版 Windows：安裝 loopMIDI、新增一個埠，用 midi-out="loopMIDI"。

在 p5.js 裡，只要一行

一行注入會依這份設定檔裡的順序（也就是上面表格的順序）替旋鈕、推桿和打擊墊編號。網址加上 ?profile=korg-nanokey2，畫面上的控制器就是這一台；真的 Korg nanoKEY2 接上時，會依埠名稱自動認出來。

javascript
document.head.prepend(Object.assign(document.createElement('script'), { src: 'https://openaudiovisual.com/p5/oav-p5.js?profile=korg-nanokey2' }));
在草稿裡控制項訊息
notePressed(note, velocity)48–72（C3–C5）琴鍵按下
p5.js 草稿
function draw() {
  background(20);
}

function notePressed(note, velocity) {   // a key goes down
  circle(random(width), random(height), velocity * 100);
}

無段旋鈕、按鈕、滾輪和觸控條沒有編號：用 midi.cc[編號] 讀（編號見上面的表），或寫 controlChange(cc, value, ch) 接。
