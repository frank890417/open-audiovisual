用在程式裡

把 Chauvet DJ SlimPAR Pro RGBA 寫進你的程式

貼進任何網頁的 <script type="module">：它從這個網站載入 @openav/devices 和 @openav/dmx，用模式 10ch 把燈 patch 在位址 1，印出它會送出的位元組。要真的送出去，用 dmxTransport()（經輸出橋接程式送 Art-Net 或 sACN，或用 Web Serial 接 Enttec DMX USB Pro）。

javascript
import { device } from 'https://openaudiovisual.com/packages/devices/index.js';
import { Patch, DmxEngine } from 'https://openaudiovisual.com/packages/dmx/index.js';

const light = await device('chauvet-dj-slimpar-pro-rgba');   // Chauvet DJ SlimPAR Pro RGBA
const patch = new Patch();
light.patch(patch, { id: 'light1', address: 1, mode: '10ch' });   // 10 channels from address 1
const engine = new DmxEngine(patch);
engine.set('light1', { dimmer: 1, color: [1, 0.5, 0] });
console.log(engine.render(0).bytes(1).slice(0, 10).join(' '));
// → 255 0 0 0 255 0 0 0 0 0

它照順序印出模式 10ch 的各個通道：

  1. dimmer 255
  2. red 0
  3. green 0
  4. blue 0
  5. amber 255
  6. colorMacros 0
  7. strobe 0
  8. autoPrograms 0
  9. autoProgramSpeed 0
  10. dimmerCurve 0
