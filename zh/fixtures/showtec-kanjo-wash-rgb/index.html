用在程式裡

把 Showtec Kanjo Wash RGB 寫進你的程式

貼進任何網頁的 <script type="module">：它從這個網站載入 @openav/devices 和 @openav/dmx，用模式 14ch 把燈 patch 在位址 1，印出它會送出的位元組。要真的送出去，用 dmxTransport()（經輸出橋接程式送 Art-Net 或 sACN，或用 Web Serial 接 Enttec DMX USB Pro）。

javascript
import { device } from 'https://openaudiovisual.com/packages/devices/index.js';
import { Patch, DmxEngine } from 'https://openaudiovisual.com/packages/dmx/index.js';

const light = await device('showtec-kanjo-wash-rgb');   // Showtec Kanjo Wash RGB
const patch = new Patch();
light.patch(patch, { id: 'light1', address: 1, mode: '14ch' });   // 14 channels from address 1
const engine = new DmxEngine(patch);
engine.set('light1', { dimmer: 1, color: [1, 0.5, 0], pan: 0.5, tilt: 0.25 });
console.log(engine.render(0).bytes(1).slice(0, 14).join(' '));
// → 128 0 64 0 0 255 0 255 128 0 0 0 0 0

它照順序印出模式 14ch 的各個通道：

  1. pan 128
  2. panFine 0
  3. tilt 64
  4. tiltFine 0
  5. panTiltSpeed 0
  6. dimmer 255
  7. strobe 0
  8. red 255
  9. green 128
  10. blue 0
  11. colorPresets 0
  12. colorSpeed 0
  13. programs 0
  14. factoryReset 0

出處、授權、驗證

通道資料來自 Open Fixture Library（MIT），檔案 fixtures/showtec/kanjo-wash-rgb.json，commit 849343f6，作者 Flo Edelmann, Felix Edelmann。由 tools/import-ofl.mjs 轉換，保留每個通道的作用、預設值和各段數值。

授權：MIT。 本專案還沒有人拿實際的燈確認過這個檔案：每個值都照出處寫。

出處

  • Open Fixture Library fixtures/showtec/kanjo-wash-rgb.json by Flo Edelmann, Felix Edelmann; MIT; channel jobs and ranges read from OFL's capabilities, not checked by this project
  • Showtec Kanjo Wash RGB: manual linked from the OFL file; not read by this project

檔案裡的說明

Imported from the Open Fixture Library. Nobody has checked it on a light for this project. OFL asks for help: Strobe: At which DMX values is strobe disabled? When is the lamp constantly on/off? Color Presets: How does Color Change differ from Jump or Fade (Gradient)?
