用在程式裡

把 Stairville MH-100 寫進你的程式

貼進任何網頁的 <script type="module">：它從這個網站載入 @openav/devices 和 @openav/dmx，用模式 14ch 把燈 patch 在位址 1，印出它會送出的位元組。要真的送出去，用 dmxTransport()（經輸出橋接程式送 Art-Net 或 sACN，或用 Web Serial 接 Enttec DMX USB Pro）。

javascript
import { device } from 'https://openaudiovisual.com/packages/devices/index.js';
import { Patch, DmxEngine } from 'https://openaudiovisual.com/packages/dmx/index.js';

const light = await device('stairville-mh-100');   // Stairville MH-100
const patch = new Patch();
light.patch(patch, { id: 'light1', address: 1, mode: '14ch' });   // 14 channels from address 1
const engine = new DmxEngine(patch);
engine.set('light1', { dimmer: 1, color: [1, 0.5, 0], pan: 0.5, tilt: 0.25 });
console.log(engine.render(0).bytes(1).slice(0, 14).join(' '));
// → 128 0 64 0 0 255 255 128 0 0 0 0 0 0

它照順序印出模式 14ch 的各個通道：

  1. pan 128
  2. panFine 0
  3. tilt 64
  4. tiltFine 0
  5. panTiltSpeed 0
  6. dimmer 255
  7. red 255
  8. green 128
  9. blue 0
  10. white 0
  11. colorTemperature 0
  12. constantColor 0
  13. strobe 0
  14. specialFunctions 0
