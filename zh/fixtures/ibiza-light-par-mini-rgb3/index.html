用在程式裡

把 Ibiza light LED PAR CAN 12x3W 3-in-1 RGB 寫進你的程式

貼進任何網頁的 <script type="module">：它從這個網站載入 @openav/devices 和 @openav/dmx，用模式 par-mini-rgb3 把燈 patch 在位址 1，印出它會送出的位元組。要真的送出去，用 dmxTransport()（經輸出橋接程式送 Art-Net 或 sACN，或用 Web Serial 接 Enttec DMX USB Pro）。

javascript
import { device } from 'https://openaudiovisual.com/packages/devices/index.js';
import { Patch, DmxEngine } from 'https://openaudiovisual.com/packages/dmx/index.js';

const light = await device('ibiza-light-par-mini-rgb3');   // Ibiza light LED PAR CAN 12x3W 3-in-1 RGB
const patch = new Patch();
light.patch(patch, { id: 'light1', address: 1, mode: 'par-mini-rgb3' });   // 7 channels from address 1
const engine = new DmxEngine(patch);
engine.set('light1', { dimmer: 1, color: [1, 0.5, 0] });
console.log(engine.render(0).bytes(1).slice(0, 7).join(' '));
// → 0 0 0 255 255 128 0

它照順序印出模式 par-mini-rgb3 的各個通道：

  1. mode 0
  2. colorMacro 0
  3. effectSpeed 0
  4. dimmer 255
  5. red 255
  6. green 128
  7. blue 0
