不接燈也能推 Generic RGB par

滑桿走的是演出用的同一個 Patch 和同一套顏色拆解，表格就是這台燈會收到的位元組，一個位址一格。什麼都不會送出去。

DMX 通道

Generic RGB par 每個模式的每個通道

直接從燈具檔產生，就是 patch 讀的那張表。通道編號從燈具的起始位址算起，值是 0–255 的位元組。

模式 3ch · 3 channel 3 個通道

通道名稱類型預設每段數值的作用
1red顏色: 紅00–255
2green顏色: 綠00–255
3blue顏色: 藍00–255

用在程式裡

把 Generic RGB par 寫進你的程式

貼進任何網頁的 <script type="module">：它從這個網站載入 @openav/devices 和 @openav/dmx，用模式 3ch 把燈 patch 在位址 1，印出它會送出的位元組。要真的送出去，用 dmxTransport()（經輸出橋接程式送 Art-Net 或 sACN，或用 Web Serial 接 Enttec DMX USB Pro）。

javascript
import { device } from 'https://openaudiovisual.com/packages/devices/index.js';
import { Patch, DmxEngine } from 'https://openaudiovisual.com/packages/dmx/index.js';

const light = await device('generic-rgb');   // Generic RGB par
const patch = new Patch();
light.patch(patch, { id: 'light1', address: 1, mode: '3ch' });   // 3 channels from address 1
const engine = new DmxEngine(patch);
engine.set('light1', { dimmer: 1, color: [1, 0.5, 0] });
console.log(engine.render(0).bytes(1).slice(0, 3).join(' '));
// → 255 128 0

它照順序印出模式 3ch 的各個通道：

  1. red 255
  2. green 128
  3. blue 0
