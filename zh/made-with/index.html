加上你的

OpenProcessing 上貼了那一行的草圖算。只用了一個套件的演出也算。

  1. 到 GitHub 開 「我做了這個」表單，填標題、你的名字、一個連結和一兩句話，我們把它加上來。
  2. 或是自己改 made-with/works.json 再開 pull request：一件作品一個物件，欄位就是檔案裡看到的那些。

一筆就是一個連結加幾句話。我們不存放你的任何檔案，作品還是你的。要改、要拿掉，隨時用同樣的方式說一聲。

一個頁面怎麼說出自己用了什麼

用 createShow() 開演的頁面，會在頁面裡放一個標籤：<meta name="generator" content="open-audiovisual 0.12.0">。WordPress 和 Hugo 留的也是這種標籤。它不會把任何東西送到任何地方，是給檢視原始碼的人看的，也讓公開網頁的搜尋與普查認得出來。createShow({ signature: false }) 就不放。

另外，一場演出和嵌入的控制器各會送出一筆匿名紀錄，裡面只有所在網站的網址，沒有別的，telemetry: false 可以關掉。p5.js 的那一行預設什麼都不送，要你自己打開才會。送什麼、絕對不送什麼、每一個開關。
