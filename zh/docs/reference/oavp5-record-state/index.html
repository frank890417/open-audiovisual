OAVp5.record.state#

變數oav-p5
OAVp5.record.state

錄影現在在哪個階段：'off'、'starting'、'on' 或 'saving'。

recordingIsOn 就是 state === 'on'。其他階段有影響的時候才需要讀它：按鈕可以顯示「啟動中……」和「儲存中……」，在檔案還在存的時候不接受新的一支。

型別
String
範圍
off | starting | on | saving

一開始是 'off'。一支錄影會依序是 'starting'（錄影程式載入中，第一次才會有）、'on'（錄影中）、'saving'（檔案製作中），然後回到 'off'。

每個草圖的第一行

js
document.head.prepend(Object.assign(document.createElement('script'), { src: 'https://openaudiovisual.com/p5/oav-p5.js' }));

相關

  • recordingIsOn 現在有沒有在錄影。
  • startRecording() 把畫布和草圖發出的聲音錄成一支影片檔，並回傳一個 promise，告訴你錄影有沒有開始。
  • stopRecording() 停止錄影，影片完成後會下載，並交給 recordingSaved(info) 和回傳的 promise。
  • OAVp5.record 錄影相關名稱背後的物件：狀態、時間、最後一支檔案、這個瀏覽器能寫的格式，以及存圖的函式。
