oav-p5 參考 · 載入選項

corner#

選項oav-p5
?oav_corner=right | left

🎹 按鈕、它的提示卡片和精簡面板放在視窗的哪一邊：right 或 left。

把 🎹 移到左邊或右邊，它旁邊出現的卡片也跟著移動。scope() 畫在對面那一側，所以兩個不會碰在一起。在 openprocessing.org 上預設是 left，因為 OpenProcessing 自己的圖示在右上角。

型別
String
可用的值
right | left
預設
right (left on OpenProcessing)

left 以外的任何值都當作 right。

注意

  • 要在 oav-p5 載入之前設好。寫在載入那一行上面的 window.OAV_P5 = { corner: … }; 優先，其次是網頁網址上的 ?oav_corner=…，最後是 script 自己網址上的 ?corner=…。寫在 window.OAV_P5 裡的值會被轉成文字，所以要寫 'off'，不要寫 false。在 OpenProcessing 上，網頁網址要寫成 ?sketch_oav_corner=…（專案的 README 說 OpenProcessing 會把它轉給草圖）。

每個草圖的第一行

js
document.head.prepend(Object.assign(document.createElement('script'), { src: 'https://openaudiovisual.com/p5/oav-p5.js' }));

底下的範例為了簡短把這一行省略了。按「複製」會自動把它放在最上面，貼進 OpenProcessing（或 p5 編輯器）就能直接跑。

相關

  • dock 🎹 按鈕和它的提示卡片放在視窗的哪個邊：bottom 或 top。有設定的話，面板一開始也在這個邊。
  • panel 🎹 面板一開始是收起來、打開，還是根本沒有：closed、open 或 off。
  • compact 把 🎹 面板顯示成角落的一個小方塊，高度是視窗的三分之一，而不是整條橫幅：on 或 off。
  • scope() 把 value 顯示在網頁角落的小示波器上，並原樣還給你，所以可以包住任何運算式來觀察它。
