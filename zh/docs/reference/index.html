控制器上旋鈕的位置，從 0 到 1：knob1 是第一顆旋鈕，knob2 是第二顆，一直到 knob8。

像讀 mouseX 一樣在 draw() 裡讀：background(knob1 * 255)。旋鈕的編號照控制器上印的順序，所以在 OAV 有設定檔的任何控制器上，旋鈕 1 就是旋鈕 1：MiniLab 3 的第一顆是 CC 74，LPD8 的是 CC 70。草圖完全不用知道 CC 號碼。

遇到 OAV 沒有設定檔的控制器，你轉的第一顆旋鈕就變成 knob1，下一顆是 knob2，依你轉的順序往下排。超過八顆就用 knob(n)。

型別
Number
範圍
0..1

旋鈕轉動的時候才會改變，不是每個畫面一次。草圖只要讀最新的值。旋鈕還沒轉過之前是 0。

micLevel#

變數oav-p5
micLevel

麥克風聽到的聲音有多大聲，從 0（安靜的房間）到 1（大喊）。

像讀 mouseX 一樣在 draw() 裡直接讀：circle(width / 2, height / 2, 50 + micLevel * 300)，有人說話圓就變大。它是以分貝量的音量，跟耳朵聽起來的感覺一致，而且是從房間本身量起：量表的底部跟著房間的底噪走（一兩秒內安頓下來，每秒最多往上爬 1.5 dB，所以人聲不會變成新的安靜），−10 dBFS（對著筆電大喊）就是 1。

實際上，安靜的房間是 0，小聲說話約 0.4 到 0.6，大喊接近 1。麥克風很小聲或離得很遠的話，用 micSensitivity() 把它調大。

它跟著瀏覽器的動畫畫面更新，不是跟著 draw()，所以用 frameRate(10) 跑的草圖讀到的還是最新的值。分頁被藏起來時數字會停住（瀏覽器在那時會暫停動畫畫面）。
