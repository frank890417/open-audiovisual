noteReleased()#

事件oav-p5
function noteReleased(note) {}

你來定義這個函式。每當有一個鍵（或打擊墊）放開，oav-p5 就呼叫它。

notePressed() 的另一半，就像 keyReleased() 之於 keyPressed()：

js
function noteReleased(note) {
  // 有一個鍵放開了
}

參數

名稱型別說明
noteNumber被放開的那個鍵的 MIDI 號碼。

相關

  • notePressed() 你來定義這個函式。每當有一個鍵（或打擊墊）按下，oav-p5 就呼叫它。
  • padReleased() 你來定義這個函式。每當打擊墊放開，oav-p5 就呼叫它。
  • noteOff() 你來定義這個函式。每收到一個 MIDI 的 note-off，oav-p5 就呼叫它，帶著是哪個鍵、哪個通道。
  • noteIsDown() 鍵 n（MIDI 號碼，或像 'C4' 這樣的音名）按著的時候是 true。
