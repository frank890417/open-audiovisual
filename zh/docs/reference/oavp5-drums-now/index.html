OAVp5.drums.now#

物件oav-p5
OAVp5.drums.now

鼓機此刻聽到的樣子，一次拿齊：小節、格、兩個相位，以及那一行字裡哪些字亮著。

卡片就是用它讓正在響的字亮起來。想一次拿到那一行字和亮著的字的時候讀它，例如把那一行字畫在畫布上，並標出正在響的字。鼓機載入之前，它給的是零和空的 text。

型別
Object
範圍
{ bar, step, phase, beatPhase, tokens, mode, text }

每次讀都是一個新的物件。phase 和 beatPhase 就是 drumPhase 和 beatPhase。tokens 是 { start, end } 的清單，標出 text 裡現在正在響的那幾個字的位置。mode 在播一行節奏時是 'string'，預設節奏或你自己畫的格子是 'grid'。text 是那一行字。

每個草圖的第一行

js
document.head.prepend(Object.assign(document.createElement('script'), { src: 'https://openaudiovisual.com/p5/oav-p5.js' }));

底下的範例為了簡短把這一行省略了。按「複製」會自動把它放在最上面，貼進 OpenProcessing（或 p5 編輯器）就能直接跑。

範例

相關

  • OAVp5.drums.src 現在播的那一行節奏，例如 'bd*4, [~ sd]*2, hh*8'。鼓機載入之前是空字串。
  • drumPhase 鼓機走到這一小節的哪裡，從 0 平滑地增加到快要 1，是你耳朵聽到的位置。
  • beatPhase 鼓機走到這一拍的哪裡，從 0 平滑地增加到快要 1，一小節會跑四次。
  • drumStep 鼓機剛剛播到這一小節 16 格裡的第幾格，從 0 到 15。
  • drumBar 鼓機現在在第幾小節，從啟動的時候起算，第一小節是 1。
