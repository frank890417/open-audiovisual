OAVp5.chop.slots()#

函式oav-p5
OAVp5.chop.slots()

列出 CHOP 函式現在用的每一個記憶：是哪一種、怎麼找到它、最新的值是多少。

用來查為什麼兩個呼叫好像共用同一個記憶，或迴圈是不是做出了好幾百個：OAVp5.chop.slots().length 就是現在有幾個。它只讀取狀態，不會改任何東西。

回傳

Array<Object> 每一個記憶一筆 { kind, key, mode, value }。kind 是哪個函式（'lag'、'spring' …）。key 是靠順序找到的呼叫的 '#1'、'#2'，有名字的就是名字，靠行號對應的就是那一行程式。mode 說明是哪一種：'order'、'name' 或 'site'。value 是它最近一次的輸出（trail 沒有）。

注意

  • 這是進階用法。🩺 和測試會用到，草圖很少需要。

相關

  • OAVp5.chop.reset() 忘掉叫 name 的那個記憶（lag、speed 的累計、計數…），不給名字就全部忘掉：下一次呼叫會重新開始。
  • OAVp5.chop CHOP 函式放在同一個地方，加上它們背後模組的狀態：OAVp5.chop.lag(…)、.state、.slots()、.reset()。
  • lag() 讓數值平順地跟上 value，不要跳：上升花 up 秒，下降花 down 秒（TouchDesigner 的 Lag CHOP）。
