OAVp5.chop.module#

變數oav-p5
OAVp5.chop.module

@openav/chop 模組本身，載好之後才有，之前是 null：CHOP 函式底下用的那些類別和函式。

要用到比 p5 風格呼叫更底層的東西時才需要：OAVp5.chop.module.DEFAULTS 列出這些函式用的預設值，new OAVp5.chop.module.Lag({ up: 0.1 }) 做出一個你自己保管的 lag。先確認它不是 null。

型別
Object | null

第一次呼叫 CHOP 函式、而且模組載好之前是 null，之後就是那個模組（Lag、Spring、Trail、envelope()、DEFAULTS 等等）。

注意

  • 這是進階用法。這個模組也以 @openav/chop 發布，給不經過 oav-p5 的草圖和演出使用。
