OAVp5.mic.error#

變數oav-p5
OAVp5.mic.error

麥克風為什麼沒開起來，用瀏覽器的錯誤名稱表示，像 'NotAllowedError'，沒有錯誤的時候是 null。

給想比卡片說得更多的草圖用：if (OAVp5.mic.error === 'NotAllowedError') …。🎹 旁邊的卡片已經用使用者的語言，針對每一種告訴他要按什麼了，這是同一件事給你的程式用。

型別
String | null

一開始是 null，麥克風開起來之後又回到 null。失敗之後是瀏覽器的錯誤名稱（被拒絕是 'NotAllowedError' 或 'SecurityError'，沒有麥克風是 'NotFoundError'，被別的程式占住是 'NotReadableError'），或是在不能詢問的頁面上的 'no getUserMedia'。

每個草圖的第一行

document.head.prepend(Object.assign(document.createElement('script'), { src: 'https://openaudiovisual.com/p5/oav-p5.js' }));
