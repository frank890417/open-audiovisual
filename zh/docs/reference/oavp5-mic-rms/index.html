OAVp5.mic.rms#

變數oav-p5
OAVp5.mic.rms

麥克風原始的音量：平滑過的 RMS，0 到 1，是 oav-p5 把它換成 micLevel 的分貝刻度之前的值。

最新一個畫面裡所有取樣的均方根，稍微平滑過。它是線性的，就像波形畫出來的樣子，所以適合快速檢查，或是用在你自己的刻度上。micLevel 就是用它算出來的：OAVp5.mic.db 是同一個數字換成 dBFS，OAVp5.mic.floor 是房間本身的底噪，單位也是 dBFS。

型別
Number
範圍
0..1

麥克風開著的時候，每個畫面更新一次，關著是 0。對著筆電說話是個很小的數字，程式碼裡的註解說大約在 0.01 到 0.05，所以 micLevel 才改用分貝來算。

說話和音樂的典型數值要看麥克風和房間。人聲的 0.01 到 0.05 是程式碼註解裡的數字，這裡沒有量過。

相關

  • OAVp5.mic.db 麥克風的音量，單位是相對滿刻度的分貝（dBFS）：0 是最大聲，−100 是無聲或麥克風關著。
  • OAVp5.mic.floor oav-p5 量到的房間本身的底噪，單位是 dBFS：micLevel 把它（再加 6 dB）當成安靜的那個音量。
  • OAVp5.mic.level 跟 micLevel 一樣的 0 到 1 音量，讀它不會把麥克風打開。
  • micLevel 麥克風聽到的聲音有多大聲，從 0（安靜的房間）到 1（大喊）。
