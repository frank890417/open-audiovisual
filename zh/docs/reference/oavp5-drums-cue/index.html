OAVp5.drums.cue()#

函式oav-p5
OAVp5.drums.cue(bar, name, [every])

跟 cue(bar, name, every) 一樣，但會回傳建立出來的 cue（或原本就有的那個），bar 無效的時候回傳 null。

想拿著這個 cue 的時候用它，例如想知道它在第幾格發動。只是安排計畫的話，cue() 比較短。所有 cue 的清單在 OAVp5.drums.cues。

參數

名稱型別說明
barNumber第幾小節，從 1 算起，4.5 是第 4 小節的一半。見 cue()。
nameAny這個 cue 的名字。
everyNumber每隔幾小節再來一次，0 或不傳：只一次。 可省略

回傳

Object | null 這個 cue：{ bar, name, every, at, period, key }，其中 at 和 period 以格為單位。bar 小於 1 或不是數字就是 null。重複前面呼叫過的，會回傳已經存在的那個 cue。

相關

  • cue() 替某一小節安排事情：到了第 bar 小節，就呼叫 cueFired(name, bar)，cueName 變成 name，給了 every，之後每隔那麼多小節再來一次。
  • OAVp5.drums.cues 到目前為止宣告過的所有 cue，照宣告的順序排。
  • cueFired() 一個由你定義的事件函式：用 cue() 宣告的 cue，到了它的那一小節就會呼叫它，帶著 cue 的名字和小節。
