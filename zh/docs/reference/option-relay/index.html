relay#

選項oav-p5
?oav_relay=a ws:// or wss:// address

手機和 link 房間用來傳話的中繼的位址：一個 WebSocket 網址。

📱 按鈕會顯示一個 QR code，讓手機打開遙控頁面，手機的 MIDI 分頁就是透過這個中繼來彈你的草圖。link 的房間也用它。預設是專案的公開中繼。想讓資料只留在自己的機器上，就從儲存庫的副本執行 node packages/relay/server.js，再把 relay 指到 ws://localhost:7458/relay。

型別
String (URL)
可用的值
a ws:// or wss:// address
預設
wss://remote.cheyuwu.com/relay

照你給的使用。

注意

  • 載入的時候不會連它。要打開 📱 卡片（OAVp5.phone()）或設了 link 才會用到。
  • 要在 oav-p5 載入之前設好。寫在載入那一行上面的 window.OAV_P5 = { relay: … }; 優先，其次是網頁網址上的 ?oav_relay=…，最後是 script 自己網址上的 ?relay=…。寫在 window.OAV_P5 裡的值會被轉成文字，所以要寫 'off'，不要寫 false。在 OpenProcessing 上，網頁網址要寫成 ?sketch_oav_relay=…（專案的 README 說 OpenProcessing 會把它轉給草圖）。

每個草圖的第一行

js
document.head.prepend(Object.assign(document.createElement('script'), { src: 'https://openaudiovisual.com/p5/oav-p5.js' }));

底下的範例為了簡短把這一行省略了。按「複製」會自動把它放在最上面，貼進 OpenProcessing（或 p5 編輯器）就能直接跑。

相關

  • room 手機要加入哪個房間才能彈這個頁面：預設是每個瀏覽器自己亂數取的一個。
  • remote 📱 的 QR code 在手機上打開的那個遙控頁面的位址。
  • link 加入一個房間：房間相同的 oav-p5 頁面，會透過中繼聽到彼此的程式送出的聲音。填房間名，空的就是不加入。
  • OAVp5.phone() 顯示 📱 卡片：一個 QR code，讓手機打開遙控頁面，手機上的 MIDI 分頁就能彈這個草圖。回傳房間名稱。
