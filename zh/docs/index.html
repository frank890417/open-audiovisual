open-audiovisual 使用手冊

跑起來、寫作品、上台演出需要知道的事，一章一頁。這裡寫到的 API 名稱、選項和訊號，都對照過原始碼，兩者對不上時，以程式碼為準。

oav-p5 速查表 →用 oav-p5 的 p5 草圖會用到的名字放在一頁，附圖：喊、敲、彈、讓數字好用。可以印成一張 A4。 API 參考 →只想查一個名稱？oav-p5 的每個變數、函式、事件與選項，和每個套件的匯出，都能搜尋，每一條附能直接跑的範例。

  1. 01簡介

    open-audiovisual（OAV）是一套在瀏覽器裡跑的 JavaScript 框架，給現場影音表演用。

    • 給誰用
    • 四層與兩條主軸
    • 從哪裡來
    • 怎麼讀這本手冊

  2. 02快速開始

    挑一個最接近你手上東西的。

    • 三種進場方式
    • 跑起來
    • 一個檔，不用 clone
    • 固定一個版本
    • 用哪個瀏覽器
    • 你看到的是什麼
    • 不用硬體也能彈
    • 你的第一個世界
    • 做一個新範例
    • 檢查你的成果

  4. 04架構

    open-audiovisual 是一套資料層框架。

    • 畫面迴圈
    • L1 · 輸入：訊號（Signals）
    • L2 · 映射：映射器（Mapper）
    • L3 · 世界：舞台（Stage）
    • L4 · 輸出：影像與聲音兩條分支，都是選用
    • 主軸 · 時間軸
    • 主軸 · 後台監看
    • 主軸周邊：控台與手機

  10. 10DMX 燈光

    DMX512 是告訴舞台燈要做什麼的方法：一條線傳一個 universe，裡面有 512 個通道，每個通道是 0 到 255 的數字，每秒送大約 40 次。

    • 離開電腦的三條路
    • 燈具和 patch
    • scene、cue、chase 和 effect
    • 每一格的位元組送去哪裡
    • 用聲音和控制器推燈
    • 安全
    • 沒有硬體時怎麼看
    • 在 TouchDesigner 裡確認
    • 還沒有用真的硬體測過

  12. 12多螢幕拼接：一張畫布

  23. 23疑難排解

    這些都是排練和寫程式時真的遇過的問題，附上解法。

    • 瀏覽器主控台出現 ws://…:7457 錯誤
    • Chrome 跳出「區域網路」或「這台裝置上的應用程式」的詢問
    • 手機加入卡片顯示「relay offline」
    • 看不到任何 MIDI 裝置
    • 聽不到 IAC 匯流排上的 DAW
    • 線被拔掉之後，DAW 就沒聲音了
    • 接兩台控制器時，一條路由對兩台都有反應
    • 電腦鍵盤按了沒反應
    • Learn 綁錯了訊號
    • 時間軸不再推動某個參數
    • 在程式碼裡改了路由，卻什麼都沒變
    • 接到 sound/cutoff 的路由只在 0 和 1 之間動
    • 鏡頭或麥克風啟動不了
    • 沒有聲音
    • 加了那一行的 p5.js 草圖不對勁
    • Strudel 收不到 OAV Virtual MIDI
    • 在 iPhone 上，手機的傾斜和敲擊都沒作用
    • 部署之後，網站還在跑舊的程式碼
    • 視窗退到背景時，演出變慢
    • 用到 CDN 的範例，連網時能跑，離線就不行
    • 連接埠已經被佔用
    • 輸出視窗打不開，或一直是黑的
    • 照片沒有定位到桌上的某台螢幕
