p5.js · MIDI · 一行

p5.js 一行接上

現場試玩：範例 15 → 手冊裡的同一章 GitHub 上的 p5/ ↗

那一頁的草圖就是普通的 p5.js，第一行是這一行。點 🎹、轉旋鈕、敲打擊墊。

任何一份 p5.js 草圖（OpenProcessing、p5 編輯器、你自己的網頁）在最前面加一行，就能用 MIDI 控制器、螢幕上的控制器或手機來彈：

js
document.head.prepend(Object.assign(document.createElement('script'), { src: 'https://openaudiovisual.com/p5/oav-p5.js' }));

在 OpenProcessing 也可以不寫這行，改把網址貼到右側 Libraries 的 ＋（自訂函式庫）。p5 1.x、2.x 的全域模式都能用， setup() 裡不用呼叫任何東西。帶著這一行、現在就能彈的草圖：範例 15。

像讀滑鼠一樣讀它#

js
function draw() {
  background(knob1 * 255);                 // knob 1, 0..1, like mouseX
  circle(width / 2, height / 2, 50 + knob2 * 300);
}

function notePressed(note, velocity) {     // like keyPressed(): any key, or a pad
  circle(random(width), random(height), velocity * 100);
}
讀值
knob1 … knob8、knob(n)0 到 1，編號照控制器上印的順序
fader1 … fader8、fader(n)0 到 1
pad1 … pad16、pad(n)按著的時候是力度，放開回到 0
note、velocity最後按的鍵（MIDI 編號）和多用力（0 到 1）
noteIsPressed、noteIsDown(60)跟 keyIsPressed、keyIsDown() 一樣
寫這個函式什麼時候被叫
notePressed(note, velocity)、noteReleased(note)按下、放開一個鍵（打擊墊也算，除非你寫了 padPressed）
knobMoved(n, value)、faderMoved(n, value)轉旋鈕、推推桿
padPressed(n, velocity)、padReleased(n)打擊墊按下、放開

旋鈕 1 就是你手上那台的旋鈕 1：控制器設定檔記著每顆旋鈕送哪個訊息（MiniLab 3 的旋鈕 1 是 CC 74， LPD8 是 CC 70）。OAV 沒有設定檔的控制器，你先轉的那顆就是 knob1，再轉的是 knob2。草圖裡自己已經有 note、velocity、knob1 這些名字的話，原本的會留著。

搭配 OP Configurator#

OP Configurator 3000（OPC，OpenProcessing 內建）幫變數取名字、定範圍。頁面上有這一行，控制器就照宣告順序接上這些變數，不用一個一個對應：

js
OPC.slider('radius', 60, 10, 300);   // knob 1
OPC.slider('speed', 1, 0, 5, 0.1);   // knob 2
OPC.toggle('trails', true);          // pad 1 flips it

旋鈕依序接 slider，推桿接在旋鈕後面，打擊墊接 toggle 和 button。轉旋鈕時 OPC 面板上的滑桿跟著動， parameterChanged() 照常會被叫。OpenProcessing 的 OPC 面板自己也能學實體控制器（面板上的 MIDI 開關），一看到它的對應在動，實體控制器就交給它，這一行繼續接螢幕上的控制器和手機（這兩個 OpenProcessing 看不到）。 OPC 變數不要取 p5 已經有的函式名稱（hue、fill），p5 1.x 會撞名。

一顆旋鈕只做一件事。 草圖自己也直接讀 knob1 的話，旋鈕 1 就歸草圖：OPC 的第一條拉桿不再跟著它（改在 OPC 面板上拉），其他旋鈕照接，並跳一次提示說明。🎹 面板的第一行就是接線表，例如「接線：旋鈕1 → knob1（草圖；radius 改用滑桿） · 旋鈕2 → speed（OPC）」。

麥克風#

同一行也接得上麥克風，草圖讀它的方式一樣：讀變數。

js
function draw() {
  background(230, 40, 10);
  fill(200 + bass * 160, 70, 100);                      // bass: the low end, 0..1
  circle(width / 2, height / 2, 50 + micLevel * 300);   // micLevel: how loud, 0..1
}

function beatDetected(level) {                          // like keyPressed(): a beat just landed
  // flash, spawn, jump to the next scene
}
讀值
micLevel0 到 1，聽起來多大聲：房間本身的底噪是 0，說話大約 0.4–0.6，大喊接近 1
bass、mid、treble0 到 1，20–250 Hz、250–2000 Hz、2000–8000 Hz 三段的能量
beat每個拍子有一格是 true，像按著滑鼠時的 mouseIsPressed
micIsOn麥克風有沒有在跑
startMic()、stopMic()用程式開、關（回傳 promise）
micSensitivity(2)靈敏度變兩倍；micSensitivity() 回傳現在的值
寫這個函式什麼時候被叫
beatDetected(level)一個拍子：音量比房間剛才的樣子突然跳起來（level 0 到 1）
kickDetected(level)、snareDetected(level)、hatDetected(level)低、中、高頻段各自打一下（20–120 Hz、150–800 Hz、6–14 kHz）

草圖開口要，它才開。 頁面載入時什麼都不會要。草圖第一次讀到 micLevel、bass、mid、treble、beat，或呼叫 startMic()，瀏覽器才會問你要不要給麥克風；答案回來之前，每個值都是 0。只寫了 beatDetected()、什麼值都沒讀的草圖，會在第一次點擊或按鍵時開。🎹 面板裡的 🎤 按鈕可以手動開關、顯示音量；瀏覽器擋下麥克風時，它會寫出來（從網址列左邊重新允許之後，再按一次）。

  • 瀏覽器要你先點一下的話。 瀏覽器在頁面被點過之前不讓聲音動起來。這個檔在 draw() 一讀到值就去要，瀏覽器擋住的話，第一次點擊或按鍵再開一次，所以不用寫 userStartAudio()。
  • 跟 p5.sound 並存。 分析用的是 @openav/audio（一個 AnalyserNode），第一次用到時從這個檔旁邊載入，有自己的 AudioContext。同一頁可以放 p5.sound（p5.AudioIn、p5.FFT），兩邊的麥克風互不相干，這裡新增的名字也沒有一個跟 p5 或 p5.sound 的名字重複。p5 1.x、2.x 的全域模式都能用。
  • 多大聲算大聲。 micLevel 是以分貝算的「聽起來的大小」，從房間量起：最低點跟著房間自己的底噪走（一兩秒內就定下來，往上每秒最多 1.5 dB，所以一直講話不會被當成新的安靜），−10 dBFS（對著筆電大喊）是 1。所以 50 + micLevel * 300 在有人說話時就看得出變大。麥克風太小聲或離太遠：micSensitivity(3)（micLevel 多 9.5 dB、三個頻段乘三，上限還是 1）。原始數值在 OAVp5.mic.rms（0 到 1）、OAVp5.mic.db、OAVp5.mic.floor（房間底噪，dBFS）。 OAVp5.mic.on('beat', fn) 跟定義 beatDetected 一樣，回傳一個可以取消的函式。
  • 你自己的名字優先。 草圖裡已經有 bass、mid（let、函式、別的函式庫）的話，原本的會留著，這個檔也不會為了它去開麥克風。
  • 關掉自動開。 ?mic=click（或 window.OAV_P5 = { mic: 'click' }）：只有 🎤 和 startMic() 能開； mic=off 就什麼都開不起來（名字還在，值一直是 0）。跟所有用麥克風的頁面一樣，要 https 或 localhost。
  • 現成可開的麥克風草圖：p5/examples/mic/。

聲音：彈什麼就聽到什麼#

js
function setup() {
  createCanvas(windowWidth, windowHeight);
  startSound('piano');          // every key is heard: a keyboard, the 🎹 on screen, a phone
}
呼叫／讀值
startSound(instrument)開聲音（預設 'piano'）；開著的時候再叫一次就換樂器
stopSound()關聲音
soundIsOn現在彈下去有沒有聲音

樂器來自 @openav/sound：piano（Salamander 平台鋼琴，第一次要載 2 MB 的取樣，載入中先用電鋼琴頂著，載不到就一直用電鋼琴）、epiano、organ、strings、choir、harp、marimba、vibraphone、xylophone、 glockenspiel、music-box，還有 synth/… 一系列合成器。🎹 面板上的 🔊 可以開關聲音，打開後有樂器選單和載入進度。

  • 沒叫它就不載。 呼叫 startSound() 或按 🔊 之前什麼都不載；之後從這個檔旁邊載 @openav/sound，從 jsDelivr 載 Tone.js 15 （選項 tone=<網址> 可以改從別的地方載）。
  • 先點一下。 瀏覽器要網頁被點過才讓它出聲，按 MIDI 鍵盤不算。setup() 裡呼叫 startSound() 的草圖，第一次點擊或按鍵之後才聽得到；在那之前 🎹 按鈕上的 🔊 是黃的。
  • 打擊墊是鼓。 第 10 軌的音（MiniLab 3、LPD8 的打擊墊，General MIDI 的鼓軌）打的是鼓組，不會彈成鋼琴。延音踏板會讓音延長。
  • 一行程式都不用寫。 頁面網址加 ?oav_sound=piano（任何樂器名；OpenProcessing 用 ?sketch_oav_sound=piano），任何草圖點一下之後就有聲音；sound=off 則保持安靜。
  • 現成可開、邊彈邊畫的草圖：p5/examples/keys/。

鼓機#

js
function setup() {
  startDrums('breakbeat', 110);   // a 16-step grid on screen; click a cell to change the beat
}

function kickDetected(level) {    // the microphone's own callback
  // swell, flash, spawn
}

function drumHit(lane, velocity) {   // every hit: 'kick', 'snare', 'hat' or 'clap'
}
讀值
drumsAreOn鼓機有沒有在打
drumStep0 到 15，剛打到第幾格
drumBar1、2、3……，從 startDrums() 開始數第幾小節
drumBpm速度（格子上的滑桿也會改它）
startDrums(pattern, bpm)、stopDrums()開始（打著的時候再叫一次就換節奏、換速度）、停
寫這個函式什麼時候被叫
drumHit(lane, velocity)每打一下，四軌都會叫
kickDetected(level)、snareDetected(level)、hatDetected(level)大鼓；小鼓或拍手；Hi-hat
beatDetected(level)大鼓或小鼓，每一格最多一次（beat 也會有一格是 true）

寫給麥克風的草圖，換成鼓機照樣動。 鼓機每打一下，叫的就是麥克風會叫的那幾個函式，所以麥克風草圖不用改就跟著鼓機動。草圖開了鼓機之後，只是寫了 kickDetected() 不會在第一次點擊時去開麥克風（有讀 micLevel 的草圖還是會問，那時兩邊都會叫它）。

  • 節奏。 'four on floor'、breakbeat、'half time'、latin、sparse，或自己寫： startDrums({ kick: 'x...x...x...x...', snare: '....x.......x...', hat: 'x.x.x.x.x.x.x.x.' })（沒寫的那軌不打）。
  • 格子放在哪。 畫面上方正中間：在 OpenProcessing 是 🎹 和 OPC 圖示中間，不擋到下面的 console；🎹 面板打開時移到面板下面。「–」收起格子，「×」關掉鼓機；🎹 面板裡的 🥁 不寫程式也能開關。
  • 鼓組。 @openav/drums 的合成鼓組（沒有取樣），跟聲音一樣點一下之後才聽得到；回呼從一開始就會被叫。

時間軸：小節與 cue#

鼓機也是時鐘：一小節十六格，從 startDrums() 開始數。宣告第幾小節要發生什麼：

js
function setup() {
  startDrums('breakbeat', 110);
  cue(1, 'calm', 12);             // bar 1, and again every 12 bars
  cue(5, 'bloom', 12);
  cue(9, 'storm', 12);
}

function cueFired(name, bar) {    // or read cueName in draw()
  look = SCENES[name];
}
呼叫／讀／定義
cue(bar, name, every)第 bar 小節（1 是第一小節，4.5 是第 4 小節的一半）；有給 every 就每隔那麼多小節再來一次
cueName最近一次觸發的 cue（第一次之前是 ''）
cueFired(name, bar)到了某個 cue 的那一小節
barStarted(bar)、stepStarted(step, bar)每一小節的第一格；每一格

同樣的 cue() 叫兩次不會多一個，所以放在 draw() 裡也可以。同一格上先照宣告順序觸發 cue，再來 barStarted、stepStarted、那一格的鼓。只要時鐘不要聲音：startDrums({})。全部用上的草圖：p5/examples/drums/。

錄影：畫面和聲音一起錄#

js
function keyPressed() {
  if (key === 'r') recordingIsOn ? stopRecording() : startRecording();   // startRecording(10): ten seconds, then it stops
}

function recordingSaved(info) {   // info.name, info.seconds, info.bytes, info.format ('mp4' or 'webm')
}
呼叫／讀／定義
startRecording()、startRecording(秒數)錄下畫布和作品的聲音；給秒數就錄那麼久自動停；一段最長 5 分鐘
stopRecording()停止，檔案自動下載
recordingIsOn現在有沒有在錄
recordingSaved(info)存好了：name、seconds、bytes、format、width、height、audio、sources、warnings、blob、url

🎹 面板上的 ⏺ 不寫程式也能開始、停止；錄影中 🎹 按鈕上有紅點和時間（點紅點就停）。📷 把畫布存成一張 PNG。

  • 影片裡有什麼。 p5 的畫布，用它實際的像素（Retina 螢幕是兩倍），每秒 30 格；加上這個檔發出的所有聲音：startSound()、鼓機和打擊墊、開著的麥克風、p5.sound 1.x，混成一軌，喇叭照常出聲。🎹、鼓機格子、提示卡片、OPC 面板都不在畫布上，所以不會進影片。
  • 檔案。 瀏覽器能錄 MP4（H.264＋AAC）就錄 MP4：Chrome 126 以後、Edge、Safari，IG、YouTube、剪輯軟體都直接吃。其他瀏覽器（Firefox、舊版 Chrome）錄成 WebM，卡片會說 IG 不收。檔名像 oav-20261015-183005.mp4；電腦上直接存到「下載」，手機上卡片有 分享 按鈕，可以存進相簿或直接傳到 IG。
  • 每錄完一段都會檢查。 卡片寫出錄到什麼（格式、長度、大小、有沒有聲音）；有問題就說發生什麼、為什麼：開著聲音卻什麼都沒錄進去（還沒點過畫面、沒有彈）、錄成 WebM、檔案幾乎是空的、畫布有畫面但影片全黑（Safari 錄 WebGL 畫布，WebKit 229611）、畫布上有別的網站的圖（沒有 CORS）、這個瀏覽器不能錄。
  • 麥克風開著就會一起錄：戴耳機，不然喇叭的聲音會被錄兩次。record=nomic 不收麥克風。
  • p5.sound。 給 p5 1.x 的 p5.sound 1.x 會一起錄。給 p5 2.x 的 p5.sound 把每個聲音直接接到喇叭，沒有總輸出可以接進錄影：錄不到，卡片會說。草圖改用 p5 1.11，或改用 startSound()、startDrums()。草圖自己用 Tone.js、Web Audio 做的聲音也錄不到。
  • 靜態圖。 📷（或 OAVp5.record.shot()）只存畫布，檔名 oav-<日期>-<時間>.png，不含 🎹 和卡片；在程式裡用 p5 自己的 saveCanvas('名字', 'png') 也一樣。
  • 選項。 record=nomic（不收麥克風）、record=off（沒有 ⏺ 和 📷，startRecording() 什麼都不做）、recfps=60、 reclimit=600（秒）、title=作品名（放進檔名）；只改這一段：startRecording({ seconds, fps, mic: false, name })。
  • 全部用上的草圖：p5/examples/record/。

三種輸入#

輸入怎麼用
實體控制器Chrome、Edge、Firefox 的 Web MIDI，瀏覽器問一次就記住
螢幕上的控制器按 🎹 打開 <oav-controller>，接上哪台控制器就換成哪台
手機面板上的 📱 顯示 QR code，手機遙控頁的 MIDI 分頁就能彈這份草圖

三種輸入進來都是同一串 MIDI，草圖分不出是誰彈的（想知道的話看 midi.last.source）。Safari 和 iPad 沒有 Web MIDI，螢幕上的控制器和手機照樣能用。草圖自己寫了 Web MIDI（navigator.requestMIDIAccess、WebMidi.js）的話，螢幕和手機會變成多出來的一個輸入，名字叫 OAV Virtual MIDI。

出狀況的時候#

彈的時候沒人會去看 OpenProcessing 畫布下面的 console，所以出狀況會直接寫在畫面上：🎹 旁邊一張小卡片，不擋畫布中間，用瀏覽器的語言，同一則只跳一次，按 × 關掉。每張都寫三件事：發生什麼、為什麼、下一步按哪裡，console 也同步寫一樣的話。

  • 麥克風：被擋下（網址列左邊的鎖頭 → 允許 → 回來點一下畫面）、被電腦的系統設定擋住、在沒有 allow="microphone" 的嵌入框裡、找不到麥克風、被別的程式（Zoom、OBS）占用、網址不是 https、瀏覽器還在等你按允許。
  • MIDI：瀏覽器沒有 Web MIDI（Safari、iPad：改用 🎹 或手機）、MIDI 權限被擋。只對有用 MIDI 的草圖說；什麼功能都沒用到的草圖不會跳任何卡片。
  • 你自己的程式：notePressed()、kickDetected()、drumHit() 這些回呼裡出錯，卡片寫出錯誤訊息、哪個檔第幾行，草圖照樣繼續跑。草圖自己宣告了 note、knob1（let、var、function），原本的會留著，卡片告訴你改讀什麼（midi.last.note、knob(1)）。
  • 聲音和鼓機：要先點一下畫面、鋼琴還在載入（先用電鋼琴頂著）、某個樂器載不到（改用備用的）、Tone.js 連不上、鼓機在打但還沒點過畫面所以沒聲音。
  • 錄影：開始錄了（錄到哪些聲音、怎麼停）、錄好了（格式、長度、大小、有沒有聲音）、錄到的影片沒有聲音、錄成 WebM（IG 不收）、整段黑、檔案幾乎是空的、畫布上有別的網站的圖、這個瀏覽器不能錄。

?oav_hints=off（或 window.OAV_P5 = { hints: 'off' }）只寫在 console；OAVp5.hints 列出說過的提示。

🩺 體檢。 🎹 面板上的 🩺（或 OAVp5.check()）把版本、頁面、瀏覽器、麥克風、MIDI、聲音、鼓機、錄影（這裡能錄 MP4 還是 WebM、上一段）、接線、草圖自己的名字、目前為止的提示整理成一張卡，截圖貼到 Discord 就能遠端看；有「複製文字」按鈕，也連到完整的裝置檢查。

在 Hydra 裡用#

Hydra 有自己的載入函式；同一個檔在那裡也能用，Hydra 的箭頭函式每一格都會重讀變數：

js
await loadScript('https://openaudiovisual.com/p5/oav-p5.js')
osc(10, 0.1, () => knob1 * 2).out()                     // knob 1 sets the colour offset
js
osc(10, 0.1, () => 1 + micLevel * 3).out()              // the microphone, asked for when this line first runs

note、velocity、knob1 … knob8、fader1 …、pad1 …、drumStep，還有 🎹 螢幕上的控制器，都一樣在。 Hydra 不是 p5，沒有可以定義的 notePressed() 回呼，改用訂閱： midi.on('notePressed', (note, velocity) => { … }) 或 OAVp5.drums.on('hit', (lane, velocity) => { … })（都回傳一個取消訂閱的函式）。測試用的是 hydra-synth 1.4.0，也就是編輯器跑的那個函式庫（p5/test/hydra-smoke.cjs）。

細節#

  • 為什麼用 prepend：p5 的友善錯誤檢查會把頁面上最後一個 <script> 當成你的草圖。這個檔放在最前面，就不會被誤當成你的程式。
  • 為什麼非同步載入的一行就夠：p5 等到視窗的 load 事件才開始全域模式，而頁面載入中插進來的 script 會讓 load 等它跑完，所以 setup() 裡就已經有 knob1。
  • 這一行沒載到時（沒網路、網址打錯），讀 knob1 的程式會停在「knob1 is not defined」。
  • 嵌到別的網站：OpenProcessing 自己的頁面允許草圖用 MIDI 和麥克風，它給的嵌入碼沒有。要讓嵌入的草圖聽實體控制器，在那個 <iframe> 加上 allow="midi"；要它聽麥克風，加 allow="microphone"。
  • 選項、MIDI 層的寫法和測試：p5/README.md。範例：p5/examples/particles/、p5/examples/opc/、p5/examples/mic/、p5/examples/keys/、p5/examples/drums/、p5/examples/record/。
