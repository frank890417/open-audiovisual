Adafruit Universal Qi wireless receiver (1901)

用在程式裡

把 Adafruit Universal Qi wireless receiver (1901) 寫進你的程式

貼進任何網頁的 <script type="module">：它從這個網站載入 @openav/devices，印出 Hw.check() 讀的那一筆零件資料。

javascript
import { device } from 'https://openaudiovisual.com/packages/devices/index.js';

const part = await device('qi-receiver');   // Adafruit Universal Qi wireless receiver (1901)
console.log(JSON.stringify(part.part.supply), Object.keys(part.part.pins).join(' '));
// → null V+ GND

接到它的程式

  • @openav/hw · Hw

    Hw.check({ board, parts: { x: { part: 'qi-receiver' } }, wires })

    列在規格的零件裡，就跟其他接線一起檢查：電壓、腳位、電流。
