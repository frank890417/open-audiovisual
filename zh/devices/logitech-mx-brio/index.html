Logitech MX Brio

試試看

你的 Logitech MX Brio 在嗎？

按下按鈕之前什麼都不會發生。「找找看」向瀏覽器要鏡頭清單，依名稱找到這一台。「打開」只問一次權限，用上面的設定打開它，跟下面的程式碼是同一組呼叫。

連接

怎麼接、說什麼協定

連接方式

USB

協定

USB Video Class (UVC)

瀏覽器給的設定

{"width":1920,"height":1080,"fps":60}

設定

設定步驟

  1. 接到支援 USB 3.0 的 USB-C 埠。它以 UVC 標準當一般網路攝影機用，羅技的軟體（Logi Options+、G HUB）再加上它的設定。 Logitech Support: Specification, MX BRIO
  2. 網頁要在 https 或 localhost 上，並且由一次點擊啟動鏡頭。在 macOS 上，瀏覽器要在「系統設定 → 隱私權與安全性」裡有相機權限。 open-audiovisual handbook: Troubleshooting, the camera or microphone does not start

已知問題

  • 頁面拿到一次相機權限之前，瀏覽器不給鏡頭的名稱，所以在那之前無法用名字分辨 MX Brio 和別的鏡頭。open() 會先要權限，再找一次。 open-audiovisual: @openav/record, camera.js (ideal, never exact, sizes; labels hidden until permission)

用在程式裡

把 Logitech MX Brio 寫進你的程式

貼進任何網頁的 <script type="module">：它從這個網站載入需要的套件。按下它加上的按鈕之前，什麼權限都不會要。

javascript
import { device } from 'https://openaudiovisual.com/packages/devices/index.js';

const cam = await device('logitech-mx-brio');   // Logitech MX Brio
console.log(JSON.stringify(cam.constraints()));
// → {"video":{"width":{"ideal":1920},"height":{"ideal":1080},"frameRate":{"ideal":60}},"audio":false}
const video = document.body.appendChild(Object.assign(document.createElement('video'), { autoplay: true, muted: true, playsInline: true }));
const button = document.body.appendChild(Object.assign(document.createElement('button'), { textContent: "Logitech MX Brio" }));
button.onclick = async () => {
  video.srcObject = await cam.open();   // asks once, finds it by its name, opens it
};

接到它的程式

  • @openav/devices · device

    const stream = await (await device('logitech-mx-brio')).open()

    依名稱在鏡頭裡找到 MX Brio，以 1920×1080、60 fps 為理想值打開它，呼叫了才會做。

  • @openav/record · Compositor

    await comp.setCamera(stream)

    演出影片把這顆鏡頭放在作品下方。

狀態

這一頁有多確定

還沒有在實機上確認：每個值都照出處寫。只有手上有這台的人能改變這一點。

說明

  • @openav/pose 的 PoseTracker 與 HandTracker 會自己打開預設的鏡頭，目前還不能替它們指定這顆。

待確認

  • 標籤比對式是照型號寫的，不是從實機讀來的。Chrome 把它叫做什麼，還沒有確認。
  • 瀏覽器能不能從它拿到 1920×1080、60 fps，還沒有確認。限制條件是理想值，所以它會以做得到的設定打開。
