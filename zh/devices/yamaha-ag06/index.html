Yamaha AG06

Yamaha AG06 是一台音訊介面，用 USB、XLR 音訊、音訊插孔 連接。這裡是 OAV 對它的了解：每筆事實都附讀到它的那一頁，加上怎麼設定、會遇到什麼問題，以及接到它的程式碼。

連接

怎麼接、說什麼協定

連接方式

USB · XLR 音訊 · 音訊插孔

協定

USB Audio Class 2.0

瀏覽器給的設定

{"echoCancellation":false,"noiseSuppression":false,"autoGainControl":false,"channelCount":{"ideal":2}}

設定

設定步驟

  1. 接上 [USB 2.0] 和 [5V DC] 端子的線之前，先把混音器切到待機，電腦也先從睡眠醒來。 Yamaha AG06 Owner's Manual (ag06_en_om_a0)
  2. 平板供不了混音器的電時，要在 [5V DC] 端子（micro B）接 USB 電源供應器或行動電源。 Yamaha AG06 Owner's Manual (ag06_en_om_a0)
  3. 要讓網頁聽麥克風時，把 [TO PC] 切到 INPUT MIX 或 DRY CH 1-2。 Yamaha AG06 Owner's Manual (ag06_en_om_a0)
  4. 網頁要在 https 或 localhost 上，並且由一次點擊啟動麥克風。在 macOS 上，瀏覽器要在「系統設定 → 隱私權與安全性」裡有麥克風權限。 open-audiovisual handbook: Troubleshooting, the camera or microphone does not start

已知問題

  • [TO PC] 在 LOOPBACK 時，電腦播出的聲音會混進它收到的聲音，所以一邊發聲一邊聽的網頁會聽到自己。說明書提醒這可能形成迴路而產生回授。 Yamaha AG06 Owner's Manual (ag06_en_om_a0)

用在程式裡

把 Yamaha AG06 寫進你的程式

貼進任何網頁的 <script type="module">：它從這個網站載入需要的套件。按下它加上的按鈕之前，什麼權限都不會要。

javascript
import { device } from 'https://openaudiovisual.com/packages/devices/index.js';
import { Signals } from 'https://openaudiovisual.com/packages/core/index.js';
import { AudioAnalyzer } from 'https://openaudiovisual.com/packages/audio/index.js';

const input = await device('yamaha-ag06');   // Yamaha AG06
console.log(JSON.stringify(input.constraints()));
// → {"audio":{"echoCancellation":false,"noiseSuppression":false,"autoGainControl":false,"channelCount":{"ideal":2}},"video":false}
const signals = new Signals();
const button = document.body.appendChild(Object.assign(document.createElement('button'), { textContent: "Yamaha AG06" }));
button.onclick = async () => {
  const stream = await input.open();   // asks once, finds it by its name, voice processing off
  const a = new AudioAnalyzer({ signals });
  a.input().context.createMediaStreamSource(stream).connect(a.input());
  setInterval(() => { a.update(); console.log('audio/rms', signals.get('audio/rms')); }, 500);
};

接到它的程式

  • @openav/devices · device

    const stream = await (await device('yamaha-ag06')).open()

    依名稱在音訊輸入裡找到 AG06，關掉瀏覽器的語音處理後打開它，呼叫了才會做。

  • @openav/audio · AudioAnalyzer

    const a = new AudioAnalyzer({ signals }); a.input().context.createMediaStreamSource(stream).connect(a.input())

    打開的串流經 input() 接進分析器，audio/rms、三個頻段和鼓的偵測就跟著 AG06，而不是預設的麥克風。

狀態

這一頁有多確定

還沒有在實機上確認：每個值都照出處寫。只有手上有這台的人能改變這一點。

待確認

  • 這些是第一代 AG06 的資料，讀自它自己的文件。AG06MK2 是另一台，這裡沒有描述。這筆紀錄之後會在哪一台上驗證，還沒有確認。
  • 標籤比對式是照型號寫的，不是從實機讀來的。Chrome 在 macOS 與 Windows 上把它叫做什麼，還沒有確認。
  • 瀏覽器設 channelCount 2 時能不能拿到兩個 USB 輸入聲道，還沒有確認。
