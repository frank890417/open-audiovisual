用在程式裡

把 Audinate Dante Virtual Soundcard 寫進你的程式

貼進任何網頁的 <script type="module">：它從這個網站載入需要的套件。按下它加上的按鈕之前，什麼權限都不會要。

javascript
import { device } from 'https://openaudiovisual.com/packages/devices/index.js';
import { Signals } from 'https://openaudiovisual.com/packages/core/index.js';
import { AudioAnalyzer } from 'https://openaudiovisual.com/packages/audio/index.js';

const input = await device('audinate-dante-virtual-soundcard');   // Audinate Dante Virtual Soundcard
console.log(JSON.stringify(input.constraints()));
// → {"audio":{"echoCancellation":false,"noiseSuppression":false,"autoGainControl":false},"video":false}
const signals = new Signals();
const button = document.body.appendChild(Object.assign(document.createElement('button'), { textContent: "Audinate Dante Virtual Soundcard" }));
button.onclick = async () => {
  const stream = await input.open();   // asks once, finds it by its name, voice processing off
  const a = new AudioAnalyzer({ signals });
  a.input().context.createMediaStreamSource(stream).connect(a.input());
  setInterval(() => { a.update(); console.log('audio/rms', signals.get('audio/rms')); }, 500);
};

接到它的程式

  • @openav/devices · device

    const stream = await (await device('audinate-dante-virtual-soundcard')).open()

    依名稱在音訊輸入裡找到 Dante Virtual Soundcard，關掉瀏覽器的語音處理後打開它，呼叫了才會做。

  • @openav/audio · AudioAnalyzer

    const a = new AudioAnalyzer({ signals }); a.input().context.createMediaStreamSource(stream).connect(a.input())

    打開的串流經 input() 接進分析器，現場的 Dante 網路就能推動 audio/rms、三個頻段和鼓的偵測。
