設定

設定步驟

  1. 安裝 Ultraleap Hand Tracking（Gemini 5.x），插上感測器。執行 "/Applications/Ultraleap Hand Tracking.app/Contents/bin/leapctl" devices 應該會列出它，並顯示 Tracking: true。 open-audiovisual: packages/leap README (setup on macOS, the bridge)
  2. 安裝 Xcode 命令列工具（clang）：橋接程式第一次啟動時會編譯它的 C 讀取程式。 open-audiovisual: packages/leap README (setup on macOS, the bridge)
  3. 執行橋接程式 node packages/leap/bridge/leap-bridge.mjs，再看 http://127.0.0.1:6437/health。install.sh 會讓它在登入時自動執行。 open-audiovisual: packages/leap README (setup on macOS, the bridge)

已知問題

  • 公開 https 網站上的網頁連到這台電腦的橋接程式時，Chrome 會跳出區域網路的詢問。被封鎖時會出現 net::ERR_BLOCKED_BY_LOCAL_NETWORK_ACCESS_CHECKS。請允許，或改從 localhost 開網頁。 open-audiovisual handbook: Troubleshooting, Chrome asks about the local network, or about apps on this device

用在程式裡

把 Ultraleap Leap Motion Controller 2 寫進你的程式

貼進任何網頁的 <script type="module">：它從這個網站載入需要的套件。按下它加上的按鈕之前，什麼權限都不會要。

javascript
import { device } from 'https://openaudiovisual.com/packages/devices/index.js';
import { Signals } from 'https://openaudiovisual.com/packages/core/index.js';
import { LeapInput } from 'https://openaudiovisual.com/packages/leap/index.js';

const leap = await device('ultraleap-leap-motion-controller-2');   // Ultraleap Leap Motion Controller 2
console.log(leap.record.use.map((u) => u.package).join(' '));
// → @openav/leap
const signals = new Signals();
const button = document.body.appendChild(Object.assign(document.createElement('button'), { textContent: "Connect the Leap bridge" }));
button.onclick = () => new LeapInput({ signals }).connect();   // the bridge on this computer: see Setup

接到它的程式

  • @openav/leap · LeapInput

    new LeapInput({ signals }).connect()

    經過本機的橋接程式，兩隻手變成 leap/hand/<side>/… 訊號（手掌位置、捏合、抓握、角度、指尖），leap.hands 有畫手用的關節。
