試試看

ENTTEC DMX USB Pro 收到的訊框

三個 DMX 通道做成滑桿，寫進一個 universe，再由 encodeEnttecDmx() 包成 Pro 的「send DMX」訊息（label 6），就是 Web Serial 或輸出橋接程式會寫到連接埠的位元組。什麼都不會送出去。

0x7E 開頭 · 0x06 label · 長度 · start code 0 · 各通道 · 0xE7 結尾

設定

設定步驟

  1. 不經橋接程式、直接從網頁：dmxTransport('serial', { patch, universe: 1 })，加一個呼叫 connect() 的 Connect 按鈕，瀏覽器只會在點擊時問要用哪個連接埠。電腦上的 Chrome 或 Edge，https 或 localhost。 open-audiovisual handbook: DMX lighting (Web Serial and the enttec sink, safety, not here)
  2. 改經輸出橋接程式：一條帶序列裝置路徑的 enttec 路由，{ "match": "dmx/1/*", "sink": "enttec", "path": "/dev/cu.usbserial-…", "universe": 1 }。裝置不在時是一個狀態，每 2 秒重試。 open-audiovisual handbook: DMX lighting (Web Serial and the enttec sink, safety, not here)

已知問題

  • 用 Web Serial 時沒有看門狗：Pro 會一直重送最後一格，所以 close() 之前先送 blackout。 open-audiovisual handbook: DMX lighting (Web Serial and the enttec sink, safety, not here)
  • OAV 寫的是 Pro 的「送出 DMX」訊框，沒有 RDM。Enttec Open DMX 或單純的 FTDI 線不是這台，不能這樣用。 open-audiovisual handbook: DMX lighting (Web Serial and the enttec sink, safety, not here)

用在程式裡

把 ENTTEC DMX USB Pro 寫進你的程式

貼進任何網頁的 <script type="module">：它從這個網站載入需要的套件。按下它加上的按鈕之前，什麼權限都不會要。

javascript
import { device } from 'https://openaudiovisual.com/packages/devices/index.js';
import { Patch, DmxEngine, dmxTransport } from 'https://openaudiovisual.com/packages/dmx/index.js';

const pro = await device('enttec-dmx-usb-pro');   // ENTTEC DMX USB Pro
console.log(pro.record.protocols.join(' '));
// → dmx512 rdm enttec-usb-pro
const patch = new Patch();
patch.add({ id: 'par1', profile: 'generic-rgbw', mode: '6ch', address: 1 });
const engine = new DmxEngine(patch);
engine.set('par1', { dimmer: 1, color: [1, 0.5, 0] });
const out = dmxTransport('serial', { patch, universe: 1 });
const button = document.body.appendChild(Object.assign(document.createElement('button'), { textContent: "Connect the ENTTEC DMX USB Pro" }));
button.onclick = async () => { await out.connect(); out.send(engine.render(0)); };   // the browser asks which port

接到它的程式

  • @openav/dmx · dmxTransport

    const out = dmxTransport('serial', { patch, universe: 1 }); button.onclick = () => out.connect()

    網頁經 Web Serial 寫入完整的 Enttec 訊框，有變化時最快每 25 毫秒一格，沒變化時每秒一格，都先經過頻閃保護。

  • @openav/out · OutClient · sink enttec

    dmxTransport('bridge', { patch, client: new OutClient({ url: 'ws://127.0.0.1:6450/out' }).connect() })

    輸出橋接程式的 enttec sink 把一個 universe 送到序列裝置上的 Pro，網頁離開時由看門狗送安全值。
