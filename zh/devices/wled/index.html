WLED

設定

設定步驟

  1. 用 DDP 時，在輸出橋接程式設一條指向 WLED 位址的 ddp 路由：{ "match": "light/*", "sink": "ddp", "host": "192.168.1.50", "port": 4048, "pixels": 60 }。light/<i>/r|g|b 是 0..1，i 是從 0 起算的燈珠。 open-audiovisual: packages/out README (the ddp sink, its config, WLED's fallback)
  2. 要改用 Art-Net 或 E1.31，在 WLED 的 Sync 設定切到那個模式，重開一次，再經輸出橋接程式的 artnet 或 sacn sink 送出。 WLED Knowledge Base: E1.31 (DMX) / Art-Net

已知問題

  • 最後一個 DDP 封包之後約 2.5 秒，WLED 會回到自己的效果，這是在橋接程式的看門狗之外的另一道保險：網頁停止送出，燈條就不再聽它的。 open-audiovisual: packages/out README (the ddp sink, its config, WLED's fallback)
  • 同一個 E1.31 優先權的兩個來源不會合併：一個網頁和一台燈控台送同一條燈條會互搶。 WLED Knowledge Base: E1.31 (DMX) / Art-Net

用在程式裡

把 WLED 寫進你的程式

貼進任何網頁的 <script type="module">：它從這個網站載入需要的套件。按下它加上的按鈕之前，什麼權限都不會要。

javascript
import { device } from 'https://openaudiovisual.com/packages/devices/index.js';
import { OutClient } from 'https://openaudiovisual.com/packages/out/client.js';

const strip = await device('wled');   // WLED
console.log(strip.record.use.map((u) => `${u.package} ${u.sink}`).join(', '));
// → @openav/out ddp, @openav/dmx artnet
const button = document.body.appendChild(Object.assign(document.createElement('button'), { textContent: "Pixel 0 red" }));
button.onclick = () => new OutClient({ url: 'ws://127.0.0.1:6450/out' }).connect().set('light/0/r', 1);   // through the out-bridge, out.json below

接到它的程式

  • @openav/out · OutClient · sink ddp

    new OutClient({ url: 'ws://127.0.0.1:6450/out' }).connect().set('light/0/r', 1)

    網頁的值送到輸出橋接程式，它的 ddp sink 把 light/<i>/r|g|b 打包成 DDP 送給燈條，每秒最多 60 次，附看門狗。

  • @openav/dmx · dmxTransport · sink artnet

    dmxTransport('bridge', { patch, client })

    把燈條 patch 成 RGB 燈具，它就經輸出橋接程式的 artnet（或 sacn）sink 接收 DMX 引擎的燈光，附閃爍上限。
