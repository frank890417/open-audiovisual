# 實驗室整合（`"lab"` 欄位）

[cheyuwu-lab](https://lab.cheyuwu.com) 用一般的 `<script>` 頁面執行作品（sketch），所以它會把需要的每個 OAV 套件，各打包成一份 classic script。實驗室的產生器（`tools/lab-dev/build-modules.mjs`）會掃描 `packages/*/package.json`，替每個宣告了 `"lab"` 欄位的套件建置模組，沒有寫死的清單。這個欄位通常是一個物件，一個套件要產出好幾個模組時，就寫成陣列。沒有宣告，就沒有模組。

| key | 意義 |
|---|---|
| `module` | 輸出名稱，產生 `runtime/modules/<module>.js`（小寫英文、數字、`-`） |
| `kind` | `"build"`（預設，打包程式碼）或 `"declare"`（只宣告一個由實驗室自己實作的模組） |
| `files` | 要打包的原始檔，路徑相對於 `packages/`。檔案之間的相對 `import` 會解析好，JSON import 直接內嵌 |
| `exports` | 掛在 `window.OpenAV` 上的名稱 |
| `wire` | 選用的檔案（路徑相對於套件資料夾），在模組的作用域裡執行，`lab` 就是 `window.lab`。它負責把套件接上 `lab.signals`／`lab.params` |
| `autowire` | 一句話說明接線做了什麼（會寫進實驗室的 `oav-manifest.json`） |
| `remoteTab` | 選用的 `{id, label, icon, entry}`：在手機的 `/remote` app 加一個分頁 |
| `since` | 版本或月份 |

規則：只用相對 import，不能有執行期相依套件，OAV 本身沒有建置步驟。產生器是冪等的（重跑幾次結果都一樣），並有 `--check` 模式（exit 3 表示 OAV 有新東西需要重新產生）。

## 單一真實來源：控制器與輸入都住在這裡

2026-10-03 決定：實驗室用到的每一個控制器與輸入模組，都寫**在 OAV 裡**，只透過參照進到實驗室：

- **產生的**：由 `"lab"` 宣告產生的 `runtime/modules/<module>.js`（檔頭是 `// GENERATED by tools/lab-dev/build-modules.mjs`）。
- **原樣提供的**：實驗室的開發伺服器從 `packages/remote/index.html` 提供 `/remote`，並從這個 repo 提供 `/oav/packages/*`。

範圍包括：訊息格式（`relay/signals.js`：`signalMeta`、`fileSignal`、力度正規化）、虛擬 Web MIDI（`midi/virtual-access.js`）、控制器設定檔與面板（`packages/midi`）、手機頁面（感測 · 琴鍵 · 控制台 · MIDI：`packages/remote`、`packages/surface`、`packages/keys`）、作品執行頁本身的手機感測器（`localSensors`，實驗室模組 `motion`）、音訊、聲音、映射和 OSC（OSC 橋接是 `packages/osc/bridges/osc-bridge.js`）。**要改哪一個，就在這裡改、在這裡測、推上 main**，實驗室會重新產生（每晚跑的 `tools/oav-sync/sync.sh`，或手動執行 `node tools/lab-dev/build-modules.mjs`）。不要去改實驗室裡的那份副本。

實驗室不准長出第二份副本。它的關卡（`node tools/lab-dev/modules-gate.mjs`，同時是一項測試，也是 `npm run deploy` 的第一步）遇到兩種情況會失敗：某個 `runtime/modules/*.js` 沒有 GENERATED 檔頭（一份簡短、每一項都附理由的允許清單除外，目前是空的），或 `runtime/modules/` 裡有子資料夾（手動複製進來的套件）。

留在實驗室的，只有薄薄一層宿主程式：必須在作品載入前就存在、或只認得實驗室自家頁面的程式碼。也就是 `runtime/lab.js`（`lab` 物件、它的中繼 socket，以及把 `navigator.requestMIDIAccess` 換成「延遲載入產生出來的 `midi` 模組」的那幾行）、`/remote` 的房間選擇器（`runtime/remote-room.js`：目前開著哪些實驗室作品）和錄製面板（`runtime/rec-remote.js`：實驗室自己的擷取／錄製 API），還有開發伺服器的中繼與路由。新種類的控制器或輸入，絕不從那裡開始寫。
