OAVp5.record.fps#

variableoav-p5
OAVp5.record.fps

Also: OAVp5.record.limit

The frame rate (fps) and the longest take in seconds (limit) that the loading options recfps and reclimit set.

They are there to read: OAVp5.record.limit tells a sketch how long a take can be. Writing to them changes nothing, because a take reads the options, not these two. To record at another frame rate once, pass startRecording({ fps: 60 }); to change the limit, set the reclimit option before oav-p5 loads (window.OAV_P5 = { reclimit: 600 }).

Type
Number
Range
fps 1..60, limit 1 …

fps is 30 and limit is 300 unless the options say otherwise (fps is kept between 1 and 60).
