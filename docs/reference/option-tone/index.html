oav-p5 reference · Loading options

tone#

optionoav-p5
?oav_tone=an ES module URL

Where Tone.js, the sound engine behind startSound(), is loaded from: an ES module address. Empty means jsDelivr.

Sound (startSound(), the sound option, the 🔊 button) uses Tone.js 15, which oav-p5 loads the first time sound is wanted. By default it comes from jsDelivr. Point tone at your own copy when the page is behind a school firewall or an ad blocker that stops the CDN, or when you serve everything yourself. If it cannot be loaded, a card says which host was unreachable and what to try.

Type
String (URL)
Values
an ES module URL
default
'' (jsDelivr)

The address of Tone.js version 15 as an ES module. Left empty, it is https://cdn.jsdelivr.net/npm/tone@15.0.4/+esm, and OAVp5.options.tone reads ''.

Notes

  • Set it before oav-p5 loads. window.OAV_P5 = { tone: … }; above the loader line wins, then ?oav_tone=… on the page address, then ?tone=… on the script's own URL. Values in window.OAV_P5 are turned into text, so write 'off', not false. On OpenProcessing the page address takes ?sketch_oav_tone=… (the project's README says OpenProcessing forwards it to the sketch).

Every sketch starts with one line

js
document.head.prepend(Object.assign(document.createElement('script'), { src: 'https://openaudiovisual.com/p5/oav-p5.js' }));

The examples below leave it out to stay short. Copy puts it at the top for you, so what you paste into OpenProcessing (or the p5 editor) runs as it is.
