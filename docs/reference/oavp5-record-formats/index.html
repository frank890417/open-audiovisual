OAVp5.record.formats()#

functionoav-p5
OAVp5.record.formats()

Says what this browser can record: { recorder, mp4, webm, mime }.

Use it before you offer a recording button, or to tell the person which file they will get: MP4 goes to Instagram and every editor, WebM does not. It asks the browser each time you call it.

Returns

Object recorder is true when the browser has MediaRecorder at all, mp4 and webm are true when it can write that format, and mime is the MIME type a recording asks for first (MP4 where possible), or '' when none works.
