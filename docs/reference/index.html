knob1#

variableoav-p5
knob1

Also: knob2 knob3 knob4 knob5 knob6 knob7 knob8

The position of a controller knob, from 0 to 1: knob1 is the first knob, knob2 the second, up to knob8.

Read it in draw() the way you read mouseX: background(knob1 * 255). Knobs are numbered the way they are printed on the controller, so knob 1 is knob 1 on any controller OAV has a profile for: the MiniLab 3's first knob is CC 74, the LPD8's is CC 70. The sketch never needs to know a CC number.

On a controller OAV has no profile for, the first knob you turn becomes knob1, the next one knob2, and so on, in the order you turn them. Past eight, use knob(n).

Type
Number
Range
0..1

Changes when the knob moves, not once per frame; the sketch just reads the latest value. 0 until the knob has been turned.

Before it has a value

Nothing to call. Reading a knob tells oav-p5 the sketch plays from MIDI, so it asks the browser for Web MIDI (Chrome, Edge, Firefox; Safari and iPad have none: use 🎹 or a phone there).

Notes

  • A sketch that already has its own knob1 (a let, a function) keeps it, and a card beside the 🎹 says what to read instead (knob(1)).
  • With OP Configurator, knobs also drive the OPC sliders in the order they are declared. A knob the sketch reads itself stays the sketch's: that slider no longer follows it.

Middle C is 60, A4 is 69. noteName(note) writes the number as a name (60 → 'C4') and noteFreq(note) as a frequency in Hz. velocity says how hard it was pressed. For every key, not just the last, define notePressed().

OAVp5.play()#

functionoav-p5
OAVp5.play(note, [velocity])

Plays a key as if a controller did: midi.play(60, 0.8) presses middle C, midi.play(60, 0) lets it go.

It sends the same MIDI bytes a keyboard would, with midi.last.source set to 'screen', so everything reacts: notePressed(), noteIsDown(), note, the sound if startSound() is on. midi and OAVp5 are the same object, so OAVp5.play and midi.play are one function.

Parameters

noteNumber | StringThe key: a MIDI number or a name ('C#4').
velocityNumberHow hard, 0..1; 0 releases the key. Leave it out for full force. optional default 1

Notes

  • The key stays down until you play it again with velocity 0.

bass#

variableoav-p5
bass

Also: mid treble

How much of the microphone's sound is low (bass), middle (mid) or high (treble), each from 0 to 1.

Use them like micLevel, one number per band: fill(200 + bass * 160, 70, 100) pushes the colour with the low end. The three share one entry because they behave the same; only the frequency range differs.

Unlike micLevel they are not measured in decibels: each is the average strength of the frequencies in its band, scaled by micSensitivity() and held to 1. A band that is faint in your room can stay close to 0; raise the sensitivity rather than multiplying by a large number.

Type
Number
Range
0..1

The energy in 20–250 Hz (bass), 250–2000 Hz (mid) and 2000–8000 Hz (treble). Updated once per display frame while the microphone is on; 0 otherwise.

Reading any of them asks for the microphone the first time, exactly like micLevel; until you allow it they are 0.

beat#

beat

True for one frame each time the microphone (or the drum machine) hears a beat.

It behaves like mouseIsPressed while a button is down, except the "press" lasts one frame: if (beat) flash = 1; is all it takes to react to the music. A beat is a jump in loudness over what the room has been doing, with at least 100 ms between two beats; two beats between two frames count as one.

kickDetected()#

eventoav-p5
function kickDetected(level) {}

Also: snareDetected hatDetected

You define these; oav-p5 calls them when the microphone (or the drum machine) hears a kick, a snare or a hat.

The microphone splits what it hears into three drum-like bands and calls the matching function when each band jumps: 20–120 Hz for the kick, 150–800 Hz for the snare, 6–14 kHz for the hat. There is no machine learning in it, just a transient in a frequency band, so a bass voice can trigger a kick.

When the drum machine plays, each of its hits calls the same functions: kick for the kick, snare for a snare, clap or rim, hat for a closed, open or pedal hat. A sketch written for the microphone therefore works with startDrums() unchanged.

Before it has a value

Defining one of them is not enough to open the microphone once the drum machine has started; reading micLevel (or calling startMic()) is. Without the drum machine, a sketch that defines any of them and reads nothing starts the microphone on the first click or key.

micLevel#

variableoav-p5
micLevel

How loud the microphone hears things, from 0 (a quiet room) to 1 (shouting).

Read it in draw() the way you read mouseX: circle(width / 2, height / 2, 50 + micLevel * 300) grows when someone talks. It is a loudness in decibels, which is how an ear hears it, measured from the room itself: the bottom of the scale follows the room's own noise (it settles within a second or two and rises at most 1.5 dB a second, so a voice never becomes the new silence), and −10 dBFS, shouting into a laptop, is 1.

In practice a quiet room reads 0, a quiet voice about 0.4 to 0.6, shouting close to 1. If the microphone is quiet or far away, raise it with micSensitivity().

It follows the browser's animation frames rather than draw(), so a sketch running at frameRate(10) still reads the latest value, and the number stops changing while the tab is hidden (browsers pause animation frames there).

Type
Number
Range
0..1

Updated once per display frame while the microphone is on. It is 0 while the microphone is off, still asking, blocked or missing.

Before it has a value

Nothing to call. The first time a sketch reads micLevel (or bass, mid, treble, beat), oav-p5 asks the browser for the microphone, and every value stays 0 until you allow it. The page needs https or localhost. If the browser kept audio quiet until a click, the first click or key starts it. ?oav_mic=click makes only the 🎤 button and startMic() turn it on; ?oav_mic=off means nothing can.

  • In the 🎹 panel the 🎤 button turns the microphone on and off by hand and shows the level. When the browser blocked it, a card beside the 🎹 says why and what to press: click the lock left of the address, set Microphone to Allow, then click the canvas.
