OAVp5.mic.stop()#

functionoav-p5
OAVp5.mic.stop()

Turns the microphone off and sets every microphone value back to 0: the same as stopMic().

stopMic() is this function. It stops the microphone's tracks and closes its audio context, so the browser's "recording" indicator goes away, and OAVp5.mic.level, bass, mid, treble, rms read 0 and db reads −100. After it, only OAVp5.mic.start() or 🎤 turns the microphone back on: reading micLevel does not.

Returns

Promise<Boolean> Resolves to false, the new state of the microphone.
