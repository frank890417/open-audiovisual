trigger()#

functionoav-p5
trigger([name])

Also: OAVp5.chop.trigger

Fires an event of your own, by name, for env() and count() to react to.

Call it where the thing happens: function mousePressed() { trigger('boom'); }. Then read it anywhere in draw() with env('boom', 0.01, 0.6) (a pulse that fades) or count('boom') (how many times so far). It returns nothing.

It works anywhere, not only in draw(), and each call is one event, remembered with the time it happened. You can fire the built-in names by hand as well: trigger('kick') pulses env('kick') as a real kick would.

Parameters

NameTypeDescription
nameStringThe name of the event. Anything is fine except the built-in meanings: 'kick', 'snare', 'hat', 'beat', 'note', 'bar' and 'step' are also fired by the microphone, the keys and the drum machine. Left out: 'trigger'. optional default 'trigger'

Notes

  • OAVp5.chop.trigger(…) is this function under another name.
