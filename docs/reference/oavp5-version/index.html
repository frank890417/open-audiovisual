OAVp5.version#

variableoav-p5
OAVp5.version

The version of oav-p5 that loaded, as text such as '0.8.0'.

Useful in a bug report or to check which build a page got: openaudiovisual.com/p5/oav-p5.js is always the latest, while a jsDelivr address with a tag is frozen. The same number is on the first line of the 🩺 check-up.

Type
String

Set when oav-p5 loads and never changes.

Notes

  • If the file loads twice (the loader line and the OpenProcessing library list), the first one wins and the second does nothing.
