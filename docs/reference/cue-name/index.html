cueName#

variableoav-p5
cueName

Also: OAVp5.drums.lastCue

The name of the last cue that fired, or an empty string before the first one.

Read it in draw() instead of waiting for cueFired(): look = SCENES[cueName];. It is the name of the last cue only, so it is the right thing for "which scene am I in", and cueFired() is the right thing for "something just began". Cues are declared with cue().

Type
String
Range
'' or a cue name

Changes when a cue fires, and keeps the name until the next one. It is '' at the start.

Notes

  • A sketch that declares its own variable called cueName keeps it: oav-p5 leaves the name alone and a card says to read OAVp5.drums.lastCue instead.

Related

  • cue() Plans something for a bar: at bar bar the function cueFired(name, bar) is called and cueName becomes name; with every, again every that many bars.
  • cueFired() An event you define: it is called when the bar of a cue declared with cue() has come, with the cue's name and the bar.
  • drumBar Which bar the drum machine is in, counted from 1 when it started.
  • startDrums() Starts a drum machine: a 16-step grid on the page that plays a preset, your own grid or one line of rhythm, and counts the bars for your sketch.
