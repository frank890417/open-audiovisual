OAVp5.chop.slots()#

functionoav-p5
OAVp5.chop.slots()

Lists every memory the CHOP functions are using right now: its kind, how it is found, and its latest value.

For finding out why two calls seem to share a memory, or whether a loop made hundreds: OAVp5.chop.slots().length is how many there are. It reads the state and changes nothing.

Returns

Array<Object> One { kind, key, mode, value } per memory. kind is the function ('lag', 'spring', …). key is '#1', '#2' for calls found by order, a name for named ones, or the line of code for calls matched by line. mode says which: 'order', 'name' or 'site'. value is its latest output (missing for a trail).

Notes

  • This is advanced. 🩺 and tests use it; a sketch rarely needs to.
