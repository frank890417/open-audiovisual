L1 INPUT — MIDI · audio analysis · chord semantics · body pose → named, normalized signals

L2 MAPPING — signal → param routes: curves · smoothing · many-to-many · live learn

L3 WORLD — your algorithmic system; reads params, never inputs. p5 / three / canvas / anything

L4 OUTPUT — screen · MIDI out · OSC → UDP bridge (Spat, Reaper, TouchDesigner, lights)

⏱ TIMELINE — param automation · scenes & cues · performance teleprompter

📟 MONITOR — backstage view on any LAN device: clock, scene, every signal, FPS

Why

Everything TouchDesigner-class tools do on a desktop, the browser now does with a URL — WebGL, Web MIDI, realtime audio analysis, on-device pose tracking. What everyone kept rebuilding was the chassis: MIDI plumbing, mapping UI, a timeline with cues, a backstage. This is that chassis, extracted from a real show — The Last Input (IRCAM / C-LAB Taiwan Sound Lab 2026, 49.4-channel dome).

Agent-native

Worlds are visual code, and coding agents are good at code. The repo ships AGENTS.md and a bundled /create-world skill: describe a performance in natural language ("a jellyfish world that blooms on consonant chords") and your agent writes a runnable World inside the chassis.
